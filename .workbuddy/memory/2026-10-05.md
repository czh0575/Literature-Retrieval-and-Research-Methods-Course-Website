写法要点（VitePress 嵌套侧边栏）：
- 分组项只写 `text` + `items`（不写 link）即为纯分组标题；带 link 的分组标题点击行为不可控，故不用
- `collapsed: false` 让分组默认展开；有 active 子项时 VitePress 也会自动展开
- 渲染后侧边栏 class 依次为 `level-0`（第七部分）／`level-1 collapsible has-active`（7.3 分组）／
  `level-2 is-link is-active`（7.3.1），可用于验证
- 同一目录（`/course`）的 sidebar 键自动覆盖子目录页面，无需额外配置
