# 1. 关键词体系与检索准备

## 1.1 先写研究问题，不要先打开数据库

以“研发费用加计扣除对高新技术企业创新投入的影响”为例，可以拆出：

- 政策：研发费用加计扣除、税收优惠
- 对象：高新技术企业、企业
- 结果：创新投入、研发投入
- 可能机制：融资约束、税负、现金流

这一步的目标是建立词表，不是马上得到最终题目。

## 1.2 关键词金字塔

```text
上位概念：税收优惠
    ↓
核心概念：研发费用加计扣除
    ↓
同义表达：研发加计扣除、加计扣除政策
    ↓
相关概念：企业创新、研发投入、创新绩效
```

上位词帮助你扩大检索范围，核心词帮助你保持相关性，相关词帮助你发现研究者使用的不同表述。

## 1.3 关键词表模板

| 概念角色 | 关键词 | 来源或依据 |
| --- | --- | --- |
| 核心政策 |  | 题目和政策文件 |
| 研究对象 |  | 题目和行业资料 |
| 结果变量 |  | 文献中的指标 |
| 同义词 |  | 检索结果标题 |
| 机制词 |  | 理论和综述文献 |

## 1.4 先求全，再限定

第一次检索的任务是尽量找全相关表述。不要一开始就叠加很多筛选条件，否则可能把关键文献排除。

第二次检索再根据研究需要限定：

- 学科
- 年份
- 来源类别
- 核心期刊
- 文献类型

## 1.5 课堂实操

为自己的选题制作一张 20 个词以内的关键词表，并写出三组检索组合。
