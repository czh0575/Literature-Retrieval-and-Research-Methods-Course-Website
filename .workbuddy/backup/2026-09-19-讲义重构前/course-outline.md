# 《文献检索与研究方法》课程大纲

本课程面向大四学生，围绕“从提出问题到形成规范研究成果”的完整过程展开。课程不把论文写作理解为最后阶段的格式加工，而是将学术道德、选题、文献检索、文献管理、文献综述和开题报告视为相互衔接的研究训练。

## 一、课程简介

### 1. 课程定位

- 认识学位论文与一般学术论文、课程报告之间的联系与区别
- 训练提出问题、分析问题、组织证据和规范表达的能力
- 为毕业论文选题、开题答辩和论文初稿准备可复用的工作流程

### 2. 学习目标

学完本课程后，学生应能够：

1. 说明学术道德、学术规范与论文质量之间的关系
2. 将宽泛兴趣转化为可研究、可度量、可完成的研究问题
3. 使用知网等数据库建立关键词体系并完成检索、筛选和导出
4. 使用 Zotero 管理题录、附件、标签、批注和引用
5. 按专题归纳文献，完成“有综有述”的文献综述
6. 独立完成一份结构完整、格式规范的课程报告或开题报告

### 3. 课程任务与考核

- 平时成绩：50%
  - 课堂表现（考勤、讨论、提问与回答）：20%
  - 课堂作业约 3 次：30%
  - 优秀表现可作为特别奖励
- 期末课程报告：50%
  - 以开题报告或课程报告为基础
  - 文献综述是重点部分
  - 必须有规范的引文和参考文献
  - 课程报告评分与开题答辩成绩相互独立

### 4. 课程产出

- 一份可行的论文选题说明
- 一份检索记录和文献管理库
- 一份文献综述初稿
- 一份课程报告或开题报告

## 二、学术道德

### 1. 为什么要学习学术道德

- 学位论文不仅考查结果，也考查研究过程
- 规范写作是未来写报告、做研究和进入职场的基础能力
- 诚信比“降低重复率”更重要，不能把查重当成学术规范的全部

### 2. 学术不端的基本类型

- 剽窃、抄袭和侵占他人学术成果
- 伪造、篡改或选择性报告数据
- 不当署名、虚构合作者或隐瞒他人贡献
- 提供虚假学术信息
- 买卖论文、代写论文
- 违规使用人工智能工具或把未经核验的生成内容当作事实

### 3. 论文写作中的具体规范

- 何时必须引用
- 直接引用、转述和总结的区别
- 引文与参考文献的一致性
- 数据、图表、图片和网络资料的来源标注
- 合作写作中的贡献确认
- 使用 AI 时的核验、披露与责任边界

### 4. 案例与课堂活动

- 代写和买卖论文案例
- “只改写句子就不算抄袭”的误区
- “AI 生成内容能否直接放入论文”的判断练习
- 给一段材料，要求学生完成转述、引用和参考文献标注

## 三、关于论文选题

### 1. 从兴趣到研究问题

- 区分研究对象、研究问题、研究变量和研究结论
- 用“是什么、为什么、怎么办”拆解问题
- 避免把“研究某行业/某群体”直接当成研究问题

### 2. 选题的四项原则

- 研究性：能够提出需要分析和论证的问题
- 创新性：在已有研究基础上形成新的角度、材料、机制或结论
- 时效性：与现实政策、行业变化或社会问题保持联系
- 可行性：在时间、数据、方法和能力范围内完成

### 3. 税收学专业的选题方向

- 税收理论与税收史
- 税收政策与制度
- 税收管理与征收
- 税收与经济发展
- 专项税种与企业、个人
- 税收法治与税收遵从
- 地方税收
- 特殊行业与税收

### 4. 实证选题的基本结构

- 用 X 表示核心解释变量，用 Y 表示被解释变量
- X、Y 必须能够找到文献支撑并且可以度量
- 避免 X 对 Y 的关系过于直接、无需研究
- 尽量优先考虑可获得的企业层面数据

### 5. 选题流程与产出

1. 确定大致方向
2. 搜集并阅读相关文献
3. 初步确定研究内容
4. 明确背景、视角、方法和意义
5. 拟定研究思路与框架
6. 撰写选题说明和开题报告

### 6. 常见问题

- 核心变量含义不清
- 研究对象过大
- 概念无法度量
- 数据获取难度过高
- 研究意义只是宏大口号
- 选题与已有论文高度重复

## 四、知网文献检索方法

### 1. 检索前的准备

- 把研究题目拆成核心概念
- 建立“核心关键词—上位概念—同义词—相关概念”的关键词金字塔
- 先求全，再逐步限定学科、年份、来源和文献类型

### 2. 基础检索与高级筛选

- 主题、篇名、关键词、摘要和全文字段的区别
- 关键词组合与检索式设计
- 按学科、年份、来源、核心期刊和文献类型筛选
- 用标题和摘要判断相关性

### 3. 从检索结果发现研究脉络

- 识别高频关键词和代表性研究
- 追踪综述、学位论文和高被引论文
- 通过参考文献和被引文献扩展检索
- 使用知网的可视化分析辅助了解研究领域

### 4. 文献筛选与记录

- 建立纳入与排除标准
- 保存题录、摘要、关键词、来源和下载位置
- 记录每篇文献的研究问题、数据、方法和结论
- 形成可追溯的检索日志

### 5. 导出与引用

- 批量导出题录
- 检查作者、年份、刊名、卷期、页码和 DOI
- 认识数据库导出格式可能存在的错误
- 为后续 Zotero 管理和文献综述写作准备数据

## 五、文献管理工具：Zotero

### 1. 为什么需要文献管理工具

- 解决文件散落和重复下载问题
- 解决题录字段不完整和格式不统一问题
- 让“阅读—批注—引用—生成参考文献”形成连续流程

### 2. Zotero 基础设置

- 安装 Zotero 与浏览器连接器
- 创建课程资料库和论文专题库
- 设置附件保存位置、同步和备份策略
- 建立 collections、tags 和 saved searches

### 3. 题录与附件管理

- 从知网等数据库导入题录
- 导入 PDF 并核对元数据
- 合并重复条目
- 统一文件命名和附件位置
- 使用标签和笔记记录阅读状态

### 4. 阅读与知识整理

- 给文献添加摘要、批注和阅读笔记
- 区分“原文观点”和“自己的判断”
- 为文献建立专题、观点和方法标签
- 记录可直接用于综述的证据句和页码

### 5. Word 引用与参考文献

- 插入文内引用
- 选择 GB/T 7714 等引用样式
- 自动生成和更新参考文献表
- 修改题录后刷新文档
- 论文定稿前逐条检查引用与参考文献

### 6. 工作流与备份

下载题录 → 核对元数据 → 归档 PDF → 阅读批注 → 写作引用 → 生成参考文献 → 备份与同步。

## 六、撰写文献综述

### 1. 文献综述的任务

- 说明研究问题在学术上的来历
- 归纳已有研究的主题、观点、方法和结论
- 比较不同研究之间的一致与分歧
- 指出已有研究的不足
- 推导出自己的研究问题、研究方法和研究价值

### 2. 文献综述的组织方式

- 按专题组织：最适合围绕 X、Y、机制、问题和对策展开
- 按国内外组织：适合文献数量和研究传统差异明显的主题
- 综合组织：先按专题，再比较国内外研究

### 3. “综”与“述”

- “综”：归纳同类观点，呈现研究脉络和共识
- “述”：说明研究使用了什么数据、方法和证据
- “评”：指出理论、数据、范围、机制或方法上的不足

### 4. 推荐写作结构

1. 研究背景和综述范围
2. 专题一：核心概念或基础研究
3. 专题二：变量关系、影响因素或研究机制
4. 专题三：具体问题、行业或区域研究
5. 国内外研究比较
6. 文献评述与研究切入点

### 5. 引用与表达

- 合并同类观点，不要机械地逐篇罗列
- 使用著者—出版年制时保持格式统一
- 每个段落先概括，再给证据，最后说明与本文的关系
- 参考文献必须覆盖正文中的全部引用

### 6. 常见问题与修改任务

- 只有“综”没有“述”和“评”
- 只写“研究很多”，却没有研究脉络
- 国内外分类混乱，专题之间重复
- 文献年代、来源和质量不匹配
- 文献综述与自己的研究问题脱节
- 课堂练习：把 5 篇逐篇摘要改写成 1 个专题段落

## 七、贯穿全课程的学习路径

选题方向 → 关键词体系 → 数据库检索 → Zotero 建库 → 阅读和批注 → 文献综述 → 开题报告 → 课程报告或论文初稿。

每个模块都应留下可提交的过程性成果，最终形成一套能够继续用于毕业论文的研究档案。
