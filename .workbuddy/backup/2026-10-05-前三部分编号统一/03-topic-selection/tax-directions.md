# 2. 税收学选题方向

## 2.1 八个常见方向

| 方向 | 可以关注的问题 |
| --- | --- |
| 税收理论与税收史 | 税负转嫁、税制结构、税收思想 |
| 税收政策与制度 | 税制改革、优惠政策、绿色税收 |
| 税收管理与征收 | 征管效率、信息化、税收稽查 |
| 税收与经济发展 | 产业结构、创新、区域发展 |
| 专项税种 | 增值税、消费税、企业所得税、个税 |
| 税收法治与遵从 | 执法规范、纳税遵从、税务代理 |
| 地方税收 | 地方税体系、财政收支和债务 |
| 特殊行业与税收 | 互联网、房地产、金融和新经济 |

这些方向是检索和思考的入口，不是可以直接提交的论文题目。

## 2.2 从“大方向”缩到“小问题”

可以沿着以下顺序收窄：

> 税收政策 → 具体政策 → 具体对象 → 具体结果 → 具体机制或情境

例如：

> 税收优惠 → 研发费用加计扣除 → 高新技术企业 → 研发投入 → 融资约束的调节作用

收窄之后，研究对象、数据和方法才会逐渐清晰。

## 2.3 方向选择的建议

- 对理论和历史感兴趣，才考虑税收理论与税收史
- 对政策实施熟悉，可以考虑税收管理或地方税收
- 希望进行实证分析，优先选择有公开企业数据的主题
- 有实习经验，可以从真实业务流程中寻找问题
- 题目应与导师研究方向和可获得资源相匹配
