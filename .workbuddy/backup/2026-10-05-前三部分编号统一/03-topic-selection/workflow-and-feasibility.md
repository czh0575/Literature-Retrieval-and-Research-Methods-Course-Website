# 4. 从兴趣到选题说明

## 4.1 六步选题流程

1. **记录兴趣**：把新闻、课程内容、实习经历中的疑问写下来
2. **检索概念**：用核心词和上位概念检索已有研究
3. **确定问题**：从对象描述转向因果、机制、比较或对策问题
4. **检查证据**：确认文献、数据和政策资料是否可得
5. **缩小范围**：限定时间、地区、行业、样本或政策
6. **写出说明**：形成背景、意义、问题、方法和可行性摘要

阅读和思考会反复循环，不是做完一步就永远不回头。

## 4.2 “是什么、为什么、怎么办”

- **是什么**：现实背景、概念、现状和问题表现
- **为什么**：原因、机制、影响因素或理论解释
- **怎么办**：政策建议、治理方案或研究设计

不同类型的论文侧重点不同。实证研究可能重点回答“为什么”，对策研究则要让建议与问题一一对应。

## 4.3 选题说明模板

一页选题说明可以包含：

- 暂定题目
- 研究对象和核心问题
- 现实背景与理论背景
- 初步文献线索
- 研究方法和数据来源
- 预期难点
- 选题价值与可行性

## 4.4 自检清单

- [ ] 题目中每个核心概念都能解释和度量
- [ ] 我能说出至少 5 篇相关文献
- [ ] 我知道数据或案例从哪里来
- [ ] 研究范围没有大到无法完成
- [ ] 题目不是已有论文的简单改写
- [ ] 研究问题能被我的方法真正回答
