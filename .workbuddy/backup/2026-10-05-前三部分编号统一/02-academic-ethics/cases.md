# 4. 案例分析与自查

## 4.1 代写和买卖论文

网络上的“代写、包过、包降重”服务，往往无法保证内容真实，也不能保证数据和文献可靠。即使最终没有被发现，学生也失去了完成研究训练的机会。

讨论问题：

- 为什么“别人代写，我自己修改”仍然存在诚信问题？
- 论文被退回后，最难补救的是什么？
- 指导教师、同学和平台分别应承担什么责任？

## 4.2 改写是否等于原创

如果段落的核心观点、证据顺序和表达结构都来自同一篇文献，仅仅替换词语并不能变成原创。合适的做法是：

1. 先理解原文
2. 合上原文写出自己的概括
3. 对照原文检查是否改变含义
4. 加上准确引用

## 4.3 自查表

- [ ] 我保存了重要资料的原始来源
- [ ] 我能解释每一条核心结论来自哪里
- [ ] 我没有虚构、拼接或选择性修改数据
- [ ] 我没有把 AI 生成的文献直接当作真实文献
- [ ] 我已经核对了正文引用与参考文献
- [ ] 我能说明合作者或他人的具体贡献
