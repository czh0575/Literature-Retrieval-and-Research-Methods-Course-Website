# 课程介绍

## 课程目标

本课程《文献检索与研究方法》面向高校学生,旨在培养以下能力:

1. **信息意识**:识别学术信息需求,选择合适的信息资源
2. **检索能力**:熟练使用各类数据库与检索工具
3. **评价能力**:评估信息源的可信度、相关性与学术价值
4. **利用能力**: 规范引用文献,撰写学术论文与综述
5. **研究素养**:形成科学的思维方式与学术规范意识

## 适用对象

- 本科生(尤其撰写毕业论文的学生)
- 研究生新生
- 需要开展课题研究的科研人员

## 学习路径

```
信息检索基础 → 数据库使用 → 检索策略 → 文献管理 → 学术写作
```

请按章节顺序学习,每章配备练习题与案例分析。
