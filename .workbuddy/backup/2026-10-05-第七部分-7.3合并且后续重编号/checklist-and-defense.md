# 7.10 提交前检查与答辩准备

开题报告写完不是终点，还有两道关：指导教师审核和开题答辩。这一节把前九节的要求收成几张清单，并说明评委会看什么、会问什么。

## 7.10.1 提交前的三轮检查

不要一次性从头读到尾地检查，分三轮做，命中率更高。

**第一轮：内容检查（对着 7.1 的骨架句看）**

- 背景、综述、研究内容三部分是否指向同一个研究对象
- 研究内容是不是在回应文献综述里指出的那个缺口
- 关键问题、研究方法、技术路线是否与研究内容对齐

**第二轮：格式检查（对着模板逐栏看）**

- 七个栏目是否齐全，栏目名称与模板是否一致
- 字数是否达到各部分下限
- 引注格式、参考文献格式是否统一
- 图表编号、图注、表格是否规范
- 页码、签名栏、日期是否填写

**第三轮：语言检查（朗读一遍）**

- 有没有读不通的长句（一句话超过 60 字就要警惕）
- 有没有“非常”“十分”“众所周知”这类空泛修饰
- 有没有从文献里直接搬过来、连词都没有改的句子
- 标点是否统一（中文用全角，英文与数字用半角）

## 7.10.2 逐栏检查清单

| 栏目 | 检查要点 |
| --- | --- |
| 一、选题的背景与意义 | 国家、社会、学界三条线索齐备；最后落到自己的研究；意义分理论、现实两条，不写空话 |
| 二、国内外研究现状 | 不少于模板要求的字数；专题划分有依据；有合并归纳；有分歧；有文献评述 |
| 三、研究的内容及可行性分析 | 总分结构；逐部分交代做什么；框架图与文字对应；可行性覆盖思路、数据、方法 |
| 四、拟解决的关键问题及难点 | 关键问题写成完整问题并交代做法；难点写清如何克服；重点与难点不重合 |
| 五、研究方法与技术路线 | 每个方法对应具体问题；技术路线图要素完整、可执行 |
| 六、研究的总体安排与进度 | 按学院当年进度表填写；每阶段有可检查的产出 |
| 七、主要参考文献 | 满足数量与外文下限；中文在前英文在后；GB/T 7714 格式统一；与正文一一对应 |

## 7.10.3 评审环节：谁在看、看什么

开题报告要经过三关，评语的口径都写在模板里：

| 环节 | 评审人 | 关注点 |
| --- | --- | --- |
| 指导教师审核 | 指导教师 | 选题是否可行、工作量是否合适、与自己研究方向是否匹配 |
| 开题答辩 | 开题答辩小组 | 选题意义、文献综述、研究内容与方法，形成不少于一定字数的评语 |
| 学院审核 | 学院毕业论文工作领导小组 | 是否同意开题 |

答辩小组的评语集中在四个方面：**选题意义、文献综述、研究内容、研究方法**。这正好对应开题报告的第一、二、三、五部分——也就是说，第四部分的重点难点、第六部分的进度、第七部分的参考文献虽然也要写，但答辩的争议点通常在前面四个部分。

::: warning 结论有“完善后通过”这一档
多数学院的开题答辩有“通过”“完善后通过”“未通过”三档。拿到“完善后通过”，意味着题目本身没问题，但某一栏需要按要求修改后重新提交，按要求改完即可；“未通过”通常指向选题本身的可行性或文献基础。因此，与其在答辩时争辩，不如在写的时候把第二部分和第三部分做扎实。
:::

## 7.10.4 答辩常见的九类问题

开题答辩时间通常不长，问题集中在下面几类。提前写下自己的答案，比现场组织语言可靠得多。

1. **这个题目为什么值得研究？**（考第一部分）——准备一段 30 秒能讲完的回答，不要复述整段背景。
2. **你读了哪些文献？这个领域最权威的研究是什么？**（考第二部分）——至少能说出 3—5 篇代表性文献的作者、结论和自己的判断。
3. **已有研究已经很多了，你的创新点在哪里？**（考第二部分与第三部分）——把文献评述里那句“因此本研究……”搬出来讲。
4. **你的核心变量怎么度量？**（考第三部分与方法）——能说清指标来源、计算方法，以及是否存在争议。
5. **数据从哪里来？样本多大规模？**（考可行性）——具体到数据库名称、样本期、样本量的量级。
6. **为什么用这个方法而不是别的？**（考方法）——从“研究问题的性质”和“识别策略”两个角度回答。
7. **如果结果和你预期相反，怎么办？**——说明你会怎么解释、会做哪些检验，而不是坚持结论不变。
8. **你的进度安排来得及吗？**——给出关键节点的日期，并说明风险最大的环节。
9. **这个题目和某篇已有论文有什么区别？**——用一句话说清对象、机制或情境上的差异。

## 7.10.5 答辩不通过的常见原因

- 题目过大或过虚，两个核心变量说不清楚
- 文献综述只有罗列，没有归纳也没有评述，看不出研究缺口
- 研究内容与文献综述脱节：综述说别人没做过 A，研究内容却在做 B
- 研究方法与研究问题不匹配，或罗列了一堆用不上的方法
- 数据来源说不清楚，“大概能拿到”这类回答容易被追问
- 进度安排明显不可行

这些问题的根源大多不在答辩现场，而在前三部分的写作。7.2 至 7.8 的每一条自查清单，实际上都是答辩评分点的拆解。
