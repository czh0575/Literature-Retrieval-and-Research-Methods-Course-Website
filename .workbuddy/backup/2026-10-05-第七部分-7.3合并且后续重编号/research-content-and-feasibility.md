# 7.6 研究内容与可行性分析

第三部分是全文的骨架。选题背景说明“为什么值得做”，文献综述说明“别人做到哪了”，这一部分要说明“**你具体做什么**”——把研究缺口变成一份能落地执行的工作安排。写好了，后面第四、第五部分都有依托；写不好，重点难点和方法都成了无根之木。

## 7.6.1 研究内容写成“总分结构”

课件的表述很明确：研究内容要采用**总分结构**。

- **总**：先用一段话说明本文总体上研究什么。这一段应该与 7.1 讲的“骨架句”一致。
- **分**：再逐一介绍每一部分做什么。每一部分用“**有总起句**”的写法，先一句概括这一部分的任务，再说明具体内容。

不要写成“本文分五章，第一章绪论，第二章文献综述，第三章……”——这种写法只交代了章名，没有交代内容。正确的做法是让读者读完“分”的部分，就知道每一章产出什么。

## 7.6.2 逐章介绍要交代四件事

每一部分（每一章）至少交代下面四项中的前三项：

1. 这一部分**回答哪个问题**
2. 使用什么**材料或方法**
3. 得出什么**类型的结果**
4. 与下一部分**如何衔接**

例如，写“研究设计”这一部分时，应该交代：本章要确定变量与模型（回答问题 2 的度量问题）；使用 CSMAR 数据库的企业层面数据；产出变量定义表与基准计量模型；为下一章的实证分析提供工具。

## 7.6.3 常见章节框架

课件给出的框架分为实证类和规范类两条路。**因选题而异，灵活变通，不要照搬。**

![两类选题的章节框架](/images/opening/o04-chapter-structure.svg)

*图 7-4　实证类与规范类选题的常见章节框架*

| | 实证分析类 | 规范分析类 |
| --- | --- | --- |
| 第一章 | 绪论（背景、意义、文献、思路与方法） | 绪论（背景、意义、文献、思路与方法） |
| 第二章 | 概念界定与理论分析 | 概念界定与理论基础 |
| 第三章 | 现状分析 | 现状与问题 |
| 第四章 | 研究设计与数据来源 | 原因或机制分析 |
| 第五章 | 实证结果与稳健性检验 | 经验借鉴或可行性分析 |
| 第六章 | 结论与对策建议 | 结论与对策建议 |

课件建议论文正文**以 5—6 章为宜（不含引言）**。章数太少，内容撑不起一篇毕业论文；章数太多，每一章都写不深，还容易重复。

::: tip 规范类选题的几种章节思路
规范分析类选题的中间章节，可以按题目的性质在下面几类里选：

- **必要性分析**：说明为什么需要研究这个问题、解决它的紧迫性在哪里
- **模型的构建方法**：介绍用于测算或评估的模型、指标与参数
- **可行性分析**：分析某一政策、方案在本地区、本行业的实施条件
- **国外经验**：梳理可比较的国家或地区做法，提炼可借鉴之处

选一到两类即可，不必全上。
:::

## 7.6.4 框架图怎么画

课件要求研究内容“配以文字描述具体的研究内容”，也就是**文字为主、框架图为辅**。框架图的作用是让评委三秒钟看懂你的整体安排。

画框架图的几条要求：

- 用 Word 或 PPT 的形状工具画，画好粘贴进文档，不要手绘拍照
- 从上到下体现**逻辑顺序**（提出问题 → 分析问题 → 解决问题），不是章节目录的复述
- 每个方框里是“这一部分做什么”，不是“第几章”
- 框架图里的方框，与研究内容正文里的“分”要一一对应
- 图要清晰、层级分明；线条不要交叉，字号不要忽大忽小

::: warning 框架图不能代替文字
有同学把研究内容只写一句“本文研究框架如图 1 所示”，然后把图贴上去。这是不够的。评委需要从文字里看到你对每一部分的理解，图只是辅助。图与文字必须对应，缺了文字，图就变成了目录的翻版。
:::

## 7.6.5 可行性分析：分点列示，几句话即可

可行性分析不用长，几句话分点写清楚即可。课件给出的三个角度：

| 角度 | 要回答的问题 | 常见写法 |
| --- | --- | --- |
| 思路可行 | 研究问题是否清晰、逻辑链条是否完整 | 已有成熟理论支撑，分析框架清晰 |
| 数据可行 | 数据能不能拿到、量够不够 | 数据可从某数据库或公开统计资料获取，样本量满足要求 |
| 方法可行 | 方法是否掌握、技术条件是否具备 | 所用方法有成熟应用先例，相关软件与操作可以实现 |

数据可行是最容易被追问的一项。写的时候要具体到“**哪个数据库、什么层面、大致多大规模**”，而不是笼统地写“数据可以获取”。如果样本地区企业数量偏少，或者数据存在缺失，最好在可行性分析里正面回应，而不是回避。

## 7.6.6 范例

::: details 范例：《环保费改税对企业数字化转型的影响研究》

**三、研究的内容及可行性分析**

**（一）研究内容**

**第一部分，绪论。** 首先介绍本文研究背景及意义，阐述我国环境治理体系从“排污费”到“环保税”的现代化转型进程，强调《环境保护税法》实施作为一项关键制度变革的重要性。然后，梳理国内外文献，总结和评述现有研究成果。

**第二部分，理论分析与研究假设。** 首先对环保费改税的制度进行简要概述，阐述“成本约束效应”与“创新补偿效应”等竞争性理论视角，在此基础上，提出关于环保费改税对企业数字化转型可能产生抑制、促进或非线性影响的研究假设。最后，将制度实际实施与相关理论基础相结合，提出本文的研究假设。

**第三部分，研究设计。** 首先，明确数据来源于 CSMAR、国家统计局等数据库，并说明数据清洗过程。其次，对本文的主要因变量企业数字化转型进行说明，同时也说明相关的自变量与控制变量。最后，根据本文的假设设计双重差分模型进行实证分析。

**第四部分，实证分析。** 首先，对本文主要变量进行描述性统计与相关性分析，并进行多元回归分析，报告环保费改税对企业数字化转型影响的基准回归结果。进一步采用平行趋势检验、安慰剂检验、替换变量度量方式等方式进行本文的稳健性检验。在异质性分析中，按产权、规模、地区、行业等进行分组。

**第五部分，研究结论与建议。** 总结全文的核心发现，并在此基础上提出相关的政策建议。坦诚说明本研究的局限性，并对未来补充做出进一步展望。

**（二）可行性分析**

在理论方面，环境经济学、财政学、公司金融等领域已有较为成熟的理论支撑，如“波特假说”“合法性理论”等，为本研究提供了扎实的理论基础。在数据方面，企业数字化转型、财务数据等可从 CSMAR、国家统计局等数据库获取。在研究方法方面，利用 Stata 软件分析样本，获得所需要的数据。

::: tip 这个范例好在哪
研究内容是五部分，逐一交代“做什么 + 怎么做”，每部分都有总起句式的概括，读下来能看出每一章的产出。可行性分析按理论、数据、方法三点分列，各一句，没有多余的铺垫。整段篇幅不到八百字，但信息是完整的。
:::
