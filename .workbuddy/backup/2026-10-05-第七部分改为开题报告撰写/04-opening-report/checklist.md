# 4. 进度安排与提交前检查

## 4.1 进度安排

进度表要写成可以检查的任务，不要只写“完成论文”：

| 阶段 | 任务 | 产出 |
| --- | --- | --- |
| 第 1 阶段 | 确定方向、初步检索 | 选题说明 |
| 第 2 阶段 | 扩展检索、阅读和批注 | 文献库和阅读表 |
| 第 3 阶段 | 完成综述、研究框架 | 文献综述初稿 |
| 第 4 阶段 | 设计方法、确认数据 | 技术路线图 |
| 第 5 阶段 | 修改开题报告 | 开题报告定稿 |

时间节点应根据学院和导师的安排调整。

## 4.2 参考文献要求

课件中给出的“中文文献在前、英文文献在后”“参考文献 15 篇以上、外文不少于 2 篇”等，可以作为本课程的建议示例，具体以学院模板和教师要求为准。

最重要的不是数量，而是：

- 文献与研究问题相关
- 关键观点都有来源
- 格式统一
- 正文和文末一一对应

## 4.3 提交前检查

- [ ] 背景最后落到了自己的研究问题
- [ ] 理论意义和现实意义没有空泛拔高
- [ ] 文献综述包含“综、述、评”
- [ ] 研究内容与目录框架一致
- [ ] 每个研究方法都对应一个问题
- [ ] 技术路线可以实际执行
- [ ] 重点和难点有所区分
- [ ] 进度安排有具体产出
- [ ] 参考文献格式统一且可核查

## 4.4 课程作业

提交一份 2—3 页的开题报告提纲，至少包括：

- 研究题目
- 背景和意义
- 文献综述的专题划分
- 研究内容和技术路线
- 数据或资料来源
- 进度安排
