# 7.3 文献综述

文献综述是开题报告里篇幅最大、也最能看出功力的部分，要求不少于两千字，同时是查重的重灾区。它承上启下：向上承接第一部分提出的“研究缺口”，向下支撑第三部分的研究内容。

本节分三个小节，按“定范围 → 写段落 → 拼初稿”的顺序排列，建议依序阅读：

- **7.3.1 任务、范围与专题划分**：综述要回答什么问题，范围怎么定，专题怎么拆。
- **7.3.2 归纳、比较与评述**：每个专题里的文献怎么写，写成一段有归纳、有比较、有评述的文字。
- **7.3.3 从阅读卡片到综述初稿**：怎么把零散的阅读笔记组装成一份可以直接修改的初稿。

## 7.3.1 任务、范围与专题划分

### 文献综述回答四个问题

1. 这个研究问题为什么会出现？它的学术来路是什么？
2. 学界已经研究了什么？有哪些代表性成果、共识与转折？
3. 不同研究之间有哪些共同点、哪些分歧？分歧出在哪（样本、数据、度量还是方法）？
4. 还留下什么缺口？这个缺口正好是本研究的切入点。

四个问题中，第四问最关键。只写到第三问的综述，是“资料整理”；写到第四问的综述，才是研究的准备。

### 三个最容易踩的坑

课件把最常见的三类问题点得很直白：

| 问题 | 表现 | 后果 |
| --- | --- | --- |
| 字数与查重 | 综述写成逐篇摘要的拼接，原文语句直接搬过来 | 篇幅上去了，重复率也上去了，属于“无效字数” |
| 格式不规范 | 引注格式前后不一致，有的用著者—出版年，有的用脚注，作者、年份、刊名残缺 | 显得不专业，给评委留下态度上的负面印象 |
| 只有综没有述 | 通篇“某某研究了某某”，不归纳、不比较、不评价 | 读十段等于读一段，看不出你的判断力 |

::: warning 查重的根源在综述的写法
综述查重高，通常不是因为“看了别人的文章”，而是因为**写法是搬运式**的。解决办法不是把句子改得面目全非（那反而更难读），而是先归纳再落笔：合上文献，用自己的话说一遍共识，然后再回头补注具体是谁说的。合不上书就写不出自己的话，这是写作的常识。
:::

### 先定范围：材料、时间、语言、来源

动笔前用一句话交代综述的范围，既约束自己，也让评委知道你的检索是有边界的：

- **材料范围**：以学术期刊论文为主，学位论文、研究报告、政策文件为辅
- **时间范围**：近五年为主，涉及制度沿革时可回溯到关键年份
- **语言范围**：中英文文献，并说明两者如何分配
- **来源范围**：中文以知网、万方等为主，外文以 Web of Science、ScienceDirect 等为主

检索的具体做法见第四、第五部分；这里只需要交代结果——检索了哪些库、用什么关键词、最终纳入多少篇。这一句话交代清楚，后面如果评委追问“有没有漏掉某支文献”，你也有据可答。

### 三种组织方式

| 组织方式 | 适用情况 | 风险 |
| --- | --- | --- |
| 按专题 | 最常用。围绕概念、变量、机制、行业、地区或问题拆分 | 专题划分失当会造成重复；只有一个专题则会写成“一节到底” |
| 按国内外 | 国内外研究传统、数据与方法差异明显的主题 | 容易变成“国外三条、国内三条”的并列，缺少比较 |
| 综合组织 | 先按专题，再在专题内部比较国内外 | 对写作能力要求较高，但效果最好 |

课件给出的建议是：**按专题比较推荐，把国内外结合起来更好。**

### “X 对 Y 的影响”型：三种拆法

如果你的题目是“X 对 Y 的影响”，专题可以按下面三条路拆。三条路不是互斥的，可以按需组合。

![文献综述的两种专题划分思路](/images/opening/o03-review-topics.svg)

*图 7-3　两类选题的专题划分思路*

**拆法一：分两头——X 的经济后果 + Y 的影响因素。**

- X 的经济后果研究
- Y 的影响因素研究
- X 对 Y 影响的机制研究
- 文献评述

这是最稳妥的一种。它天然覆盖了研究的两端，缺口也就自然出现在“两头之间的连接处”。

**拆法二：具体问题具体分析，按研究对象的特点调整。**

- 如果 X 或 Y 是一个新的研究范畴，可以先梳理“X（或 Y）的定义与度量”
- 如果你要研究的影响机理与别人不同，可以专门总结“X 对 Y 的影响机制”
- 如果 X 对 Y 的影响属于某一支大类文献（例如“X 对企业创新的影响”属于“X 对企业行为的影响”），可以先总结这一支大类文献，再收缩到你的具体问题

**拆法三：上位概念切入。** 当 X 和 Y 的关系已经有很多研究时，先把它们归到一个上位概念下（例如把“最低工资标准”“环保规制”“劳动合同法”都归到“劳动保护”或“环境规制”），从上位概念的文献讲起，再逐步收窄到你的具体变量。这样写，综述的层次感会明显增强。

::: details 范例：按“两头 + 机制 + 评述”拆专题（《环保费改税对企业数字化转型的影响研究》）

**二、国内外研究现状、发展动态**

**（一）环保费改税的经济研究后果**——X 这一端：从宏观制度层面（产业结构、能源效率、区域发展）写到微观企业层面（投资行为、创新机制、企业绩效）。

**（二）企业数字化转型的影响因素研究**——Y 这一端：归纳为政策与制度环境、金融与资源支持、企业组织内部特征三个层面。

**（三）环境规制影响企业数字化转型的机制**——把两头接起来：成本约束与资源挤出、创新补偿与倒逼、融资约束与信息披露、动态能力与战略响应四条机制。

**（四）文献评述**——指出两个领域各自成熟、但结合起来的系统性研究不足，为自己的研究开门。

::: tip 这个框架好在哪
（一）（二）分别对应 X 和 Y，（三）是两者的交叉，（四）是收束。四节之间是递进关系，不是并列关系。评委读完前三节，自己就能预判出缺口在哪——这就是结构写通了的标志。
:::


### “某问题/对策”型：由大到小拆

如果你的题目是“L 市 A 行业增值税税收风险管理研究”这类问题与对策型选题，专题不能按“两头”拆，而要**对题目里的限定词逐层收缩，由大到小**：

1. 税收风险管理的相关研究（大概念）
2. A 行业税收风险管理的相关研究（行业限定）
3. 增值税税收风险管理的相关研究（税种限定）

三层收缩完，你的研究对象正好落在这三层的交集上，缺口也就清楚了。

同样地，如果题目是“房地产税某某问题/对策研究”，可以从研究视角切分：

1. 可行性研究
2. 态度/动机研究
3. 效应研究

::: warning 限定词不是随便加的
“L 市 A 行业增值税税收风险管理”这个题目里有四个限定词：地域、行业、税种、问题域。每加一个限定词，专题就应该多收缩一层。如果综述里只写了“税收风险管理研究”和“增值税研究”，却完全没有出现 A 行业的内容，说明你的专题划分没有跟上题目的限定。
:::

### 国内外分述与结合

如果采用“国外 + 国内”的组织方式，同样要有条理，不能变成两段流水账：

1. **按专题分点列示**：国外也分专题，国内也分专题，而不是笼统地按时间或按作者罗列。
2. **单独成段，每段有一句总起或总结**：一段讲一个专题，段首或段末点明这一段的结论。
3. **国内外的专题要大致相似**：这样才便于比较。“大致相似”不代表完全一样，可以各自增加专属内容——例如国外关注的问题与国内不同，或者国内特有的制度背景。

把两者结合起来，就是“综合组织”：先在每个专题内部比较国内外，再在最后一段总结共识与分歧。

### 引注格式：著者—出版年制

推荐使用**著者—出版年制**，句子中直接带出作者与年份，读起来连贯：

- 两位中文作者用“和”连接：黄纪强和祁毓（2022）……
- 三位及以上中文作者用“等”：于连超等（2022）……
- 外文两位作者用 and：Li and Chen（2022）……
- 外文三位及以上用 et al.：Liu et al.（2022）……
- 多个文献并列时按年份排列，用分号隔开：（王杰和王军，2025；钱雪松等，2025）
- 转述加括注，直接引用加引号并标注页码

::: tip 中英文数据库的用法分工
国内文献主要通过知网、万方等获取，观点通常可以从摘要、引言和结论三处快速归纳。外文文献可以先用 Bing 学术（<https://www.bing.com/academic>）、百度学术（<https://xueshu.baidu.com/>）或 Google 学术（<https://scholar.google.com/>）找到线索，再回 Web of Science 或 ScienceDirect 核对出处。学术搜索引擎的结果会混入预印本、书籍章节和非同行评议材料，作为线索可以，作为引用来源时需要回到原始数据库核实。全文获取的具体途径见 5.3。
:::

## 7.3.2 归纳、比较与评述

专题划分确定之后，接下来是逐个专题把文献写进去。这一步的差别，直接决定了你的综述是“资料整理”还是“研究准备”。同样读三十篇文献，有人写出来是一条脉络，有人写出来是三十条摘要。

### 三个动词：综、述、评

一份合格的综述，同时包含三种动作：

- **综**：归纳。把观点相近、方法相近或结论相反的研究归到一处，说明这个专题的发展、共识与转折。
- **述**：说明。讲清楚这些研究用的是什么数据、什么方法、什么证据，而不是只给结论。
- **评**：评价。指出已有研究在理论、数据、范围、机制或方法上的不足，并说明这些不足与本研究的关系。

只有“述”的综述，是把文献的摘要抄了一遍；只有“综”而没有“述”，读者不知道结论：为什么成立；缺“评”，就少了从文献到自己研究的桥。

### 归纳的两种写法

课件把两种写法摆在一起对比，差别非常直观。

**写法一（最简单、但不推荐）**：谁 + 研究了什么 + 怎样研究 + 得出什么观点。这是罗列式写法：

> xxx（2014）利用 xxx 的数据，使用 xx 方法，研究发现……；xxx 等（2020）……

这种写法每一条单独看都没错，但读完之后，读者拿到的是清单，不是判断。十篇文献写十句，一百篇文献就要写一百句——而且极容易被判定为“只有综没有述”。

**写法二（推荐）**：先合并同类观点，再有层次、有逻辑地展开：

> 针对这一问题，学者进行了广泛深入的研究，但得到的结论却不相一致。xxx（2014）、xxx 等（2020）分别使用……和……的数据，实证研究发现……具有积极影响；但 xxx（2022）则发现了相反的结论，即……存在负向影响。

两句话写完了三篇文献，而且交代了共识、分歧、数据差异和结论方向。信息密度完全不同。

### 合并同类观点的三个可操作技巧

**技巧一：相同结论合一句。** 把结论方向一致的研究并列在一起，用“分别使用……和……的数据，均发现……”这类句式合并，只在需要区分样本或方法时才单独点名。

**技巧二：用承接词串起脉络。** 用“已有研究主要从……展开”“在此基础上”“然而”“与之相反”“进一步”这类词，把不同研究之间的关系显性化。读者顺着承接词就能看出研究是怎么推进的，而不是靠你自己在心里排序。

**技巧三：用上位概念统摄。** 当多篇文献的 X 或 Y 名称各不相同、但实质上属于同一类时，先抬到上位概念再收窄。课件举的例子是一个很好的示范：一篇研究《最低工资标准的上涨是否会加剧企业避税？》的综述，把“最低工资标准上涨”“劳动合同法实施”“环保规制强化”这些看起来不相干的研究，都归到**劳动保护**这一上位概念下，再讨论它们对企业行为的影响。这样一来，综述的层次立刻从“若干个案”上升到“一类现象”。

::: tip 一个 X 可以有很多个 Y
如果你的 X 只被研究过很少几次，看看同一支文献里有没有别的 Y。例如 X 是某项税收优惠，Y 可以是企业创新、投资、融资、避税、就业……把这些 Y 的研究合起来，就是“X 的经济后果研究”这一专题。孤立的 X 往往撑不起一个专题，但“X 的后果”可以。
:::

### 分歧要写出来，而且要说清分歧在哪

有分歧的专题，恰恰是最有价值的专题，因为分歧本身就是缺口。写分歧不要只写“有学者认为 A，也有学者认为 B”，要交代差异的来源：

| 分歧来源 | 常见表述 |
| --- | --- |
| 样本差异 | 前者以制造业上市公司为样本，后者以服务业企业为样本 |
| 时期差异 | 政策初期与政策成熟期的效应方向可能不同 |
| 度量差异 | 前者用年报文本词频度量，后者用问卷量表度量 |
| 方法差异 | 前者用双重差分法，后者用工具变量法，识别的效应不同 |
| 条件差异 | 效应在企业规模、产权性质、地区之间存在异质性 |

把分歧归因到具体来源，你的综述就有了研究意义上的信息量——而且这往往就是第三部分研究假设的由来。

### 文献评述怎么收尾

评述是综述的最后一段，也是与第三部分衔接的关键一段。它要做两件事：**指出不足**，**介绍自己**。

不足可以从五个维度去找：

1. **理论上的不足**：概念界定不清、机制解释不完整
2. **数据上的不足**：样本期过短、样本范围有限、缺微观数据
3. **研究范围上的不足**：只研究了某地区、某行业，结论能否推广存疑
4. **机制上的不足**：只验证了“有没有影响”，没说明“通过什么影响”
5. **方法上的不足**：识别策略不够干净，内生性处理有限

写完不足，紧接着交代：本研究打算研究什么、怎么做、为什么这样做。这三句就是第三部分的预告。

### 范例

以下三段摘自参考模板的文献综述部分，分别示范合并归纳、分层归纳和评述收尾。

::: details 范例一：分层归纳（影响因素类专题）

**（二）企业数字化转型的影响因素研究**

企业数字化转型作为一项系统性工程，其进程与成效受到多重因素的复杂影响。通过对现有文献的梳理，可将这些影响因素主要归纳为以下三个层面：政策与制度环境、金融与资源支持以及企业组织内部特征。

首先，政策与制度环境构成了驱动企业数字化转型的关键外部框架与激励机制。宏观层面的国家政策，如国家创新型城市试点、科技金融结合试点以及信息消费试点等，均通过提供战略指引、资源倾斜和降低不确定性，显著促进了企业数字化进程（王杰和王军，2025；钱雪松等，2025；韩律和吴丽芳，2025）。……其次，充足的金融支持与关键资源获取是企业实施数字化转型不可或缺的物质基础。……最后，企业自身的组织内部特征是决定其数字化转型意愿、能力与路径的内在核心。

::: tip 这段好在哪
用“首先、其次、最后”三个承接词搭起三个层面，每层第一句都是总起句，先说清楚这一层是什么，再给文献证据。括号里一次并列三篇文献，而不是一句一引，这是“合并同类观点”的标准做法。
:::



::: details 范例二：平行归纳 + 分歧呈现（机制类专题）

**（三）环境规制影响企业数字化转型的机制**

综合来看，环境规制可能通过成本约束、创新补偿、融资约束与信息披露、动态能力等渠道，对企业数字化转型产生复杂影响。

第一，成本约束与资源挤出机制。环保费改税将环境外部性内化为企业成本，短期内可能加剧企业资金压力，挤占数字技术研发与应用投入。……

第二，创新补偿与倒逼机制。根据“波特假说”，环境规制可能激发企业创新，通过工艺创新降低合规成本、通过产品创新开拓市场空间，最终提升生产率（杨洁等，2022）。……

::: tip 这段好在哪
四条机制用“第一、第二、第三、第四”并列，每条机制内部都是“机制名称 + 作用逻辑 + 文献证据 + 一句小结”。四条机制其实对应着四种相反的预测（抑制、促进、间接、条件），这就把“学界存在分歧”这件事写实了，而不是空喊一句“结论尚不一致”。
:::



::: details 范例三：评述与收尾

**（四）文献评述**

通过对现有文献的梳理，可以发现，当前研究在“环保费改税”和“企业数字化转型”这两个重要领域已分别取得了丰富成果，但将两者结合探讨的系统性研究尚显不足，这为本研究提供了契机。一方面，围绕环保费改税的经济后果，学术界已形成基本共识。……然而，现有探讨多将企业的应对策略导向传统的污染治理与设备升级，或笼统地视为技术创新，而对于数字化转型这一更具根本性的战略变革路径，关注相对有限。另一方面，关于企业数字化转型驱动因素的研究则构建了不同的分析视角。……而对于像环保费改税这种带有强制性约束和成本压力的政策，如何作为一种外部“推力”影响企业数字化转型决策，则缺乏深入探讨。综上所述，现有研究虽对环保费改税与企业数字化转型分别进行了较为深入的探讨，但尚未将二者置于同一框架下进行系统分析，研究视角存在一定割裂。因此，本研究尝试建立连接，系统考察环保费改税这一环境规制政策对企业数字化转型进程的影响。

::: tip 这段好在哪
先用“一方面……另一方面……”分别指出两端的不足（一端太关注传统应对策略，另一端只关注鼓励性政策），再用“综上所述”收束到同一个缺口（两者割裂），最后一句直接给出本研究要做什么。不足、缺口、研究内容三段合一，与第三部分自然衔接。
:::

## 7.3.3 从阅读卡片到综述初稿

前两小节讲了专题怎么拆、段落怎么写。这一小节解决最后一个问题：怎么把零散的阅读笔记，变成一份可以直接拿去修改的初稿。核心办法只有一句话——**先做卡片，再拼段落**。

### 阅读卡片：每篇文献至少记录六项

读文献时不要只画线，也不要只写“这篇挺好”。每篇文献至少记下六项，缺一项就可能要在写作时重新翻原文：

| 字段 | 记录内容 |
| --- | --- |
| 作者与年份 | 与文末参考文献一致，供引注使用 |
| 研究问题 | 这篇文章要回答什么，一句话 |
| 数据与样本 | 用了什么数据、覆盖什么时期、样本量多大 |
| 方法 | 用了什么识别策略或分析工具 |
| 核心结论 | 结论的方向和条件，不要只写“有影响” |
| 证据句与页码 | 可以直接引用或转述的关键句，标明页码 |

如果用了 Zotero，这六项可以直接落在条目的“笔记”里：一句话概括结论，再用引文功能把关键句摘出来，页码会一并保留（做法见 6.6）。这样做的好处是，写作时你把 Zotero 的笔记列表摊开，专题内部的文献就能按结论自动排在一起。

::: tip 区分“原文观点”和“自己的判断”
卡片上最好用两种标记区分：原文说了什么（可引用、可核查），以及你读完后的判断（这篇的不足在哪、和自己研究的关系是什么）。第二种内容不会出现在综述的正文里，但它是你写“评”那部分时的素材。两者混在一起，写作时容易把自己的推测当成别人的结论写进综述。
:::

### 从卡片到段落：三步法

1. **按专题归档**：把卡片按 7.3 划分的专题分组，一组对应一段或几段。
2. **组内排序**：每个专题内部，按“共识 → 分歧 → 推进”排序，而不是按发表时间机械排列。发表时间只在说明研究演进时才有意义。
3. **写总起与收束**：先写这一段的总起句（这一专题研究了什么、达成什么共识），把卡片的内容按顺序填进去，最后写一句收束（这一专题还留下什么问题）。

三步做完，一个专题的段落就成型了。多个专题依次处理，综述的骨架就有了。

### 三种可复用的段落模板

**模板一：共识型**（一个专题内部结论基本一致）

> 围绕【专题】，已有研究主要从【视角/维度】展开。【作者一（年份）、作者二（年份）】分别使用【数据】和【方法】，均发现【共同结论】。这一结论在【另一情境】下也得到了验证（作者三，年份）。可见，【一句话概括共识】。

**模板二：分歧型**（存在相反结论）

> 针对【问题】，学者进行了广泛深入的研究，但结论并不一致。【作者一（年份）、作者二（年份）】基于【数据】的实证研究发现【正向结论】；但【作者三（年份）】则发现【反向结论】。造成这一分歧的原因可能在于【样本/时期/度量/方法差异】。

**模板三：分层型**（影响因素类、机制类专题）

> 综合来看，【对象】受到以下【N】个层面的影响：首先，【层面一】……（证据）；其次，【层面二】……（证据）；最后，【层面三】……（证据）。其中，【层面中的某一点】仍有待进一步检验。

三种模板可以混用。一个专题内部如果既有共识又有分歧，就用模板一打底，用模板二补分歧。

### 组装初稿的顺序

1. **先写各专题的正文段**，不写开头和结尾
2. **再写各专题的总起句和收束句**，检查前后是否衔接
3. **然后写文献评述段**，从各专题的收束句里提炼不足
4. **最后写综述的开头**（交代检索范围与研究问题的来路）

先写中间再写两头，是因为开头需要知道结尾，而结尾只有在正文写完才清楚。反过来写，开头几乎一定要重写。

### 最容易返工的四个地方

| 返工点 | 症状 | 对应处理 |
| --- | --- | --- |
| 专题重复 | 同一个观点在第（一）节和第（三）节都讲了一遍 | 检查专题划分，把交叉内容归到唯一一节，其余处只做引注 |
| 引注与文末不符 | 正文写了某作者，参考文献里没有；或年份对不上 | 用 Zotero 生成参考文献表后逐条核对 |
| 有述无评 | 全是“某某发现”，读不到你的判断 | 补写文献评述段，并确保每个专题的收束句里有一点判断 |
| 与自己的研究脱节 | 综述写得不错，但读不出你要研究什么 | 检查文献评述最后一句，必须交代本研究要做什么 |
