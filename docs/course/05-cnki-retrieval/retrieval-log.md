# 4.7 题录导出与检索日志

## 4.7.1 为什么要导出题录而不是手抄

筛选完成后，要把保留的文献导出成题录（Bibliographic Record）。题录是对一篇文献的结构化描述，包含作者、题名、来源、年份、卷期、页码等字段。手抄题录既慢又极易出错（作者名漏字、卷期写反、页码连字符错误），且无法被文献管理软件直接利用。通过数据库的导出功能生成标准格式题录，是毕业论文文献管理的基本功。

::: warning 题录必须来自导出，不要手敲
凡 plan 引用或列入参考文献的文献，题录必须来自数据库导出或文献管理软件生成，不建议手工录入。手工录入的题录在格式（尤其是 GB/T 7714-2015）上几乎必然存在细节错误，答辩前核对会非常痛苦。
:::

## 4.7.2 选定待读文献：勾选操作路径

在知网结果列表中，导出前需先勾选目标文献。常见三种选择方式：

| 选择方式 | 操作路径 | 适用场景 |
| --- | --- | --- |
| 单条勾选 | 在每条文献前的复选框打勾 | 精挑细选少量文献 |
| 按页全选 | 点击列表上方“全选”复选框 | 整页（通常 20 条）都要 |
| 跨页批量选择 | 勾选后翻页继续勾选，系统保留已选 | 结果分布多页、需汇总导出 |

### 操作步骤（以结果列表页为例）

1. 在检索结果页，逐条浏览，对要保留的文献点击其前的复选框。
2. 若整页都要，点击列表表头左侧的“全选”复选框。
3. 翻到下一页继续勾选，已勾选条目通常会被系统记住（页面顶部显示“已选 N 篇”）。
4. 确认数量无误后，再进行导出。

::: warning 勾选后不要关页面或刷新
勾选后不要急着关闭页面或刷新。知网的已选项在刷新或断网后可能清空，尤其跨页选择时务必在导出完成后再离开页面。以当前版本实际界面为准，“全选”复选框的具体位置可能随布局调整。
:::

## 4.7.3 导出题录的入口与对话框

勾选完成后，通过以下路径打开导出对话框：

1. 确认顶部“已选 N 篇”数量正确。
2. 点击结果列表上方的“导出与分析”（或“导出”）按钮。
3. 在展开菜单中选择“导出文献”。
4. 进入导出对话框，选择目标格式（见 4.7.4）。
5. 点击“导出”或“下载”，得到题录文件或文本。

## 4.7.4 导出格式对照表

知网通常提供多种导出格式，但它们性质不同：有的是“格式化文本”（给人看的参考文献串），有的是“机器格式”（给文献管理软件导入的结构化文件）。必须分清。

| 格式 | 性质 | 给什么用 | 能否被软件直接导入 |
| --- | --- | --- | --- |
| GB/T 7714-2015 | 格式化文本 | Word 中手工粘贴或核对中文参考文献格式 | 否 |
| EndNote | 机器格式 | 导入 EndNote | 是 |
| RefWorks | 机器格式 | 导入 RefWorks | 是 |
| NoteExpress | 机器格式 | 导入 NoteExpress | 是 |
| NoteFirst | 机器格式 | 导入 NoteFirst | 是 |
| BibTeX | 机器格式（若提供） | 导入 Zotero / LaTeX | 是 |
| 自定义 | 半结构化 | 按需选取字段 | 视配置 |
| 查新（引文格式） | 格式化文本 | 查新报告、简单引用 | 否 |

::: tip 给 Zotero 用就优先选 RIS
如果你使用 Zotero（见第 6 章），最方便的做法是导出为 BibTeX 或 RIS（若提供），或直接用 Zotero Connector 浏览器插件一键抓取，避免手工导入。知网页面若提供 RIS 格式，也优先选 RIS，Zotero 兼容性最好。
:::

### 该选哪种格式：按用途决策

若仍不确定导出哪种格式，按下表对照你的当前任务直接选择：

| 你正在做的事 | 应选格式 | 原因 |
| --- | --- | --- |
| 用 Zotero / EndNote 管理文献 | RIS 或 BibTeX / EndNote | 机器格式，软件可解析字段 |
| 在 Word 里手工列参考文献 | GB/T 7714-2015 | 已是规范排版文本，直接粘 |
| 写查新报告或简单引用 | 查新（引文格式） | 知网定制引文样式 |
| 只需部分字段做表格 | 自定义 | 按需勾选字段导出 |

::: warning 机器格式与 GB/T 7714 文本各存一份
同一批文献建议同时导出“机器格式”与“GB/T 7714 文本”两份：前者进文献管理软件，后者留作核对与应急粘贴。不要等到写参考文献时才发现只有一种、且格式不对。以当前版本实际界面为准，部分格式（如 BibTeX、RIS）可能不全部提供，按实际可选项选择最接近的机器格式。
:::

## 4.7.5 关键提醒：机器格式与文本格式不可混用

这是学生最常犯的错误，单独强调：

- **给文献管理软件用的是机器格式**（RIS / BibTeX / EndNote / NoteExpress 等）。这类格式含字段分隔符，软件能解析出作者、年份、标题分别是什么。
- **GB/T 7714 文本是给人看的**。它把文献排成“[1] 作者. 题名[J]. 期刊, 年, 卷(期): 页码.”的样子，适合直接粘进 Word 的参考文献列表，或用来核对格式，但软件无法反向解析它。

::: warning GB/T 7714 文本不能当导入文件
不要把 GB/T 7714 文本当导出文件丢进 Zotero 让它“识别”，Zotero 无法可靠解析纯文本参考文献，会导致字段错乱（作者变题名、年份丢失）。正确流程：软件管理用机器格式导入；最终排版用 GB/T 7714 文本或让 Zotero 按 GB/T 7714 样式生成。
:::

## 4.7.6 导出后必须人工核对的字段清单

即便用机器格式，导出结果也常有字段错误，导入文献管理软件后必须逐条核对以下字段：

| 字段 | 常见错误 | 核对方法 |
| --- | --- | --- |
| 作者姓名与顺序 | 多作者被截断成“等”、顺序错 | 对照原文详情页作者列表 |
| 题名与副标题 | 副标题丢失、标点错 | 对照原文题名全名 |
| 期刊全称 | 用了简称（如“税务研究”误为“税研”） | 核对期刊标准全称 |
| 年份 | 网络首发日期误作出版年 | 以纸质刊期年份为准 |
| 卷（期） | 卷期缺失或错位 | 对照原刊目次 |
| 页码 | 连接符被替换（如“12-20”变“12~20”） | 按 GB/T 7714 用“-” |
| DOI / 网络地址 | DOI 缺失 | 补填或留空，勿编造 |
| 文献类型标识 | 缺失 [J]/[D] 等 | 按类型补标识 |

::: tip 导出后立刻核对三栏
建议导出后立即在文献管理软件中批量浏览一遍，重点看“作者是否完整”“年份对不对”“期刊名是否全称”。这三类错误占导出问题的 80% 以上，早改比写完后统一改省力得多。
:::

## 4.7.7 常见导出问题与处理

| 问题 | 表现 | 处理方法 |
| --- | --- | --- |
| 多作者被截断成“等” | 导出只显示前 3 作者 + 等 | 在导出对话框选择“显示全部作者”或导出后再补全 |
| 中文期刊名用简称 | “财研”代替“财经研究” | 改为期刊标准全称（查期刊官网） |
| 英文题名大小写被改 | 全大写或首字母全大写 | 按原标题大小写修正 |
| 页码连接符被替换 | “12~20”或“12—20” | 统一改为半角短横“-” |
| DOI 缺失 | 题录无 DOI 字段 | 去期刊页或 Crossref 补填，无则不填 |
| 网络首发日期写成出版日期 | 年份早于正式刊期 | 以纸质刊出版年卷期为准，网络首发另注 |

::: warning “网络首发”文献怎么引用
“网络首发”（Online First）文献尚未分配正式卷期页码，知网可能以首发日期填充。引用此类文献时，若学校参考文献规范允许，应注明“网络首发”或待其正式出版后引用；正式出版后须更新卷期页码，不可用首发信息充当已出版信息。
:::

### 导出故障速查表（一页速查）

下表把六类常见问题压缩为一行一动作，供导出后快速对照。若多项同时出现，优先处理“作者、年份、期刊名”三项，因为它们直接影响参考文献是否合格。

| 症状 | 立刻动作 |
| --- | --- |
| 作者只剩“等” | 重新导出并勾选“显示全部作者”，或手工补全 |
| 期刊名是简称 | 查期刊官网改为标准全称 |
| 年份早于实际刊期 | 改为纸质刊出版年，网络首发另注 |
| 页码用了 ~ 或 — | 全替换成半角短横 - |
| 英文题名全大写 | 还原为原标题大小写 |
| DOI 空白 | 去 Crossref 或期刊页补，无则留空 |

::: tip 导出即核对
养成“导出即核对”的习惯：每导出一批，立刻在文献管理软件里扫一遍作者、年份、期刊名三栏。若等几百条文献全部导出后再统一核对，定位和修正成本会成倍上升。
:::

## 4.7.8 导出文件的命名、去重与归档

导出得到的题录文件若不加以组织，很快会与多次检索产生的多个版本混在一起，写作时找不到“最终版”。建议在导出环节就建立命名与归档规范。

### 命名规范

按“日期_主题_格式”命名，避免笼统叫“题录.txt”。示例如下：

| 文件 | 含义 |
| --- | --- |
| `20260312_退税投资_GB.txt` | 2026-03-12 检索“退税+投资”导出的 GB/T 7714 文本 |
| `20260312_退税投资.ris` | 同批文献的机器格式（RIS） |
| `20260315_退税现金流_GB.txt` | 2026-03-15 补充检索“退税+现金流”的文本 |

### 去重

跨多次检索常出现同一篇文献被导出两遍。处理方法：

1. 导入文献管理软件后，用软件的“查重（Find Duplicates）”功能合并。
2. 若手工维护，导出前在筛选表中标记已导出文献，避免重复勾选。
3. 注意同一篇文献可能有“网络首发”与“正式出版”两个版本，保留正式出版版，网络首发版删除或备注。

### 归档结构

建议把检索相关文件放在同一项目文件夹下，与检索日志、筛选表对应：

```
文献检索/
├─ 检索日志.md
├─ 文献筛选表.md
├─ 题录_GB/        （GB/T 7714 文本，用于 Word 粘贴）
├─ 题录_机器/      （RIS/BibTeX，用于软件导入）
└─ 阅读笔记/       （A 档文献的精读笔记）
```

::: tip 两份备份文件的分工
机器格式与 GB 文本建议各存一份，且同名不同扩展名。写作时：用文献管理软件（第 6 章）插入引用并生成 GB/T 7714 参考文献；若临时需要单条文献，从 `题录_GB` 中复制即可，不必重新导出。
:::

::: warning 去重要合并，不要覆盖
去重时不要简单“后导出的覆盖先导出的”。后一次检索可能只导出了子集，覆盖会丢失前一批文献。正确做法是合并而非覆盖，导入软件后统一查重。
:::

## 4.7.9 检索日志的意义与模板

检索日志（Search Log）是记录每一次检索的“实验记录本”。它解决三个问题：避免重复检索同一式子、让检索过程可答辩、为开题报告的“文献检索过程”提供素材。建议每换一次检索式就记一行。

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 日期 | 检索当天 | 2026-03-12 |
| 数据库 | 所用平台 | 中国知网（CNKI） |
| 检索式 | 完整检索式 | SU='留抵退税' AND SU='投资' |
| 限定条件 | 时间/文献类型/学科等 | 2015–2025，期刊 |
| 结果数 | 命中条数 | 86 |
| 保留数 | 纳入精读数 | 12 |
| 新发现关键词 | 本次新出现的相关词 | 现金流、固定资产投资 |
| 下一步动作 | 后续计划 | 补“现金流”同义词重搜 |

::: details 展开：检索日志填写注意事项
- 检索式要写“完整可复现”的版本，包括字段限定（SU=主题、FT=全文等）与逻辑符，不能只写“搜了留抵退税”。
- “新发现关键词”是日志最有价值的一栏，它直接驱动下一轮检索，也是 4.6.5 修正关键词表的依据。
- 日志可用 Excel 或 Markdown 表格维护，建议与文献管理软件的文件夹分类对应。
:::

## 4.7.10 把检索日志写成开题报告里的一段话

开题报告的“文献检索过程”或“研究现状”部分，常要求说明检索了哪些库、用什么策略。可直接由日志提炼成一段连贯文字。

**示例段落（约 150 字）：**

> 本研究以中国知网（CNKI）为核心检索平台，检索时间范围为 2015 年 1 月至 2025 年 12 月，文献类型限定为期刊论文与学位论文。以“留抵退税”“增值税留抵退税”“退税”为主题词，分别与“企业投资”“固定资产投资”“现金流”组配检索，初步获得相关文献 200 余篇；经逐条阅读标题与摘要，剔除纯政策速递、研究对象不符及重复文献后，保留直接相关文献 23 篇、背景与方法相关文献 41 篇。在此基础上，沿关键文献的参考文献与引证文献追溯，补充经典与最新研究 15 篇，最终形成本研究文献基础。

::: tip 示例数字要换成你自己检索到的
这段示例中的数字（200、23、41、15）仅为写法示范，实际写作必须填你真实检索得到的数值，不得照搬。检索日期也须写明，保证可复现。
:::

## 4.7.11 提交成果：文献检索与筛选表

本课程阶段成果应包含一份“文献检索与筛选表”，建议字段如下：

| 字段 | 说明 |
| --- | --- |
| 序号 | 文献编号 |
| 题名 | 完整题名（含副标题） |
| 作者（年） | 第一作者及出版年 |
| 来源 | 期刊名或授予单位 |
| 类型 | 期刊 / 学位论文 / 其他 |
| 相关性类别 | 直接相关 / 背景 / 方法 / 无关 |
| 优先级 | A / B / C |
| 与选题关系 | 支撑 / 竞争 / 背景 |
| 备注 | 可复用方法、数据来源等 |

该表既是平时作业提交物，也是写作文献综述时的索引。建议与文献管理软件（第 6 章）的标签体系保持一致，避免两套系统对不上。

## 4.7.12 课堂实操

完成以下两项产出：

**任务一：导出两种格式题录**

1. 从 4.5 的筛选结果中选取 10 条文献，在知网结果页勾选（注意跨页保留，见 4.7.2）。
2. 先导出为 **GB/T 7714-2015** 文本格式，保存到 `题录_GB.txt`。
3. 同一批文献再导出为机器格式（RIS 或 BibTeX，若提供；否则 EndNote），保存到 `题录_机器.ris`（或对应扩展名）。
4. 打开两个文件对比：GB 文本是“[1] 作者. 题名[J]…”的人读格式；机器格式含字段标签（如 `TY - `、`AU - `、`TI - `）。确认两者记录的是同一批文献。

**任务二：完成一份检索日志**

按 4.7.8 模板，为你本次检索填写至少 3 行日志（不同检索式各一行），并包含一行填好的示例（日期、数据库、检索式、限定、结果数、保留数、新发现关键词、下一步动作齐备）。

**提交产出：** 两个题录文件 + 一份含至少 3 行的检索日志表格。完成后自查：机器格式文件能否被文献管理软件成功导入且字段无乱码（重点看作者是否完整、年份是否正确）；若导入后作者被截断或年份缺失，回到 4.7.6 重新核对并修正。
