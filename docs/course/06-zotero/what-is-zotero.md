# 6.1 认识 Zotero：它解决什么问题

第 6 章要让你独立走完“用 Zotero 管理毕业论文文献”的完整流程：装软件、把知网和英文库的文献抓进资料库、整理分类、校对题录、做阅读笔记、在 Word 里自动生成参考文献表、做好备份与同步。6.1 与 6.2 解决“为什么用、界面长什么样”，6.3 解决“怎么装”，6.4 至 6.7 解决“怎么抓、怎么管、怎么用”，6.8 解决“怎么备份与协作”。

先从最朴素的问题开始：手工管理文献到底会遇到哪些麻烦，Zotero 又是怎么把这些麻烦逐一消掉的。

## 6.1.1 手工管理文献的六种典型困境

对照下面六种情况，看看自己是否已经踩中。这几乎是所有大四学生写开题报告和初稿时的共同经历。

| 编号 | 典型困境 | 具体表现 | 带来的后果 |
| --- | --- | --- | --- |
| 1 | PDF 文件散落各处 | 文献 PDF 一半在“下载”文件夹，一半在桌面，一半在 U 盘，论文写到第三章时找不到第一篇参考过的政策文件 | 引用时翻遍硬盘，半天找不到原文，甚至凭记忆写引用导致出错 |
| 2 | 文件名混乱 | 下载时系统自动命名为“论文(1).pdf”“新建文件夹 3”“文献.pdf”“未命名.pdf” | 无法从文件名判断内容，排序、检索全部失效 |
| 3 | 题录字段靠手敲 | 参考文献的作者、年份、卷、期、页码、起止页全部手动输入，复制粘贴时漏字、错位 | 参考文献表出现大量格式错误，被导师打回重改 |
| 4 | 引用格式反复改 | 期刊要求 GB/T 7714，学校要求 APA，投会议又要 MLA，每次改格式都重写一遍参考文献 | 同一批文献在不同场景要维护多份，极易版本错乱 |
| 5 | 换设备找不到全文 | 实验室电脑里的文献，回宿舍的笔记本上没有；重装系统后本地资料库丢失 | 写作中断，重复下载，浪费学校数据库的流量额度 |
| 6 | 同学间协作混乱 | 小组分工查阅文献，互相用微信、邮箱发 PDF 和 Excel 题录表，谁更新了哪一版说不清 | 出现重复阅读、漏读，汇总时表格字段对不齐 |

假设你的选题是“增值税留抵退税对制造业企业现金流的影响”。开题前你在知网下载了 40 篇文献，文件名是默认的“论文(1).pdf”到“论文(40).pdf”。写第三章时你想引用其中一篇关于 2019 年留抵退税试点的论文，但 40 个文件名毫无区别，只能逐个打开核对标题，花了 25 分钟才找到。更糟的是，参考文献里你手敲了作者“刘”和年份“2019”，实际应为“刘某某、王某某（2019）”，导师审稿时指出作者名漏了一位。这类事情在手工管理下几乎必然发生。

::: tip 文献到多大规模就该上工具
这六类问题的共同原因是文献规模超过了手工管理的上限，与认真程度无关。参考文献超过 30 篇、涉及中英文多个数据库时，就必须要一个文献管理工具。Zotero 是其中上手最快的一个。
:::

## 6.1.2 Zotero 是什么

Zotero 是一款**免费、开源、跨平台**的文献管理软件，由非营利组织 Corporation for Digital Scholarship 维护，名字源自阿尔巴尼亚语“zotëroj”。

**第一，免费。** Zotero 对个人用户永久免费，没有功能阉割版与付费版的区分。下载、安装、在本机使用全部免费；只有当你需要把资料库同步到云端（Zotero 官方服务器）且本地附件超过 300 MB 时，才需要考虑存储扩容（可购买官方存储，也可用 6.8 介绍的 WebDAV 方案）。对学校没有购买 EndNote 或 NoteExpress 的同学来说，免费意味着零成本上手。

**第二，开源。** 源代码公开。软件不会因为商业公司倒闭而停更；社区（如 Zotero 中文社区）可以针对中文文献场景开发插件和翻译器；数据格式开放，你随时可以把全部题录和附件导出为标准格式，不会被锁在某个软件里。

**第三，跨平台。** 提供 Windows、macOS、Linux 三个系统的安装包，且同一账号下的资料库可以在不同系统间同步。无论用实验室的 Windows 台式机，还是自己的 MacBook，操作流程基本一致。

::: warning 安装包只从官网或中文社区下载
Zotero 官网为 <https://www.zotero.org>，下载页为 <https://www.zotero.org/download/>，官方文档为 <https://www.zotero.org/support/>。安装包只从官网或 Zotero 中文社区 <https://zotero-chinese.com> 下载，不要从来源不明的网盘或论坛下载安装包，以免带入恶意程序或过期版本。
:::

### 6.1.2.1 数据目录：你的文献实际存在哪里

数据目录的位置决定了你能不能防住丢数据。Zotero 主程序在电脑上有两个存放位置：

1. **程序文件**：Zotero 软件本体，默认装在 `C:\Program Files\Zotero`（Windows）或“应用程序”文件夹（macOS），卸载重装不影响你的文献。
2. **数据目录（Data Directory）**：真正存放题录数据库和 PDF 附件的地方，默认在用户文档区，例如 Windows 下为 `C:\Users\你的用户名\Zotero\`。其中 `zotero.sqlite` 是题录索引数据库，`storage` 子文件夹里是按条目编号存放的 PDF 原文。

::: tip 数据目录位置要提前知道
毕业前务必知道自己的数据目录位置（菜单「编辑 → 设置 → 高级 → 文件和文件夹」中可查看“数据目录位置”，不同版本位置略有差异，以当前版本实际界面为准）。重装系统前把整个数据目录复制备份，就能完整恢复文献，比一个个重新下载省事得多。这一点在 6.8 还会展开。
:::

### 6.1.2.2 跨平台的具体含义

“跨平台”对毕业论文写作有实际好处：

1. **同一份数据，三种系统通用**。Zotero 的资料库文件（`zotero.sqlite` + `storage`）不区分系统，Windows 上建的库，复制到 macOS 或 Linux 上直接能用。
2. **操作逻辑一致**。三系统下菜单结构、快捷键（Ctrl 与 Cmd 对应）基本相同，换电脑不必重新学一遍。
3. **同步抹平差异**。登录同一账号后，哪台设备上的改动都会同步到其它设备。
4. **Linux 用户也有完整支持**。Zotero 7 提供 Flatpak、snap 及官方 tarball 等多种安装方式，学校机房若为 Linux 同样可用。

::: warning 跨平台不等于拷文件就能用
跨平台不等于“文件随便拷就能用”。直接复制 `storage` 文件夹而漏掉 `zotero.sqlite`，会导致“有 PDF 却看不到条目”。完整备份必须连数据库一起复制（6.8 详述）。
:::

## 6.1.3 核心术语表

下面这张术语表贯穿全章，建议先读一遍，写作时随时回看。

| 术语 | 英文 | 含义 | 对应到你的论文 |
| --- | --- | --- | --- |
| 条目 | Item | 资料库中的一条文献记录（含题录与附件） | 一篇《税务研究》论文 = 一个条目 |
| 题录 | Metadata | 条目的描述字段：作者、标题、年份、期刊、卷期页等 | 参考文献表里那一行信息的数据来源 |
| 附件 | Attachment | 挂在条目下的文件：PDF、CAJ、网页快照、图片 | 你下载的“留抵退税”原文 PDF |
| 分类 | Collection | 资料库里的虚拟文件夹，仅用于组织视图 | “增值税改革”分类下汇聚相关条目 |
| 标签 | Tag | 打在条目上的彩色关键词，用于横向筛选 | 给某篇打“待精读”“已引用”标签 |
| 群组库 | Group Library | 多人共享的云端资料库 | 与同门共建“文献精读”库 |
| 翻译器 | Translator | 浏览器连接器用来识别某网站并提取题录的规则文件 | 决定知网能否被正确抓取 |
| 连接器 | Connector | 浏览器扩展，负责把网页文献推送给主程序 | 工具栏上那个 Zotero 图标 |

::: details 展开：条目与分类的关系（容易误解）
条目（Item）是真实存在的数据；分类（Collection）只是一个视图。同一个条目可以出现在多个分类里（例如一篇同时讲“增值税”和“制造业”的论文，既在“增值税改革”分类，也在“行业影响”分类），但它本身只存一份。删除一个分类**不会**删除条目，删除条目才会真正消失。所以整理文献时尽管用分类和标签，不必像文件夹那样担心挪动会丢文件。
:::

## 6.1.4 Zotero 的五项核心能力

Zotero 围绕“从网页抓取 → 在本地管理 → 在阅读中批注 → 在写作中引用 → 跨设备同步”这条主线，提供五项核心能力。

| 编号 | 核心能力 | 简要说明 | 税收学论文中的例子 |
| --- | --- | --- | --- |
| ① | 抓取 Capture | 在浏览器里一键把题录（元数据）和部分全文存进资料库 | 在知网检索“研发费用加计扣除”主题，点一下连接器就把 20 篇论文的题录和 PDF 存好 |
| ② | 管理 Organize | 用分类、标签、检索、去重组织海量条目 | 建立“增值税改革”“个税专项附加扣除”两个分类，把 80 篇文献分门别类 |
| ③ | 阅读与批注 Read & Annotate | 内置 PDF 阅读器，支持高亮、便签、笔记 | 在《税务研究》某篇 PDF 上高亮“留抵退税”的定义段落，写一条笔记“可引用于第三章概念界定” |
| ④ | 引用 Cite | 与 Word / LibreOffice / Google Docs 集成，插入引用并自动生成参考文献表 | 写初稿时在正文点“插入引文”，文末参考文献表随引用自动更新，格式锁定 GB/T 7714 |
| ⑤ | 同步与协作 Sync & Collaborate | 跨设备同步、群组库（Group Library）共享 | 用学校机房电脑抓的文献，回宿舍笔记本自动同步；与同门共享一个“文献精读”群组库 |

各项能力的操作入口如下，后面各页会逐步拆解：

1. **抓取**：在浏览器打开知网检索页 → 点工具栏 Zotero 图标 → 选择条目 → 保存（详见 6.4）。
2. **管理**：左栏“新建分类” → 拖条目进去；或右键条目“添加标签”（详见 6.5）。
3. **批注**：中间栏双击 PDF 附件 → 在打开的阅读器里选中文字高亮 → 右侧“笔记”写批注（详见 6.6）。
4. **引用**：Word 里“Zotero”选项卡 → “Add/Edit Citation” → 搜索并插入（详见 6.7）。
5. **同步**：「编辑 → 设置 → 同步」填账号密码 → 点工具栏同步箭头（详见 6.8）。

::: details 展开：五项能力之间的依赖关系
这五项能力有先后依赖：

1. **抓取（①）是起点**。没有条目，后面的管理、批注、引用都无从谈起。所以 6.3 装好工具后，6.4 立即讲抓取。
2. **管理（②）决定效率**。条目一多就必须分类，否则中间栏会变成一长串无法定位的列表。6.5 专门讲资料库组织。
3. **批注（③）沉淀思考**。高亮和笔记是把别人的文献变成自己的论据的关键一步。6.6 讲题录校对与笔记。
4. **引用（④）产出成果**。前三项都是输入，只有引用这一步直接服务于你的论文正文和参考文献表。6.7 讲 Word 集成。
5. **同步（⑤）保障安全**。它贯穿全程，但最容易被忽略，所以 6.8 单独强调备份。
:::

### 6.1.4.1 每项能力的输入与输出

每项能力都有明确的输入和输出，理清这一点有助于排查“为什么某一步没产出”。

| 能力 | 输入 | 输出 |
| --- | --- | --- |
| ① 抓取 | 浏览器中的网页文献（知网、Google Scholar 等） | 资料库中的条目 + 可能的 PDF 附件 |
| ② 管理 | 已存在的条目 | 有序的分类、标签、去重后的干净资料库 |
| ③ 批注 | 条目的 PDF 附件 | 高亮、便签、结构化笔记 |
| ④ 引用 | Word 中的“插入引文”命令 | 正文里的规范引文 + 文末自动生成的参考文献表 |
| ⑤ 同步 | 本地的资料库改动 | 云端及其他设备上的相同内容 |

::: tip 某一步没产出，先查输入
某一步没产出时，先检查输入齐不齐。例如连接器抓不到 PDF，常见原因是缺了学校知网的下载权限（见 6.4 版权提醒），而不是 Zotero 坏了。
:::

### 6.1.4.2 五项能力的优先级

时间有限时，按下面的优先级投入精力最划算：

1. **必掌握**：①抓取、④引用。这两项直接决定“文献进得来、引文出得去”，是毕业论文的硬需求。
2. **强烈建议**：②管理、③批注。文献一多就乱，笔记则是把文献转化为论文论点的关键。
3. **保底**：⑤同步。它不提升写作速度，但防止前四项成果丢失。

学有余力时把②③做扎实，文献综述（第 7 章）的质量会明显提升；只学①④也能把参考文献格式做对，只是管理会粗糙些。

## 6.1.5 Zotero 的四个组成部分

学生最容易搞混的一点是：以为装了 Zotero 主程序就万事大吉，结果在浏览器里找不到抓文献的按钮；或者反过来，装了浏览器里的 Zotero 图标却提示无法保存。原因是 Zotero 由四个相互配合的部分组成，缺一不可。

![Zotero 的四个组成部分](/images/zotero/z21-zotero-components.svg)

*图 6-1 Zotero 的四个组成部分及其分工。*

| 组成部分 | 形态 | 职责 | 只装它会发生的问题 |
| --- | --- | --- | --- |
| Zotero 主程序 | 桌面软件（Windows / macOS / Linux） | 管理本地资料库：存储条目、分类、标签、附件、笔记 | 单独运行只能手动“新建条目”手敲字段，无法从网页一键抓取，效率极低 |
| Zotero Connector（浏览器连接器） | 浏览器扩展（Chrome / Edge / Firefox 等） | 在网页上识别文献，把题录和全文“推”给主程序 | 单独装了却无处可放，点击保存会提示找不到 Zotero，或在网页端生成一个无法使用的收藏 |
| 文字处理器插件 | Word / LibreOffice / Google Docs 里的“Zotero”选项卡 | 在论文中插入引文、生成和更新参考文献表 | 没装则论文里只能手敲引用，无法自动生成参考文献表 |
| Zotero 账号与云同步 | 云端账号 + 本地设置 | 跨设备同步条目与附件、提供备份、支持群组库协作 | 不登录账号则资料库只在当前电脑，换设备、重装即丢失 |

::: warning 三件套的最低组合
“主程序 + 连接器”是抓取文献的最低组合；“主程序 + 文字处理器插件”是写论文的最低组合；“主程序 + 账号同步”是防丢失的最低组合。本课程要求三件套齐装：主程序、连接器、文字处理器插件，并注册账号开启同步。文字处理器插件的安装通常在首次启动主程序时自动提示，若未提示可在「编辑 → 设置 → 引用（Cite）」中重新安装（不同版本菜单位置略有差异，以当前版本实际界面为准）。
:::

### 6.1.5.1 四部分的安装顺序建议

四部分虽可独立下载，但按下面的顺序装，能减少“点了保存却提示找不到 Zotero”这类报错：

1. **先装主程序**：它负责创建数据目录、在系统中注册本地服务，是其它部分运行的基础。
2. **再装浏览器连接器**：安装时连接器会检测本机是否已有主程序在运行；主程序开着，连接器才能把数据推过去。
3. **接着确认文字处理器插件**：首次启动主程序通常会弹出安装提示；若错过，在「编辑 → 设置 → 引用」中重装（不同版本位置略有差异，以当前版本实际界面为准）。
4. **最后登录账号开启同步**：账号不影响抓取和引用，但建议尽早登录，避免资料库只在单台电脑。

::: tip 连接器提示 not running 的常见原因
如果安装后点击连接器提示“Zotero is not running”，九成是因为先装了连接器、后装主程序，或主程序没启动。按上述顺序重来一遍即可。
:::

## 6.1.6 与 EndNote、NoteExpress、Mendeley 的对比

下表对比四款主流工具，帮助你理解为什么本课程选 Zotero，也便于将来在导师课题组使用其他工具时快速迁移知识。

| 软件 | 授权方式 | 价格 | 中文文献支持 | Word 集成 | 附件与同步策略 | 协作功能 | 适合的使用阶段 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Zotero | 开源 / 免费 | 免费；云端附件超 300 MB 可购扩容 | 需配合中文翻译器与茉莉花插件，适配较好 | 原生支持 Word / LibreOffice / Google Docs | 本地为主，云同步可选 WebDAV | 群组库（Group Library） | 本科至科研全阶段，尤其适合预算有限、跨平台用户 |
| EndNote | 商业 / 闭源 | 付费，常随学校授权免费给学生 | 对英文数据库适配好，中文需额外配置 | 原生支持 Word | 本地 + EndNote Online 同步 | 共享文库（需授权） | 课题组统一采购、重视 Web of Science 场景 |
| NoteExpress | 国产 / 商业 | 多数高校已购授权，学生免费 | 对知网、万方等中文库适配优秀 | 原生支持 Word / WPS | 本地 + 官方云 | 团队共享 | 以中文文献为主、学校已采购的师生 |
| Mendeley | 商业（曾被 Elsevier 收购，已逐步停更） | 免费版有限制 | 英文为主，中文支持一般 | 原生支持 Word | 本地 + Mendeley 云 | 群组（Mendeley 已收缩服务） | 早期英文用户；新用户不建议作为主力 |

::: tip 选型前先问图书馆
决定用哪款软件前，先问学校图书馆是否已统一采购 EndNote 或 NoteExpress 的校园授权。如果课题组师兄师姐都用 NoteExpress，而你又主要做中文文献，跟随团队习惯能减少协作成本。本课程选 Zotero，是因为它免费、跨平台、对中文文献可用（配合插件）、数据开放可控，最契合学生个人独立完成毕业论文的场景。
:::

### 6.1.6.1 选型小结：本校环境优先

若图书馆已购 NoteExpress 且你只做中文、用 WPS，跟随学校授权最省心；若你跨平台、想免费长期可用、并可能投英文期刊，Zotero 是更稳的选择。两者方法论互通，学会一个，另一个半天就能上手。

## 6.1.7 为什么选 Zotero：数据格式开放

除免费、跨平台、中文可用、本地可控外，还有一点对毕业论文尤为重要：**导出格式开放**。Zotero 不把你的文献锁死在私有格式里，随时可整库导出为标准格式，便于迁移和应对不同投稿要求。

| 导出格式 | 用途 | 什么时候用 |
| --- | --- | --- |
| BibTeX (.bib) | LaTeX 写作、多数英文期刊投稿 | 用 Overleaf 写论文，或投支持 BibTeX 的期刊 |
| RIS (.ris) | 通用题录交换 | 把文献发给用 EndNote / NoteExpress 的同学 |
| CSL JSON | 引用样式语言生态 | 配合 Pandoc、Typora 等写作工具 |
| CSV | 表格查看 | 想用 Excel 批量核对作者、年份字段 |

::: tip 答辩后导出 BibTeX 与 RIS 留存
毕业答辩后，把整个资料库导出一份 BibTeX 和一份 RIS 留存。将来读研或工作时换软件，这批文献无需重新录入。这是开源软件相比闭源商业软件最实在的好处。
:::

### 6.1.8.1 校外访问的两种常见方式

多数高校为知网等数据库提供两种校外访问途径：

| 方式 | 原理 | 对 Zotero 的影响 |
| --- | --- | --- |
| WebVPN / 浏览器代理 | 在浏览器里访问学校提供的代理地址，再进入知网 | 浏览器处于认证态，连接器可正常抓取；注意 PDF 下载也走代理，速度取决于代理 |
| CARSI / 机构登录 | 知网首页点“机构登录”，选本校，用学号密码或统一身份认证跳转 | 无需装客户端，登录后当前浏览器会话即认证；最推荐，与连接器配合最顺 |

::: tip 判断认证是否成功的最简办法
判断认证是否成功的最简办法：在浏览器里打开一篇知网文献，看能否直接点开或下载 PDF。能下载，说明 Zotero 连接器也能下；不能，则问题在权限而非软件。
:::

## 6.1.9 关于 Zotero 的四个常见误解

| 误解 | 真相 | 正确预期 |
| --- | --- | --- |
| “装了就能自动抓所有网站” | 连接器靠翻译器识别网站，小众或改版频繁的网站可能不支持 | 主流数据库（知网、Web of Science、Google Scholar）支持好；冷门网站可能需手敲 |
| “插件是 Zotero 官方出的” | 茉莉花、中文翻译器都是社区维护，非官方 | 安装前认准官方仓库（见 6.3），大版本升级后插件可能需重装 |
| “同步就等于备份” | 同步是跨设备一致，误删也会同步删除；且免费额度仅 300 MB 附件 | 同步之外，仍需 6.8 讲的本地/网盘备份 |
| “Zotero 只适合英文” | 配合中文翻译器与茉莉花插件，中文文献抓取质量明显提升 | 中文为主、英文为辅的毕业论文完全够用 |

::: details 展开：为什么“同步≠备份”值得反复强调
同步（Sync）的作用是让多台设备看到同一份资料库。如果你在笔记本上误删了 10 篇文献，同步会把这个删除也传到云端、再传到台式机，结果是所有设备一起丢。真正能防误删的是备份：把数据目录复制一份到另一个硬盘或网盘，且保留历史版本。两者互补，不能互相替代。6.8 会给出具体备份方案。
:::

### 6.1.9.1 没有 Zotero 与有 Zotero：同一任务的对照

下表把毕业论文中五项高频任务，分别用“手工做法”和“用 Zotero”对照列出。这里只比较操作方式差异，不罗列具体耗时——每个人的手速不同，你只需体会“一次 vs 反复”的差别。

| 任务 | 手工做法 | 用 Zotero 的做法 |
| --- | --- | --- |
| 收集 20 篇知网文献的题录 | 逐篇打开，复制作者、标题、期刊、年份到 Excel，易漏易错 | 在检索结果页点连接器，勾选 20 篇，一次存入 |
| 下载 20 篇 PDF 全文 | 逐篇点“下载”，再手动改名归类 | 连接器或茉莉花批量抓取，附件自动挂到条目 |
| 正文插入一篇引用 | 手敲“（刘某某，2019）”，并确认真实存在 | 搜索条目，点“插入引文”，自动写为规范格式 |
| 把参考文献表从 GB/T 7714 改成 APA | 逐条重排作者、年份、标题顺序，极易出错 | 在 Word 里切换引用样式，整表一键更新 |
| 换一台电脑继续写 | U 盘拷 PDF、重装 Excel 题录表 | 登录账号同步，资料库自动出现在新设备 |

## 6.1.10 Zotero 7 与版本现状

本课程以 **Zotero 7** 为准。Zotero 7 是截至本课件编写时的主流稳定版本，在 PDF 阅读器、附件管理、界面响应速度上较旧版有明显改进，但核心概念（条目、分类、标签、连接器、同步）与旧版一致，这些方法在 Zotero 6 上也同样适用，只是个别按钮文字不同。

需要特别留意的是菜单名称的英文差异：

| 你看到的菜单 | 英文旧称 | 说明 |
| --- | --- | --- |
| 设置 | Settings（Zotero 7）/ Preferences（Zotero 6 及更早） | 中文界面下显示为“设置”，英文界面下 7 代叫 Settings |
| 插件 | Add-ons / Plugins / 扩展 | 不同版本按钮文字不一 |
| 引用 | Cite | Word 集成相关设置所在 |

::: warning 菜单路径均指中文界面
凡本课件中写“菜单「编辑 → 设置 → …」”之处，均指中文界面下的路径。你的 Zotero 若仍是英文界面，对应为“Edit → Settings / Preferences → …”。不同大版本之间菜单位置可能微调，请以你当前安装版本的实际界面为准，不要因为文字略有出入就以为操作错了。每次 Zotero 大版本升级（如 6 升 7）后，第三方插件（茉莉花等）可能需要等待作者适配或重新安装。
:::

## 6.1.11 诚实清单：Zotero 做不到什么

Zotero 也有做不到的事。分清边界，才能把它用在合适的地方。

| Zotero 不是…… | 说明 | 这件事该谁做 |
| --- | --- | --- |
| 写作软件 | 它不负责写论文，只负责管文献和插入引用 | 用 Word / WPS / LaTeX 写正文 |
| 全文搜索引擎 | 它的检索只针对你已抓进资料库的条目，不能替代知网、Web of Science 的库内检索 | 先去数据库检索，再把结果抓进来 |
| 自动摘要工具 | 它不会替你总结文献观点 | 自己读、自己做笔记（见 6.6） |
| 题录纠错神 | 抓取来的字段可能错漏（尤其中文），需人工校对 | 6.6 讲校对方法 |
| 阅读替代 | 内置阅读器能看 PDF、做高亮，但深度研读仍靠你 | 配合批注与笔记 |
| 版权通行证 | 它帮你下载 PDF，但是否合规由使用人负责 | 遵守数据库使用规范（见 6.4 版权提醒） |

Zotero 管的是文献和引用，不管阅读和思考。把精力放在后者上，让 Zotero 接管重复劳动，才是正确的分工。

## 6.1.12 端到端 mini 案例：从检索到引用

一个完整的小案例，把五项核心能力串成一条线。具体操作在后面各页，这里只看流向。

**场景**：你的论文要引用“研发费用加计扣除”政策对高新技术企业的影响，需要抓取 3 篇核心文献并在初稿中引用。

| 步骤 | 动作 | 用到哪项能力 | 落到哪个页面 |
| --- | --- | --- | --- |
| 1 | 在知网检索“研发费用加计扣除 高新技术企业”，得到结果列表 | — | 4.7 / 5.x 检索部分 |
| 2 | 点浏览器工具栏 Zotero 图标，勾选 3 篇，保存到“研发费用加计扣除”分类 | ① 抓取 | 6.4 |
| 3 | 左栏新建“研发费用加计扣除”分类，把条目拖进去；给 1 篇打“已精读”标签 | ② 管理 | 6.5 |
| 4 | 双击其中 1 篇 PDF，高亮政策定义段落，写笔记“用于第二章概念界定” | ③ 批注 | 6.6 |
| 5 | 打开 Word，在正文中点“Add/Edit Citation”插入这 3 篇的引文，文末自动生成参考文献表 | ④ 引用 | 6.7 |

## 6.1.13 从 EndNote / NoteExpress 迁移到 Zotero

如果大二、大三已经用 EndNote 或 NoteExpress 攒了一批文献，不必推倒重来，可以迁移过来：

1. 在原有软件里，把资料库**导出为标准格式**（通常选 RIS，扩展名 `.ris`；EndNote 也可导出 `.enl` 但 Zotero 对 RIS 兼容性最好）。
2. 打开 Zotero，菜单「文件 → 导入」（File → Import）。
3. 在导入向导中选择“RIS/Refer”类格式，定位到刚才导出的 `.ris` 文件，按提示完成导入。
4. 导入后检查：题录字段是否完整、PDF 附件是否跟着过来。附件有时需在原软件里先“嵌入 PDF”再导出，否则 Zotero 只收到题录、收不到全文，需回到 6.4 重新挂附件。

::: warning 迁移后中文文献最常出错
跨软件迁移后，中文文献的字段（作者、期刊名）最常出错，导入后按 6.6 的方法逐条校对。不要把“导入成功”当成“数据正确”。
:::

### 6.1.16.2 常见答疑

1. **问：我电脑很旧，Zotero 7 能跑吗？** 答：Zotero 7 对硬件要求不高，近十年的电脑基本都能流畅运行；若系统过旧（如 Windows 7），可查阅官方文档确认最低系统要求，或继续使用 Zotero 6（核心方法相通）。
2. **问：注册账号要钱吗？** 答：注册 Zotero 账号免费，仅云端附件超过 300 MB 才需考虑扩容，毕业论文阶段通常够用。
3. **问：手机上能用吗？** 答：Zotero 有 iOS / Android 的配套 App，可查看同步过来的条目与笔记，但抓取与批量管理仍以桌面端为主；手机适合路上看摘要，不适合建库。
4. **问：学完这页就能直接写参考文献了吗？** 答：不能。这页只解决认不认识、装不装的问题，真正生成参考文献表要等到 6.7；在此之前请先走完 6.3–6.6。
