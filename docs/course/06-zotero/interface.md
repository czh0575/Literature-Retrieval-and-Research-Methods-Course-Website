# 6.2 Zotero 界面：三栏结构与六个区域

装好 Zotero（安装步骤见 6.3）并首次启动后，你会看到一个由“三栏 + 顶部工具栏 + 左下角标签区 + 右下角预览区”组成的窗口。## 6.2.1 六个区域总览

![Zotero 主界面三栏结构](/images/zotero/z03-main-window.svg)

*图 6-2 Zotero 主界面的六个区域。①菜单栏 ②工具栏 ③左栏：资料库与分类 ④中间栏：条目列表 ⑤右栏：信息 / 笔记 / 标签 / 相关 ⑥左下角：标签过滤器。*

| 区域 | 名称 | 一句话作用 | 常用动作 |
| --- | --- | --- | --- |
| ① | 菜单栏 | 文件、编辑、视图、工具、帮助，放全局命令 | 文件→导入/导出、编辑→设置、工具→插件 |
| ② | 工具栏 | 常用按钮：新建条目、新建分类、添加附件、同步、搜索 | 新建条目、新建分类、添加附件、同步、搜索 |
| ③ | 左栏 | 资料库与分类的树状结构，决定“看哪一组文献” | 我的文库、分类、重复条目、未分类条目、回收站 |
| ④ | 中间栏 | 当前范围的条目列表，逐条显示题录摘要 | 单击选中、双击打开、Ctrl/Shift 多选 |
| ⑤ | 右栏 | 选中条目的详细信息、附件、笔记、标签、相关 | 信息、摘要、附件、笔记、标签、相关 |
| ⑥ | 左下角标签过滤器 | 按标签横向筛选当前条目 | 点标签筛选、Ctrl 叠加、清除筛选 |
| 预览区 | 右下角 | 不打开 PDF 就能瞄一眼摘要或附件 | 选中条目后自动显示 |
| 布局切换 | 视图→布局 | 切换三栏 / 两栏 / 单栏 | 屏幕窄时选两栏 |
| 列排序 / 列定制 | 中间栏列标题 | 排序与增删列 | 点击排序；右键勾选字段 |

::: tip 左栏选范围，中间选条目，右栏改细节
记住一个心智模型：**左栏选“范围”，中间栏选“条目”，右栏看“细节”**。任何一次操作基本都遵循“先在左栏定位分组 → 在中间栏点中条目 → 在右栏编辑字段”的顺序。后面 6.4 抓取、6.5 整理都会反复用到这个模型。
:::

## 6.2.1 区域① 菜单栏

菜单栏位于窗口最顶部，包含五个一级菜单。下表列出每个菜单下最常用到的命令。

| 菜单 | 常用命令 | 作用 | 何时用到 |
| --- | --- | --- | --- |
| 文件 File | 新建文库 / 新建分类 | 建立资料库或子分类 | 开始建“我的论文”分类时 |
| 文件 File | 导入 / 导出文库 | 从 RIS、BibTeX 等导入，或整库导出备份 | 迁移旧库（6.1.13）、备份（6.8） |
| 编辑 Edit | 设置（Settings / Preferences） | 改语言、账号、引用样式、数据目录 | 改中文、登账号、装插件 |
| 视图 View | 布局（Layout） | 切换三栏 / 两栏 / 单栏 | 屏幕小想多看 PDF 时 |
| 工具 Tools | 插件（Add-ons） | 安装 / 管理茉莉花等插件 | 6.3 装中文插件 |
| 帮助 Help | 文档 / 关于 | 打开官方文档、看版本号 | 报错时查文档 |

::: warning “设置”在不同版本的名字
“设置”在不同版本叫 Settings（Zotero 7）或 Preferences（Zotero 6 及更早），中文界面统一显示“设置”。菜单项文字以你当前版本为准；若找不到某项，先确认是否装了改变界面的插件，或升级到了不同大版本。
:::

## 6.2.2 区域② 工具栏

工具栏在菜单栏正下方，是日常最高频点击的一排按钮。下表按从左到右顺序说明。

| 按钮（图标特征） | 名称 | 点击后发生什么 | 对应流程 |
| --- | --- | --- | --- |
| 绿色加号（可长按） | 新建条目 | 弹出条目类型菜单，选“期刊论文”等即创建空条目 | 手敲题录时（不推荐，优先用抓取） |
| 黄色文件夹加号 | 新建分类 | 在左栏新建一个分类（虚拟文件夹） | 6.5 整理资料库 |
| 回形针 | 添加附件 | 给选中条目挂 PDF、网页快照或链接 | 6.4 场景 C 挂附件 |
| 便签 / 笔记图标 | 添加笔记 | 在选中条目下新建一条笔记 | 6.6 做读书笔记 |
| 放大镜形状 | 查找可用 PDF | Zotero 尝试为无全文的条目联网找 PDF | 补全文（成功率有限） |
| 绿色旋转箭头 | 同步 | 把本地改动上传 / 下载云端，保持多设备一致 | 6.8 同步 |
| 右侧搜索框 | 快速搜索 | 输入关键词，在当前文库 / 分类内筛选条目 | 随时定位某篇文献 |

::: tip 绿色加号长按可展开条目类型
“新建条目”的绿色加号**长按**会展开条目类型列表（期刊论文、图书、报告、学位论文等）；单击则按上一次的类型快速新建。毕业论文最常见的是“期刊论文”，其次是“学位论文”（硕博论文常来自知网）和“报告”（政策文件、税务总局公告）。
:::

## 6.2.3 区域③ 左栏：资料库与分类

左栏是资料库的“目录树”。最顶端是“我的文库（My Library）”，它下面的每个分类（Collection）都是它的子集视图。

| 节点 | 含义 | 操作提示 |
| --- | --- | --- |
| 我的文库 My Library | 所有条目的总集合，无论归到哪个分类都能在这里看到 | 点它看全部文献 |
| 分类（你自建） | 虚拟文件夹，仅用于组织视图，不复制条目 | 右键“我的文库”→ 新建分类 |
| 重复条目 Duplicate Items | 系统自动识别出的疑似重复条目 | 定期来这里合并（6.5） |
| 未分类条目 Unfiled Items | 还没归入任何分类的条目 | 抓取后忘了归类会堆在这里 |
| 回收站 Trash | 删除的条目暂存处 | 误删可右键“恢复” |

::: warning 从分类移除不等于删除条目
“我的文库”里删除条目 = 真正删除（先进回收站）；“分类”里删除条目 = 只是把它从该分类移除，条目仍留在“我的文库”。新手常误以为“从分类里删了文献就没了”，其实只是取消了归类。要彻底删除，去“我的文库”或“未分类条目”里删，并清空回收站。
:::

## 6.2.4 区域④ 中间栏：条目列表

中间栏列出当前范围（某个文库或分类）下的所有条目，每一行是一条文献。理解各列含义，是后续校对题录（6.6）的基础。

| 列名 | 含义 | 毕业论文中怎么用 |
| --- | --- | --- |
| Title | 文献标题 | 一眼找文献；抓取后常需补全或修正 |
| Creator | 作者 / 编者 | 中文文献用茉莉花拆分姓名（6.3） |
| Year | 出版年 | 按年份排序看最新研究 |
| Publication | 来源出版物（期刊名 / 出版社） | 判断是否为核心期刊 |
| Item Type | 条目类型（期刊论文、图书…） | 类型错会导致字段错，需校对（6.6） |
| Date Added | 加入资料库的时间 | 看哪批是最新抓的 |
| Date Modified | 最后修改时间 | 看最近编辑过哪些 |

中间栏里还有两类小图标，紧贴在标题前：

- **回形针图标**：该条目挂有附件（PDF 或快照）。点击条目后，右栏“附件”标签页可见具体内容。
- **便签 / 笔记图标**：该条目下建有笔记。点开右栏“笔记”可见。

选中条目的几种方式：

1. **单击**：选中一条，右栏显示其信息。
2. **双击**：选中并在右侧（或新标签页）展开详情 / 打开 PDF 阅读器。
3. **Ctrl / Cmd + 单击**：不连续多选，用于批量打标签或归入分类。
4. **Shift + 单击**：从已选第一条到当前条连续多选。

::: tip 批量拖入分类更快
抓完一批文献后，先用 Ctrl 多选、再一次性拖进某个分类，比一条条拖快得多。多选后右键 → “添加到分类”也能实现，不必非用鼠标拖。
:::

## 6.2.5 区域⑤ 右栏：信息 / 摘要 / 附件 / 笔记 / 标签 / 相关

右栏是选中条目的详情面板，顶部有一排标签页。

| 标签页 | 内容 | 用途 |
| --- | --- | --- |
| 信息 Info | 题录字段：标题、作者、年份、期刊、卷期页、DOI 等 | 校对与补全（6.6） |
| 摘要 Abstract | 文献摘要文本 | 快速判断要不要精读 |
| 附件 Attachments | 该条目挂的 PDF、CAJ、网页快照 | 双击打开阅读 |
| 笔记 Notes | 你写的读书笔记 | 6.6 做批注与笔记 |
| 标签 Tags | 该条目自带的标签 | 打“已精读”“待引用”等 |
| 相关 Related | 手动链接的“相关文献” | 建立文献网络 |

::: warning 字段随条目类型变化
右栏显示的**字段会随“条目类型（Item Type）”变化**。例如“期刊论文”有“卷、期、页码、ISSN”，而“图书”有“出版者、出版地、ISBN”，没有卷期页。如果某个字段找不到，先检查右上角条目类型是否选错。把“网页”误当成“期刊论文”是抓取失败（6.4）最常见的后遗症，需到 6.6 改回正确类型，字段才会完整出现。
:::

## 6.2.6 区域⑥ 左下角：标签过滤器

左下角的标签过滤器（Tag Selector）列出当前文库 / 分类中出现过的所有标签，带彩色圆点。它是“横向筛选”：不论文献在哪个分类，只要打了同一标签，就能一起筛出来。

1. 在左下角找到你想筛选的标签（如“已精读”），单击它。
2. 中间栏立刻只显示带该标签的条目；标签旁的计数表示命中条数。
3. 按住 Ctrl / Cmd 再点第二个标签，可叠加筛选（同时满足多个标签）。
4. 取消筛选：再次单击已激活的标签使其变灰，或点左下角“清除筛选”（Show Only 区域的清除按钮，不同版本位置略有差异）。

::: tip 给每篇打一个状态标签
标签是“跨分类”的维度。分类用来回答“这篇属于哪个主题”，标签用来回答“这篇读到哪一步了”。推荐给每篇打一个状态标签：未读 / 已读 / 已精读 / 已引用。这样答辩前用标签过滤器一键筛出“已引用”，就能核对参考文献是否覆盖关键文献。
:::

## 6.2.7 预览区、布局切换与三个高频操作

中间栏与右栏之间、右栏底部还有一个**预览区**（部分布局下显示为“附件预览 / 摘要预览”），选中条目后会显示其摘要或附件缩略图，不打开 PDF 也能瞄一眼。

窗口布局可调整：

1. 菜单「视图 → 布局」（View → Layout）。
2. 在布局子菜单中选择：三栏（默认，信息最全）、两栏（隐藏左栏，专心读）、单栏（仅条目列表 + 阅读器）。
3. 选择后界面立即切换；写论文时若屏幕窄，可用两栏让 PDF 阅读器占更大面积。

::: warning 布局菜单名称因版本而异
布局菜单的准确名称与位置因版本而异，可能叫“Layout”“版面”“显示”等。若「视图」下找不到，可检查是否在“设置 → 常规”里有相关开关，或直接拖动各栏分隔线达到类似效果。以当前版本实际界面为准。
:::

三个高频界面操作：

**调整栏宽。** 把鼠标移到两栏之间的竖分隔线上，光标变成左右箭头时，按住左键左右拖动，即可加宽或收窄某一栏。中间栏太窄看不全标题时，向右拖左栏分隔线即可。

**点击列标题排序。** 在中间栏，点击任意列标题（如 Year）即可按该列排序；再次点击切换升序 / 降序，标题旁出现小箭头指示方向。想按“最新加入”排序就点 Date Added。

**自定义显示哪些列。** 在中间栏任意列标题上**右键**，会弹出列管理菜单：

1. 勾选 / 取消勾选字段，控制哪些列显示（如加上“出版社”“DOI”）。
2. 选“定制列…”（Customize Columns，名称因版本而异）可调整列顺序、宽度、是否固定。
3. 确定后中间栏立即按你的配置显示，配置随资料库保存。

毕业论文阶段，建议在中间栏固定显示 Title、Creator、Year、Publication、Item Type 五列。Item Type 一列能帮你一眼发现被误识别成网页的条目。

## 6.2.8 把界面改成中文

Zotero 默认安装后可能是英文界面（取决于系统语言与下载版本）。改成中文的步骤：

1. 菜单「编辑 → 设置」（Edit → Settings / Preferences）。
2. 在设置窗口左侧选「常规」（General）。
3. 找到「语言」（Language）下拉框，选择“中文（简体）”或“Chinese (Simplified)”。
4. 点击“确定 / OK”，按提示重启 Zotero。
5. 重启后菜单、按钮文字变为中文。

::: warning 插件菜单仍是英文属正常
部分第三方插件（如茉莉花）的菜单项仍是英文，属正常现象，不影响使用。另外，语言选项的具体位置（常规 / 外观 / 高级）在不同版本可能微调；若“常规”里没有“语言”，可到「高级 → 常规」或顶部语言栏查找，以当前版本实际界面为准。改语言后如仍显示英文，确认是否真的点了“重启”，仅关闭窗口不够。
:::

## 6.2.9 右栏“信息”标签页：字段详解

右栏“信息（Info）”是校对题录的主战场（6.6 会专门讲校对）。下表给出税收学论文中的真实填写示例，便于抓到文献后对照检查。

| 字段 | 含义 | 税收学例子 | 校对要点 |
| --- | --- | --- | --- |
| 标题 Title | 文献题名 | “增值税留抵退税对企业投资的影响” | 抓取后偶有断字、缺副标题，需补全 |
| 作者 Creator | 作者，可多人 | 刘某某、王某某（角色选“著”） | 中文文献应拆成独立作者，勿写成“刘某某, 王某某”一长串（茉莉花负责拆分） |
| 日期 / 年份 | 出版年 | 2023 | 与文献实际年一致；年份错会导致排序乱 |
| 出版物 Publication | 期刊 / 出版社名 | 《税务研究》 | 抓取后可能不全，需补全称 |
| 卷 Volume | 卷号 | 43 | 部分期刊有卷 |
| 期 Issue | 期号 | 5 | 与卷、页配合定位 |
| 页码 Pages | 起止页 | 45–58 | 常被漏抓，需手补 |
| DOI | 数字对象标识符 | 10.xxxx/xxxxx | 有则填，便于他人检索 |
| URL | 来源链接 | 知网文章页地址 | 快照类条目才有 |
| 语言 Language | 文献语种 | 中文 / 英语 | 中文文献填“中文” |

::: warning 作者字段最易出错
“作者”字段最易出错。正确做法是每位作者占一行（点字段右侧的“+”添加），角色选“著 / 编 / 译”。若抓取后作者变成“刘某某 王某某”一个整体字符串，说明连接器没识别好，需用茉莉花拆分或手动改（6.6）。把多个作者塞在同一行，会导致参考文献里作者名显示异常。
:::

## 6.2.10 附件的四种形态

右栏“附件（Attachments）”里挂的文件常见有四种形态，处理方式不同。

| 形态 | 来源 | Zotero 内置阅读器能否直接读 | 说明 |
| --- | --- | --- | --- |
| PDF | 知网 PDF 下载 / 拖动识别 | 能 | 首选格式 |
| CAJ | 知网老文献的 CAJ 格式 | 不能直接读 | 需转 PDF（6.4 详述） |
| 网页快照 Snapshot | 连接器抓网页时生成 | 能（视为特殊 HTML） | 含网页截图，适合抓政策公告页 |
| 附件链接 Link | 添加“链接到文件”时生成 | 取决于原文件 | 只记录本机路径，不复制进 storage，换电脑易失效 |

添加附件的入口：选中条目 → 工具栏“添加附件”回形针 → 选“上传文件”（选本地 PDF）、“添加快照”（抓当前网页）、“添加链接”（链接本机文件）。毕业论文建议优先用“上传文件”把 PDF 真正存进资料库，少用“链接”以免换设备丢附件。

## 6.2.11 笔记的两种类型

右栏“笔记（Notes）”用于写读书笔记，分两种：

1. **子笔记（Child Note）**：选中某条目后点工具栏“添加笔记”生成，挂在条目下，随条目走。推荐用这种，因为笔记和文献一一对应，引用时好找依据。
2. **独立笔记（Standalone Note）**：在左栏“我的文库”空白处、不选任何条目时点“添加笔记”生成，独立于条目，适合写“选题思路”“待办清单”等总览性内容。

读完一篇“研发费用加计扣除”的文献，最好在它下面建一条子笔记，记下核心结论、可用数据来源、准备引用的具体段落。这样到 6.7 写正文时，不用重读 PDF 就能直接引用。笔记写法在 6.6 细讲。

## 6.2.12 建立“相关文献”链接

右栏“相关（Related）”标签页可手动把两篇主题相近的文献连起来，形成文献网络，方便对比阅读。

1. 选中条目 A，点右栏“相关”标签页。
2. 点“关联条目”（Link to Item，名称因版本而异）按钮。
3. 在弹出的条目选择器里搜索并选中条目 B，确认。
4. 之后在 A 的“相关”里点 B 可一键跳转；B 的“相关”里也会反向出现 A。

“相关”是手动的，不会自动生成。适合把“同一政策的不同研究”“支持与反对同一结论的文献”成对链接，写文献综述（第 7 章）时很有用。不必每篇都连，挑关键几对即可。

## 6.2.13 标签与分类如何分工

新手常纠结“这篇该建分类还是打标签”。**分类管“主题归属”（树状、相对固定），标签管“阅读状态 / 用途”（平铺、可多变）**。

| 维度 | 分类 Collection | 标签 Tag |
| --- | --- | --- |
| 结构 | 树状，可嵌套子分类 | 平铺，无层级 |
| 一篇文献 | 可同时属于多个分类 | 可同时打多个标签 |
| 典型用法 | 增值税改革 / 个税 / 行业影响 | 未读 / 已精读 / 已引用 / 待补PDF |
| 何时新增 | 主题框架稳定后 | 阅读推进中随时加 |

::: details 展开：一个推荐的分类 + 标签组合
分类（主题）：背景与政策、理论与机制、数据与方法、文献综述素材、待读。
标签（状态）：未读、已读、已精读、已引用、待补PDF。
这样“已精读”且“已引用”的文献，用标签过滤器一键筛出，就能核对参考文献是否覆盖关键文献；而“待补PDF”标签提醒你哪几篇还没下全文。两者配合，资料库既有序又可动态追踪进度。
:::

## 6.2.14 中间栏右键菜单详解

在中间栏条目上**右键**，会弹出常用操作菜单。

| 右键项 | 作用 | 毕业论文场景 |
| --- | --- | --- |
| 添加到分类 | 把条目归入某分类（不移动） | 批量归类 |
| 创建副本 | 复制一条相同条目 | 极少用，易产生重复 |
| 关联 | 建立“相关”链接（见 6.2.12） | 连对比文献 |
| 查找可用 PDF | 联网补全文 | 缺 PDF 时 |
| 添加笔记 | 新建子笔记 | 边读边记 |
| 导出条目 | 导出为 RIS / BibTeX | 发给同学或备份 |
| 删除 | 移到回收站 | 清无用文献（可恢复） |

::: warning “创建副本”与重复条目的区别
“创建副本”会生成一条内容相同但独立的条目，容易和“重复条目”混淆，一般无需使用。若发现资料库里有两条一模一样的文献，去左栏“重复条目”合并，而不是再建副本。
:::

## 6.2.15 左栏里的其他资料库

左栏“我的文库”上方或下方，登录账号后还可能出现两类库：

1. **群组库（Group Libraries）**：你加入或创建的共享库，多人可同时往里加文献，适合与同门共建“文献精读”库（详见 6.8）。
2. **我的出版物（My Publications）**：你本人发表的成果，毕业论文阶段一般用不到。

::: tip 别把文献存进群组库
个人写作业默认都在“我的文库”里操作，不要误把文献存进某个群组库而导致自己“我的文库”里找不到。若左栏出现不认识的库，先确认是不是加入了某个群组。
:::

## 6.2.16 界面快捷键速查

Windows 用 Ctrl，macOS 用 Cmd。

| 快捷键（Win / Mac） | 作用 |
| --- | --- |
| Ctrl+N / Cmd+N | 新建条目 |
| Ctrl+Shift+N / Cmd+Shift+N | 新建分类 |
| Ctrl+E / Cmd+E | 导出选中条目 |
| Ctrl+F / Cmd+F | 聚焦搜索框 |
| 空格 Space | 在预览区打开选中条目 |
| Delete / Backspace | 删除选中条目（进回收站） |
| Ctrl+D / Cmd+D | 为选中条目添加标签（部分版本） |

::: warning 快捷键以菜单标注为准
快捷键因版本与系统不同可能略有差异；若某组合无效，以菜单项旁显示的快捷键为准（Zotero 常在菜单项右侧标注）。macOS 上凡本表写 Ctrl 的，实际多为 Cmd。
:::

## 6.2.17 界面常见问题与处理

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 中文显示成方块 / 乱码 | 系统缺中文字体或语言未切 | 按 6.2.8 切中文并重启；确认系统装了中文字体 |
| 界面字体太小看不清 | 未设置界面缩放 | 菜单「编辑 → 设置 → 外观 / 常规」找缩放项（位置因版本而异）调大 |
| 窗口卡死无响应 | 大资料库正在建索引 | 稍等；仍无响应可强制关闭重开，索引会在后台继续 |
| 右栏不显示字段 | 条目类型（Item Type）选错 | 改成正确的“期刊论文”等，字段即出现（6.6） |
| 左栏分类消失了 | 误切到两栏 / 单栏布局 | 视图 → 布局改回三栏 |
| 标签过滤器为空 | 当前范围无标签 | 确认选了有条目的分类；标签是自动从条目收集的 |

## 6.2.18 初学者最容易认错的几处

| 认错 | 真相 | 后果与纠正 |
| --- | --- | --- |
| 把“分类”当“文件夹” | 分类是视图，不复制条目 | 从分类删文献不会丢数据；真要删去“我的文库” |
| 回收站=彻底删除 | 回收站可恢复 | 误删先去回收站右键“恢复” |
| 图标灰色=软件坏了 | 灰色回形针可能只是“暂无附件” | 不是故障，去右栏“附件”确认 |
| 字段少=数据丢了 | 多为条目类型选错 | 改成正确 Item Type，字段即出现（6.6） |
| 英文界面=装错版本 | 只是语言未切 | 按 6.2.8 改中文即可 |

::: details 展开：用一次完整动作串起六个区域
假设你在知网抓到一篇《税务研究》的论文，现在想整理它：
1. 左栏（③）点“我的论文”分类 → 中间栏（④）出现该条目；
2. 中间栏单击选中 → 右栏（⑤）“信息”显示作者年份；
3. 右栏“标签”加“已读” → 左下角（⑥）标签过滤器多一个可筛选项；
4. 右栏“附件”双击 PDF → 预览区（右下）显示正文；
5. 工具栏（②）点“同步” → 改动上传云端。
:::

## 6.2.19 课堂实操

保证操作时 Zotero 已安装并能打开（安装见 6.3；若还未装，可先读完本页，装好后再回来做）。

1. 打开 Zotero，对照图 6-2，在纸上或用截图标注出六个区域的位置（①菜单栏 ②工具栏 ③左栏 ④中间栏 ⑤右栏 ⑥左下角标签过滤器）。
2. 在左栏“我的文库”上右键 → 新建分类，命名为“我的论文选题”（若已有可不建）；在该分类下用工具栏“新建条目”（绿色加号，选“期刊论文”）建一条空条目；在右栏“信息”里随便填一个标题（如“测试条目”）。
3. 给这条测试条目在右栏“标签”加两个标签：“测试”“未读”；然后到左下角标签过滤器点“未读”，确认中间栏只显示带该标签的条目；再点“清除筛选”恢复全部。
4. 把界面切成中文（若原本是英文）：按 6.2.8 步骤操作，重启后截图菜单栏显示“文件 / 编辑 / 视图 / 工具 / 帮助”。
5. 在中间栏点击列标题“Year”排序一次，再右键列标题勾选“Item Type”列，确认能看到类型列。

::: details 展开：界面练习自查
- [ ] 已能指出六个区域分别在哪里
- [ ] 已新建一个分类并建一条测试条目
- [ ] 已添加标签并用标签过滤器成功筛选、清除
- [ ] 已把界面切成中文（或确认原本就是中文）
- [ ] 已会用列标题排序与自定义列
- [ ] 已保存一张标注了六区域的界面截图
:::

### 6.2.19.1 一张合格截图应包含什么

截图中应能看到①顶部菜单栏（文件 / 编辑 / 视图 / 工具 / 帮助）、②工具栏一排按钮、③左栏“我的文库”及你新建的“我的论文选题”分类、④中间栏里那条测试条目、⑤右栏“信息”显示你填的标题、⑥左下角标签过滤器里出现“测试”“未读”两个标签。六项齐备即为合格。若你还未安装 Zotero，可先保存六区域速查表作为替代产出，安装完成后再补截图。

### 6.2.19.2 常见答疑

1. **问：为什么我的界面和图 6-2 不完全一样？** 答：示意图是典型布局，你的窗口宽度、是否登录账号、装没装插件都会让细节不同；区域位置一致即可，不必逐像素对齐。
2. **问：右栏“相关”和“标签”我暂时用不上，能隐藏吗？** 答：可以。在右栏标签页上右键或拖动分隔线调整；这些标签页只是视图，隐藏不影响数据。
3. **问：误删了条目怎么办？** 答：先看左栏“回收站”，右键“恢复”即可；若已清空回收站则只能从备份或重新抓取恢复（见 6.8）。
4. **问：能不能把界面调成深色？** 答：部分版本在「设置 → 外观」提供主题切换；若没有，以当前版本实际界面为准，不影响功能。

::: warning 菜单路径以当前版本为准
本页所有菜单路径（如「编辑 → 设置 → 常规 → 语言」）均为中文界面下的典型位置。Zotero 不同大版本、是否装有第三方插件，都可能让菜单位置或文字略有差异。若你按图索骥找不到某项，优先确认界面语言与版本号（菜单「帮助 → 关于」可看版本），并以当前版本实际界面为准，不要因文字出入就判定操作错误。
:::
