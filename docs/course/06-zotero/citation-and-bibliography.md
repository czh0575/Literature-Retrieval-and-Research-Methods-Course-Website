# 6.7 Word 引用与参考文献表

## 6.7.1 为什么要在 Word 里插引用而不是手打

写论文时，最省事也最危险的做法，是把“（张三, 2020）”和文末条目一个字一个字手打进 Word。手打引用有三个绕不开的麻烦：

1. **无法批量更新。** 题目、作者、页码一旦要改，得逐条手动改，几十上百条引用改到崩溃。
2. **一变全乱。** 删掉一段引用、调换章节顺序，文末的编号（[1][2][3]）不会自动重排，容易出现“正文引了 5 篇、文末列了 6 篇”的错位。
3. **最容易造成遗漏。** 手打最容易出现“正文引了、文末没列”或“文末列了、正文没引”两类硬伤，而答辩和查重最先抓的就是这种不一致。

用 Zotero 的 Word 插件插入引用，引用和参考文献表都由题录字段生成，改一处、刷新全局。下表对比两种做法：

| 对比项 | 手打引用 | Zotero 插件插入 |
| --- | --- | --- |
| 改作者 / 年份 | 逐条手动改 | 改题录后刷新一次 |
| 删除一段引用 | 文末编号要重排，易错 | 自动重排 |
| 切换引用样式 | 几乎要重写 | 文档首选项一键切换 |
| 是否漏列 / 多列 | 高发 | 由引用生成，不会漏 |
| 100 篇文献的工作量 | 极大且易错 | 插入 + 刷新即可 |

一个实际发生的例子：某同学手打 80 条引用，答辩前删掉两章，文末编号出现“[3][5][7]”跳号，且有两篇正文引用但文末缺失，返工一整天。用插件，这类问题在刷新瞬间消失。

**引用一致性自检表**（无论手打还是插件，交稿前都过一遍）：

| 检查 | 合格标准 |
| --- | --- |
| 正文引用数 = 文末条目数 | 完全一致 |
| 每条正文引用都能在文末找到 | 无一遗漏 |
| 每条文末条目都在正文被引 | 无多余 |
| 编号连续无跳号 | 顺序编码制下尤其重要 |

## 6.7.2 文字处理器插件的安装

安装 Zotero 主程序时，通常会自动安装 Word 插件，Word 顶部出现“Zotero”选项卡。如果打开 Word 后看不到该选项卡，重装步骤如下：

1. 完全关闭 Word（包括后台进程）。
2. 打开 Zotero，菜单「编辑 → 设置 → 引用（Cite）→ 文字处理器（Word Processors）」。
3. 点击“重新安装 Microsoft Word 插件”（或“安装插件”）按钮。
4. 重新启动 Word，顶部应出现 Zotero 选项卡。

**验证安装成功：** 打开任意一个 Word 文档，查看顶部功能区是否有“Zotero”标签页；进入该页，应能看到“Add Citation”“Add Bibliography”“Document Preferences”“Refresh”等按钮。若按钮灰色或缺失，重复上述重装步骤，并确认 Word 版本在 Zotero 支持范围内。若重装多次无效，尝试先卸载 Zotero 再重装（会保留资料库），或查看官方文档 <https://www.zotero.org/support/word_processor_integration>。

::: warning 版本与 Office 界面的差异
不同 Word 版本（含中国香港、中国澳门地区常用的 Office 365 繁体 / 英文界面）选项卡文案可能不同；若上述路径找不到，请以当前 Zotero 版本实际界面为准。使用 WPS 文字处理软件的同学，需先确认所用 Zotero 版本对该 WPS 版本的支持情况，并非所有组合都可用。
:::

## 6.7.3 插入一条文内引用

1. 在 Word 文档中，把光标放到要引用的句子末尾（具体放在句号之前还是之后，按本校学位论文规范执行）。
2. 切换到“Zotero”选项卡，点击“Add Citation（添加引用）”。
3. 首次会弹出“文档偏好（Document Preferences）”让你先选引用样式（见 6.7.7），之后直接进入搜索框。
4. 在搜索框输入作者、年份或标题关键词，从结果里选中正确条目。
5. 确定后，文内出现形如“（张三, 2020）”或“[1]”的引用，它看起来像文字，其实是 Word 域。

假设光标在“加计扣除显著促进了企业创新”句末：

- 插入前：`加计扣除显著促进了企业创新。`
- 插入后（GB/T 7714 著者-出版年制）：`加计扣除显著促进了企业创新（张伟, 2020）。`
- 插入后（GB/T 7714 顺序编码制）：`加计扣除显著促进了企业创新[1]。`

同一篇文献在文中出现多次时，每次都走“Add Citation”选同一文献，Zotero 会自动复用，不会重复生成不同编号。若想删除某处引用，选中该引用域后直接按 `Delete` 即可，文末编号会随之更新。

::: tip 引用是“域”不是普通文字
Zotero 插入的是 Word 域（field）。不要手动改写其中的作者年份，否则刷新时会被还原或丢失。要修改，必须用 6.7.4 的“编辑引用”功能。
:::

## 6.7.4 编辑引用与添加页码

插入后若要调整，不要删掉重插，用编辑功能更稳：

1. 选中文内已插入的引用，点击 Zotero 选项卡“Add / Edit Citation（添加 / 编辑引用）”。
2. 在弹窗中可以：换一篇文献、添加页码（如“p.23”或“第 23 页”，具体格式由所选样式决定）、改为“仅作者”“仅年份”等变体。
3. 经典文献引用某个具体观点或数据时，务必加页码，便于读者和答辩老师核对原文。

示例：引用张伟（2020）关于“研发强度提升 0.8 个百分点”的论断，应写成“（张伟, 2020, p.12）”或“[1, p.12]”，而非只写“（张伟, 2020）”。没有页码的引用在严谨的学术写作里会被认为不够规范。

**机构作者与多作者：** 若作者字段设为“机构”（如国家税务总局），引用会显示机构名而非个人；多作者时样式按规则显示“等”或“et al.”，具体阈值（如超过几人显示“等”）由所选样式决定，不必手动删减作者。

## 6.7.5 合并多篇引用

同一处需要多个来源共同支撑时，合并插入最规范：

1. 在 Add Citation 搜索框里，先选中第一篇。
2. 按住 `Ctrl` 再依次点选其他篇，一起确定。
3. 文内显示为“（张三, 2020; 李四, 2021）”或“[1, 3, 5]”形式，排序与连接符由样式决定。

合并引用的排序规则因样式而异，常见如下：

| 样式 | 合并后顺序 | 连接符 |
| --- | --- | --- |
| GB/T 7714 顺序编码制 | 按引用先后 / 编号升序 | 逗号，如 [1, 3, 5] |
| GB/T 7714 著者-出版年制 | 按作者姓氏 | 分号，如（张, 2020; 李, 2021） |
| APA | 按作者姓氏字母 | 逗号 / & |

::: tip 合并引用的顺序
你不必手动调整顺序，切换样式时 Zotero 会自动重排。合并引用常用于“已有大量研究证实某结论”的综述句，但注意不要堆砌，三到五篇足够，再多会让句子失去重点。
:::

## 6.7.6 插入参考文献表

1. 把光标放到文末“参考文献”标题的下方空行。
2. 点击 Zotero 选项卡“Add Bibliography（添加参考文献）”。
3. Zotero 扫描全文所有引用，自动列出被引文献，格式随所选样式生成。
4. **只有正文真正插入过的条目才会出现**，从根本上避免“文末列了、正文没引”。

::: tip 参考文献表的标题与层级
“参考文献”通常作为一级或二级标题放在正文之后、致谢之前。插入前先手动写好“参考文献”标题并设置好样式（如“标题 1”），再把光标放到标题下方，Zotero 不会替你建标题，只生成列表本身。插入后若想调整列表字体、缩进，直接对 Word 里的样式（如“参考文献”段落样式）修改即可，但不要在引用域内部手改文字。
:::

## 6.7.7 选择并更改引用样式

不同学院、不同期刊要求不同样式，常见如下：

- 中文社科常用 **GB/T 7714-2015**，又分“顺序编码制”（正文用 [1][2]）和“著者-出版年制”（正文用（张三, 2020））。
- 英文常用 APA、MLA、Chicago 等。

更改样式的步骤：

1. 点击 Zotero 选项卡“Document Preferences（文档首选项）”。
2. 在样式列表中选择所需样式；若列表没有，点“更多样式”从 <https://www.zotero.org/styles> 安装。中文可用“GB/T 7714 2015”相关样式，注意区分简体 / 繁体与编码制。
3. 确认后，全文引用与参考文献表整体切换，无需重插。

**安装样式的具体操作：** 在“文档首选项”弹窗点击“使用编辑器安装样式其他样式…”或“管理样式”，打开官方样式仓库 <https://www.zotero.org/styles>；在搜索框输入“Chinese”或“GB/T 7714”，找到对应 .csl 点击安装，回到 Word 即可在列表选用。

::: warning 样式安装的版权与版本
引用样式文件（.csl）由社区维护，从官方样式仓库 <https://www.zotero.org/styles> 获取最稳妥。学校若有自定样式，以学校模板为准；切换样式后务必通读一遍文末，确认文献类型标识（[J] [M] [D] 等）正确，特别是从英文样式切回中文样式时容易残留英文标点。若装错样式（如装了繁体版却写简体），及时在仓库换装正确版本。
:::

## 6.7.8 中文文献样式的特别检查

自动生成不等于一定正确，定稿前逐项核对以下易错点（建议对照下表逐条打勾）：

| 检查项 | 常见错误 | 正确做法 |
| --- | --- | --- |
| 中文作者姓名 | 被拆成“张, 伟”显示异常 | 作者字段按 6.6.3 填“张, 伟” |
| “等”的出现时机 | 三名作者也显示全部 | 按样式规则，超阈值才显示“等” |
| 文献类型标识 | 期刊误标 [M] | 期刊 [J]、图书 [M]、学位 [D]、报告 [R] |
| 英文大小写 | SMITH / smith 混乱 | 按样式，通常首字母大写 |
| 卷期页码 | 缺卷或页码连接符错 | 填全卷期页，连接符符合样式 |
| DOI / URL | 缺失或前缀多余 | DOI 不含 `https://doi.org/` 前缀 |

## 6.7.9 修改题录后刷新

写作过程中若发现某文献的作者、年份或题名错了，正确流程是：

1. 回到 Zotero，按 6.6 的方法改题录字段。
2. 回到 Word，点击 Zotero 选项卡“Refresh（刷新）”，或在某些版本中按 `F9`。
3. 全文引用与参考文献表同步更新，无需手工逐条改。

::: tip 刷新前先确认光标不在引用域里
若光标正好停在某条引用内部时刷新，个别版本可能报错。刷新前先把光标点到正文空白处，再点刷新更稳妥。如果刷新后某条文献没变化，先确认你在 Zotero 改的是“同一篇”（用标题核对），而不是库中另一份重复条目。
:::

## 6.7.10 定稿前解除域代码（谨慎）

向学校系统提交、或投往某些不认 Word 域的平台前，需要把引用“落定”成纯文本：

1. 点击 Zotero 选项卡“Unlink Citations（解除引文链接）”。
2. 引用与参考文献表变成普通文字，**此后在 Zotero 里改题录不会再同步到这篇文档**。

::: warning 解除是不可逆的
解除前务必保留一份带域的原件（另存一份）。一旦 Unlink，引用就不再是“活”的，后续任何修改都要手动完成。建议：终稿经导师确认无误后再解除，并留存带域版本以便答辩后微调。解除后若发现错误，用带域备份件修改后再解除一次，不要直接手改纯文本。
:::

## 6.7.11 引文格式细节

自动生成省事，但几个细节不注意仍会出错：

1. **页码格式。** 著者-出版年制常写“（张伟, 2020, p.12）”或“（张伟, 2020: 12）”；顺序编码制常写“[1, p.12]”。具体用 p. 还是冒号、是否加“页”字，由样式决定，统一即可。
2. **“等”与“et al.”阈值。** 多数样式规定作者超过 3 人（含）才显示“等”或“et al.”，前 3 人全列。不要自行删减，交给样式。
3. **中英文标点。** 中文文献用全角括号“（ ）”与逗号“，”，英文用半角“( )”与“, ”。混用是常见硬伤，切换样式时重点检查。
4. **期刊名是否加书名号。** GB/T 7714 中文文献期刊名通常不加书名号、用全称；英文期刊名用斜体。以学校模板为准。
5. **英文文献标题大小写。** APA 等样式要求标题首字母大写（sentence case）或每词首字母大写（title case），不要全大写或全小写。

## 6.7.12 学校模板常见差异

不同学校、甚至同学院不同老师的模板要求可能不同，写之前务必拿到本校《学位论文写作规范》或模板文件，重点确认以下三项：

| 差异点 | 常见两种要求 |
| --- | --- |
| 编码方式 | 顺序编码制（[1]）vs 著者-出版年制（（张,2020）） |
| 文献表排序 | 按引用顺序 vs 按作者姓氏拼音 / 字母 |
| 文献表标题 | “参考文献”vs“主要参考文献”vs“Bibliography” |

拿到模板后，先在 Zotero 里装好对应样式，写几段样张生成文献表，与模板逐条比对无误，再正式开写，避免写到一半返工。

## 6.7.13 从插入到生成文献表的完整走查

把前面步骤串成一次标准操作，假设你要写“政策背景”一段并引用两篇文献：

1. 在 Word 写好句子：“加计扣除政策自 2015 年扩围以来作用明显。”
2. 光标置于句末，Zotero 选项卡 → Add Citation，搜索“119 号”选中那份政策文件，确定 → 出现“（财政部 国家税务总局, 2015）”。
3. 另起一句：“既有研究也证实了政策对企业创新的促进作用”，光标置于句末 → Add Citation，搜索“张伟 2020”选中，加页码 p.12 → 出现“（张伟, 2020, p.12）”。
4. 需要同时引张伟与李芳支撑同一句 → Add Citation，`Ctrl` 多选两者 → “（张伟, 2020; 李芳, 2021）”。
5. 写完全文，到文末建“参考文献”标题。
6. 光标置于标题下方 → Add Bibliography，生成列表，仅含上述被引文献。
7. 发现张伟年份应为 2019 → 回 Zotero 改题录 → 回 Word 点 Refresh → 文内与文末同步变 2019。
8. 导师确认无误后 → Unlink Citations，另存纯文本终稿提交。

## 6.7.14 各类文献的 GB/T 7714-2015 输出样例

| 类型 | 文末条目样例（示意） |
| --- | --- |
| 期刊论文 | [1] 张伟. 研发费用加计扣除对企业创新的影响[J]. 财政研究, 2020(3): 12-20. |
| 学位论文 | [2] 李芳. 税收优惠与企业研发投资[D]. 中国人民大学, 2021. |
| 图书 | [3] 刘明. 中国税收制度[M]. 北京: 经济科学出版社, 2019. |
| 报告 | [4] 国家税务总局. 中国税收政策年度报告[R]. 2022. |
| 报纸文章 | [5] 王强. 加计扣除政策扩围[N]. 中国税务报, 2019-05-12(03). |
| 电子资源 | [6] 财政部. 关于完善研发费用加计扣除政策的通知[EB/OL]. (2015-11-02)[2024-03-01]. http://... |

::: tip 用样例反查字段是否齐全
把生成的文献表和上面样例对照：期刊论文是否带了 [J]、卷期页；学位论文是否带了授予单位和年份；图书是否带了出版地、出版社。缺哪个，回 Zotero 补哪个字段。税收学论文常引用政策文件（[R] 或 [EB/OL]），务必填全发文机关和文号，否则文献类型标识与来源会不完整。
:::

## 6.7.15 参考文献表的排版规范

自动生成的是“内容”，排版仍需符合学校模板：

1. **悬挂缩进**：多数中文学位论文要求参考文献每条第二行起缩进，与首行对齐。在 Word 里选中列表，设置段落“悬挂缩进 2 字符”，不要用空格手敲。
2. **字号与行距**：通常比正文小半号、1.5 倍行距，具体看模板。
3. **与正文关系**：参考文献表前通常插入分页符，保证从新页开始；它不参与正文页码编号时按模板处理。
4. **不要手改域文字**：排版调整（缩进、字体）作用在段落样式上，不要改动引用域内部文字，否则刷新会还原。

## 6.7.16 引用写作的两种节奏与最佳实践

写论文时引用有两种常见节奏，各有适用：

| 节奏 | 做法 | 适用 |
| --- | --- | --- |
| 边写边插 | 写一句插一句引用 | 思路清晰、文献已读透 |
| 先写后插 | 先写完整草稿标占位，再统一补插 | 初稿赶工、文献还没全读 |

无论哪种，都遵循一条：**引用必须在交稿前全部通过 Zotero 生成，不留手打**。先写后插的同学，要在补引时回到 6.7.3 逐条插入，不要用“待补”占位符代替引用，占位符不会进参考文献表，最容易被漏检，导致“正文写了引用、文末没有条目”。

## 6.7.17 引用与查重的关系

引用规范还影响查重结果，税收学同学尤其要留意：

1. **合理引用不算抄袭**：凡在正文插入引用、文末列入对应条目的内容，查重系统通常识别为引用而非重复，但前提是引用格式规范、数量合理。
2. **大段引用要节制**：即便标注了出处，一整段照抄仍可能被判定引用过度，建议用自己的话概括后只引关键句。
3. **政策原文谨慎处理**：税收学常整段引用法规条文，这类内容查重可能标红，写前应了解学校对法规引用的规定，必要时放入附录而非正文。
4. **与学术道德呼应**：规范引用是格式要求，也是诚信底线，详见本课程“学术道德与引用”章节。

## 6.7.18 引用样式管理与多文档写作

写长篇毕业论文时，往往会拆成多个 Word 文档（各章分开写），最后合并。引用管理要注意：

1. **统一文档首选项**：每个分文档都用同一引用样式、同一 Zotero 账号，合并后才不会样式打架。
2. **合并方式**：先把各章文档合并成一个总文档，再让 Zotero 统一“Refresh”整理编号；不要分别生成再手工拼接，否则编号会重。
3. **样式切换时机**：定稿前再切换 / 微调样式，中间阶段保持一种，减少刷新成本。
4. **多人合写**：若与同学分工写不同章，各自引各自的文献，合并后跑一次重复项检查，统一去重。

::: tip 合并文档的坑
Word 合并文档时，Zotero 引用域通常能保留，但偶尔会变成“断开的域”。合并后务必点一次 Refresh，并核对文末参考文献表是否完整、编号是否连续。发现某条引用变灰或文末缺失，回到对应分文档重新插入该引用再合并。
:::

## 6.7.19 常见问题速查表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Word 没有 Zotero 选项卡 | 插件未安装 / 被禁用 | 见 6.7.2 重装插件 |
| 插入引用搜不到文献 | 文献在别的库或未保存 | 确认在“我的文库”且已保存 |
| 参考文献表少了某条 | 正文没真正插入该引用 | 回正文用 Add Citation 补插 |
| 样式列表没有 GB/T 7714 | 未安装该 CSL | 从 zotero.org/styles 安装 |
| 刷新后格式没变 | 选错样式或域损坏 | 重设文档首选项，必要时解除重插 |
| 中文姓名显示异常 | 作者字段填法错 | 回到 6.6.3 修正作者 |
| 合并引用顺序不对 | 样式规则使然 | 不必手调，换样式会自动重排 |
| 解除后想再改 | 域已变纯文本 | 用带域备份件重做，不要手改 |
| 中英文标点混用 | 样式切换残留 | 对照 6.7.11 逐项改 |
| 页码格式不统一 | 样式未指定或手填不一致 | 用编辑引用统一加页码 |

## 6.7.20 课堂实操

用已经读过、题录校对过的 5 篇文献完成以下可检查产出：

1. 在一段综述文字里插入 3 条单独文内引用。
2. 在另一处插入 1 条“合并多篇”引用（至少 2 篇）。
3. 对其中 1 条经典文献引用添加具体页码。
4. 文末插入自动生成的参考文献表，样式选 GB/T 7714-2015（顺序编码制）。
5. 故意修改一条 Zotero 题录的年份，回到 Word 点“刷新”，确认文内与文末同步变化。
6. 将文档另存一份带域原件，再对副本做 Unlink Citations，对比两者差异。
7. 对照 6.7.8 检查表与 6.7.11 细节，逐条核对生成的中文文献条目。

提交截图：含引用的正文段落 + 自动生成的参考文献表（含一条带页码的引用）即可。

::: tip 引用不是越多越好
文献综述里引用几十篇是正常的，但正文每个论断都该“该引才引”。过多无关引用反而稀释重点，也增加查重负担。用 6.5 的标签筛出“文献综述”类文献集中调用即可。
:::
