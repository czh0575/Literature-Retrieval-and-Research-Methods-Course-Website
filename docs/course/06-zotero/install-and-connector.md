# 6.3 安装 Zotero、浏览器连接器与知网中文插件

本页动手装三件套：Zotero 主程序、Zotero Connector 浏览器连接器、改善中文文献抓取的茉莉花（Jasminum）插件，最后用一张自检清单确认一切正常。装好之后，6.4 就能开始抓文献。

::: warning 下载只认官方渠道
下载只认官方渠道：Zotero 官网 <https://www.zotero.org/download/>、Zotero 中文社区 <https://zotero-chinese.com>、茉莉花仓库 <https://github.com/l0o0/jasminum>、中文翻译器 <https://github.com/l0o0/translators_CN>。切勿从来源不明的网盘、论坛或公众号文章里的“破解版”链接下载，以免带入恶意程序或过期、被篡改的插件。Zotero 本身免费，不存在“破解版”。
:::

## 6.3.1 下载：认准官网下载页

打开 <https://www.zotero.org/download/>。页面会同时提供两部分下载：**左侧是 Zotero 主程序**，右侧是 **Zotero Connector 浏览器连接器**。

![Zotero 下载页](/images/zotero/z01-zotero-download-page.svg)

*图 6-3 Zotero 官网下载页。左侧是主程序，右侧是浏览器连接器。*

下载前先确认你的系统，页面通常会自动识别，但也请自己核对：

| 你的系统 | 应选主程序 | 连接器去哪装 |
| --- | --- | --- |
| Windows 10 / 11 | Zotero for Windows（64 位） | 页面跳转 Edge / Chrome 应用商店，或 Firefox 附加组件 |
| macOS 11 及以上 | Zotero for macOS（Apple Silicon 或 Intel，按芯片选） | Safari / Chrome / Edge / Firefox 对应商店 |
| Linux | Zotero for Linux（Flatpak / tarball 等） | Firefox 附加组件，或对应浏览器商店 |

::: tip 版本号与 macOS 首次打开的提示
页面显示的版本号（如 Zotero 7.x.x）以官网当前提供为准，你下载时一定是最新的稳定版。若页面提示“已是最新”，直接下载即可。macOS 上若提示“无法打开，因为来自身份不明的开发者”，在“系统设置 → 隐私与安全性”里点“仍要打开”即可，这是 macOS 对未上架 App Store 软件的常规提示。
:::

## 6.3.2 安装主程序

![Zotero 安装向导](/images/zotero/z02-install-wizard.svg)

*图 6-4 Zotero 安装向导。*

**Windows 步骤：**

1. 打开“下载”文件夹，双击 `Zotero-7.x.x_x64_setup.exe`（文件名随版本变化）。
2. 若弹出“用户账户控制”询问是否允许，点“是”。
3. 安装向导出现后，点“Next / 下一步”。
4. 阅读许可协议，选“我接受”，点“下一步”。
5. 选择安装位置：默认 `C:\Program Files\Zotero` 即可；若 C 盘空间紧张，可改到其他盘（记住改后的路径，6.8 备份时要找）。点“下一步”。
6. 安装类型：选“Standard / 标准”即可，除非你清楚要自定义组件。点“下一步”。
7. 点“Install / 安装”，等待进度条完成。
8. 勾选“运行 Zotero”，点“Finish / 完成”。

**macOS 步骤：**

1. 打开下载的 `.dmg`，把 Zotero 图标拖到“应用程序”文件夹。
2. 在启动台打开 Zotero；首次打开若被拦截，按系统提示在“隐私与安全性”中允许。

**Linux 步骤（以 Flatpak 为例）：**

1. 终端执行 `flatpak install flathub org.zotero.Zotero`（具体命令以官网为准）。
2. 从应用菜单启动 Zotero。

::: warning 安装位置与安装类型
安装位置（步骤 5）建议保持默认，或改到你知道的盘符。Zotero 的“程序文件”和“数据目录”是分开的（6.1.2.1），重装程序不会删除你的文献，但改了安装路径后，以后若需手动定位程序，请记得你选的位置。安装类型若无特殊需求务必选“标准”，自定义可能漏装组件。
:::

## 6.3.3 首次启动向导

主程序首次启动后，可能会弹出“欢迎 / 设置向导”，依次处理三件事：

1. **安装浏览器连接器**：向导可能提示“Install Browser Connector”，点对应浏览器按钮，会跳到该浏览器的扩展商店（详见 6.3.5）。若当时跳过，后面也能从官网补装。
2. **登录账号**：向导可能提示“Sign in”，输入你在 6.3.4 注册的邮箱与密码（若还没注册，可先跳过，稍后在「编辑 → 设置 → 同步」里登录）。
3. **设置数据目录**：一般保持默认即可，向导会告诉你资料库存哪里（如需改位置，见 6.1.2.1 与 6.8）。

::: tip 跳过向导后怎么补做
如果首次启动没有弹出向导，或你点了“跳过”，后面补做即可：连接器在 6.3.5 单独装，账号在「编辑 → 设置 → 同步」登录，数据目录在「编辑 → 设置 → 高级 → 文件和文件夹」查看。向导只是把这几步集中起来，跳过不影响后续。
:::

## 6.3.4 注册并登录 Zotero 账号

账号用于云同步（6.8）和跨设备一致。

**注册（只需一次）：**

1. 浏览器打开 <https://www.zotero.org/user/register>。
2. 填写用户名、邮箱（推荐学校邮箱）、密码，完成人机验证。
3. 到邮箱查收验证邮件，点其中的链接激活账号。

**在主程序登录：**

1. 打开 Zotero，菜单「编辑 → 设置」（Edit → Settings / Preferences）。
2. 左侧选「同步」（Sync）。
3. 在“Zotero 账号”区填注册的邮箱与密码。
4. 点“设置同步 / Set Up Syncing”或“登录”，出现“已登录”即成功。
5. 下方“同步的数据”可勾选“同步附件中的文件”（会占用云端空间，免费额度 300 MB；如超量可只同步题录、附件留本地，或 6.8 用 WebDAV）。

::: warning 账号用邮箱注册
账号是**邮箱注册**，不是随便设的用户名登录。若登录提示错误，先确认邮箱是否已完成验证（没点激活邮件链接会登不进）。密码建议与学校邮箱密码不同，且记在密码管理器，避免遗忘导致同步无法进行。
:::

## 6.3.5 安装浏览器连接器 Zotero Connector

没有连接器，你就只能在 Zotero 里手敲题录。

![安装浏览器连接器](/images/zotero/z04-connector-install.svg)

*图 6-5 在浏览器扩展商店安装 Zotero Connector。*

1. 打开你常用的浏览器（Edge / Chrome / Firefox 之一）。
2. 方式一：回到 <https://www.zotero.org/download/>，点页面右侧“Zotero Connector”下的对应浏览器按钮，自动跳到该浏览器的扩展商店。
3. 方式二：直接在 Chrome 网上应用店 / Edge 加载项 / Firefox 附加组件里搜索“Zotero Connector”。
4. 在商店页面点“添加 / 安装 / Add to…”，按提示确认“添加扩展”。
5. 安装完成后，浏览器工具栏（地址栏右侧）出现一个 Zotero 图标。
6. 若图标没出现在工具栏，点浏览器右上角的“扩展”拼图图标，找到 Zotero Connector，点其后的“图钉”固定，使其常驻工具栏。

::: tip 把连接器固定在工具栏
建议把连接器图标“固定（图钉）”在工具栏，而不是收进扩展菜单。抓取文献时你需要随时点它，固定在显眼处能省去每次展开扩展菜单的麻烦。若你用多个浏览器，每个都要单独装一次连接器；但只需其中一个装好并配合主程序即可开始抓取。
:::

## 6.3.6 连接器安装后的自检

装好连接器后，先确认它和主程序能“对话”。最关键的是看工具栏图标的**状态**。

![浏览器工具栏的 Zotero 连接器](/images/zotero/z05-connector-toolbar.svg)

*图 6-6 浏览器工具栏上的 Zotero 连接器图标及其在知网页面的状态。*

| 图标状态 | 含义 | 你能做什么 |
| --- | --- | --- |
| 灰色 / 空心 | 当前页面暂无可抓取内容（如普通新闻页） | 无需操作，换到文献页再试 |
| 书本 / 单页图标 | 当前是单篇文献详情页，可抓取这一条 | 点一下保存该条 |
| 文件夹图标 | 当前是检索结果列表页，可批量勾选 | 点一下弹出多选窗口 |

自检步骤：

1. 确保 Zotero 主程序正在运行（任务栏有 Zotero 图标）。
2. 浏览器打开知网 <https://www.cnki.net>，检索任意主题（如“增值税”），进入结果列表页。
3. 看工具栏 Zotero 图标：应变为“文件夹”样式（表示可批量）。
4. 点击该图标，应弹出“保存到 Zotero”窗口，列出本页可抓的条目，并可选择保存到“我的文库”或某分类。

::: warning 点连接器没反应的排查顺序
若点击连接器提示“Zotero is not running”或毫无反应，多数是主程序没开，或先装了连接器后装主程序。先打开 Zotero 主程序，再点图标；仍不行就重启浏览器。这是安装阶段最高频的报错，按这个顺序排查能省很多时间。
:::

## 6.3.7 为什么还要装“知网中文插件”

到这里，主程序 + 连接器已能工作，但抓取**知网中文文献**时经常出问题。原因是 Zotero 内置的翻译器（Translator）对知网的适配长期不稳定，典型症状如下：

| 症状 | 表现 |
| --- | --- |
| 作者字段异常 | 作者变成“刘某某 王某某”一长串，没拆成独立作者 |
| 期刊名不全 | 《税务研究》只抓到“税务研究”或英文缩写 |
| 抓不到 PDF | 只存了题录，没下载全文 |
| 类型错认 | 条目类型被识别成“网页”而非“期刊论文” |

解决思路有两条，本课程**推荐方案一**：

- **方案一（推荐）：装 Zotero 中文社区的“茉莉花（Jasminum）”插件**。它显著改善中文文献抓取，并提供 PDF 批量下载、作者姓名拆分、知网元数据增强等功能，是中文用户的事实标准增强。
- **方案二：更新翻译器文件**。从中文翻译器项目 <https://github.com/l0o0/translators_CN> 取较新的知网翻译器，覆盖到 Zotero 的 translators 目录，让内置识别更准。

::: warning 社区插件的来源与版本适配
第三方插件与翻译器均由社区维护，Zotero 官方不提供。安装前请从上述官方仓库或 Zotero 中文社区下载，不要从来源不明的网盘下载安装包。Zotero 每次大版本升级（如 6 升 7）后，插件可能需要重新安装或等待作者适配；若出现插件“不兼容”提示，先到插件发布页看是否有适配新版，不要强行启用可能损坏资料库的旧插件。
:::

## 6.3.8 安装茉莉花插件

茉莉花（Jasminum）是中文文献工作流的核心插件。

![安装茉莉花插件](/images/zotero/z06-jasminum-install.svg)

*图 6-7 在 Zotero 中通过「工具 → 插件」安装本地 .xpi 插件文件。*

**第一步：下载 .xpi 文件**

1. 打开 <https://zotero-chinese.com/plugins/> 或 GitHub 仓库 <https://github.com/l0o0/jasminum>。
2. 找到与当前 Zotero 版本匹配的发布包（Release），通常是 `.xpi` 文件。
3. 点击下载，记住下载保存的位置（如“下载”文件夹）。

**第二步：在 Zotero 中安装**

1. 打开 Zotero，菜单「工具 → 插件」（Tools → Add-ons / Plugins / 扩展，名称因版本而异）。
2. 在插件管理窗口右上角，点齿轮图标（⚙）。
3. 选“Install Plugin From File… / 从文件安装插件…”。
4. 在文件选择框定位到刚下载的 `.xpi`，双击或选“打开”。
5. 按提示确认安装，可能要求“以管理员身份”或“信任此插件”。
6. 安装完成后，按提示**重启 Zotero**（关掉再开）。
7. 重启后回到「工具 → 插件」，在列表里确认 Jasminum 已显示且“已启用”。

::: warning 以当前版本实际界面为准
Zotero 7 的插件管理入口在「工具 → 插件」；不同版本的按钮文字可能是 Add-ons / Plugins / 扩展，位置也可能略有差异（个别版本在「编辑 → 设置 → 扩展」）。齿轮图标可能在右上角，也可能在窗口其他角落。若找不到“从文件安装”，以当前版本实际界面为准，或查 Zotero 中文社区的对应教程。务必下载与你 Zotero 大版本匹配的 .xpi，版本不匹配会安装失败或启用后报错。
:::

## 6.3.9 更新翻译器的方法

除了装插件，保持翻译器（Translator）为较新版本也能提升抓取质量：

1. 菜单「编辑 → 设置 → 高级 → 文件和文件夹」（Edit → Settings → Advanced → Files and Folders，位置因版本而异）。
2. 在该页查找与“翻译器 / Translators”相关的按钮，如“更新翻译器（Update Translators）”“更新样式（Update Styles）”一类。
3. 点击后 Zotero 会联网拉取最新翻译器与引用样式；完成后重启生效。

::: warning 没有“更新翻译器”入口怎么办
并非每个版本都在“高级 → 文件和文件夹”里提供“更新翻译器”按钮；若当前版本没有该入口，可在茉莉花插件的设置里找翻译器更新选项，或等待 Zotero 主程序自动更新翻译器（Zotero 通常会随启动检查更新）。不要手动去系统目录替换 translators 文件，除非你清楚自己在做什么，错误替换可能导致抓取全面失效。以当前版本实际界面为准。
:::

## 6.3.10 安装完成后的自检清单

| 检查项 | 怎么做 | 正常表现 | 异常怎么处理 |
| --- | --- | --- | --- |
| 主程序能打开 | 双击桌面 Zotero 图标 | 出现三栏界面（见 6.2） | 重装；看是否缺运行库 |
| 账号已登录 | 「编辑 → 设置 → 同步」 | 显示“已登录”及邮箱 | 重输密码；查激活邮件 |
| 连接器在工具栏 | 看浏览器工具栏 | 有 Zotero 图标且已固定 | 6.3.5 重装并固定 |
| 知网可弹保存窗 | 结果页点连接器 | 弹出“保存到 Zotero”窗口 | 开主程序；重启浏览器 |
| 题录字段完整 | 抓一条知网文献看右栏 | 作者拆分、期刊名全、类型为期刊论文 | 装/重装茉莉花（6.3.8） |
| 能下到 PDF | 抓文献后看右栏附件 | 有 PDF 附件且能打开 | 用茉莉花下载（6.4）或手工下 |

::: tip 自检第 5 项不过就先修插件
自检第 5 项“题录字段完整”是判断中文插件是否生效的关键。若抓到的作者仍是一长串、类型是“网页”，说明茉莉花没装好或没启用，回到 6.3.8 确认已重启且已启用。这一项不过，6.4 会非常痛苦。
:::

## 6.3.11 常见问题速查表

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 连接器图标不出现在工具栏 | 没固定 / 没装成功 / 收进扩展菜单 | 扩展页固定图钉；确认已安装 |
| 点击连接器无反应 | 主程序没运行 | 先开 Zotero 主程序再点 |
| 提示“could not save item” | 主程序未开 / 连接器与主程序版本错配 | 开主程序；升级两者到匹配版本 |
| 抓取后作者是一长串 | 没装茉莉花 / 翻译器旧 | 装茉莉花（6.3.8）或更新翻译器（6.3.9） |
| 抓不到 PDF | 知网未登录 / 无下载权限 / 连接器限制 | 校内或 CARSI 登录；用茉莉花下载（6.4） |
| 装了插件但启动变慢 | 插件多 / 大资料库索引 | 正常；若极慢检查是否有冲突插件 |
| 插件显示“不兼容” | 插件版本与 Zotero 大版本不匹配 | 下匹配版；等大版本适配，勿强行启用 |
| 同步提示密码错误 | 邮箱未验证 / 密码错 | 查激活邮件；重置密码 |

::: details 展开：更隐蔽的一类问题（杀毒软件拦截）
少数 Windows 环境下，杀毒软件会把 Zotero 的连接器通信或插件当成可疑行为拦截，表现为“主程序开着但连接器说找不到”。若上述常规排查都无效，可临时退出杀毒软件再试一次；确认是误报后，把 Zotero 安装目录加入杀毒软件白名单。不要为省事长期关闭杀毒软件。
:::

## 6.3.12 安装顺序的总原则

三件套按“主程序 → 连接器 → 插件 → 账号”的顺序装，背后是依赖关系。顺序弄反，就会出现“点了保存却说找不到 Zotero”之类报错。

| 若你反着做 | 会发生什么 | 正确做法 |
| --- | --- | --- |
| 先装连接器，后装主程序 | 连接器检测不到主程序，点击无反应 | 先开主程序再装连接器 |
| 主程序没装就装插件 | 插件无处可装，安装失败 | 主程序就绪后再装茉莉花 |
| 没登录账号就同步 | 同步无目标，附件传不上去 | 先登录，再点同步 |
| 插件没启用就抓取 | 题录字段错乱，作者不拆分 | 装完确认“已启用”再抓 |

## 6.3.13 各浏览器连接器安装的差异

不同浏览器的连接器来自各自的扩展商店，入口不同，操作逻辑一致。

| 浏览器 | 连接器商店入口 | 特别注意 |
| --- | --- | --- |
| Chrome | Chrome 网上应用店，搜“Zotero Connector” | 需能访问 Google 服务；校园网若受限可用 Edge 替代 |
| Edge | Microsoft Edge 加载项（addons.microsoftedge.microsoft.com），搜“Zotero Connector” | 与 Chrome 内核相同，体验一致，国内访问通常更顺 |
| Firefox | Firefox 附加组件（addons.mozilla.org），搜“Zotero Connector” | 无需 Google 服务，访问较稳 |
| Safari | Zotero 7 起对 Safari 支持有限，以官网文档为准 | 若 Safari 装不上，换 Chrome / Edge / Firefox 完成抓取 |

::: warning 连接器只作用于装了它的浏览器
连接器只作用于“你装了它的那个浏览器”。若你在 Edge 装了连接器，却用 Chrome 打开知网，是抓不到的，必须在装了连接器的浏览器里操作。毕业论文阶段建议固定用一个浏览器做文献检索与抓取，避免“明明装了却抓不了”的误会。
:::

## 6.3.14 茉莉花装好后的功能验证

“已启用”不等于“能干活”。装完后做一次功能验证，确认茉莉花真的接管了中文抓取：

1. 打开 Zotero，在中间栏**选中一条**知网文献条目（用 6.3.6 自检抓到的那条）。
2. 在条目上**右键**，看菜单里是否出现茉莉花提供的项，如“抓取知网元数据”“下载 PDF”“管理知网附件”等（具体文字因版本而异）。
3. 菜单「工具 / 编辑 → 设置」里，看是否多出一个“Jasminum”或“茉莉花”配置页，可设置作者拆分、PDF 下载等。
4. 若有上述菜单与配置页，说明插件生效；若右键没出现相关项，回到 6.3.8 确认已重启、已启用，或重下匹配版本。

一条中文条目上右键能看到茉莉花菜单，才是真装好。验证通过后再进入 6.4，抓取会顺很多。

## 6.3.15 浏览器无痕模式与容器标签的坑

连接器在以下两种场景可能“看不见”页面，导致抓取失败：

1. **无痕 / 隐私窗口**：部分浏览器默认禁止扩展在无痕模式运行，连接器在无痕窗口不工作。抓取文献请用普通窗口；若必须用无痕，需先在扩展管理里勾选“允许在无痕模式使用”。
2. **Firefox 容器标签（Container Tabs）**：容器标签隔离了站点上下文，个别情况下连接器识别异常。正常检索知网用默认容器即可。

::: warning 不要在无痕窗口抓文献
知网全文下载涉及学校权限，本就建议在“已登录、已认证”的普通窗口操作。无痕窗口既可能让连接器失效，也可能让知网登录态丢失。写论文抓文献时，统一用普通窗口、保持知网登录态，是最稳的组合。
:::

## 6.3.16 卸载与干净重装（排障用）

若插件装坏、界面异常，或升级 Zotero 大版本后插件冲突，可用干净重装恢复。**数据目录的处理要格外谨慎**：

1. 在 Zotero「编辑 → 设置 → 同步」先点一次同步，把最新数据传上云端（防丢）。
2. 退出 Zotero。
3. 在「工具 → 插件」里先禁用 / 移除有问题的插件（比整体重装更轻量，优先试这个）。
4. 若仍异常，卸载 Zotero 主程序（系统“添加或删除程序”）。
5. **数据目录不要删**（默认 `C:\Users\你的用户名\Zotero\`）。删程序不会删文献，但手动删数据目录会丢全部 PDF 与题录。
6. 重新下载安装主程序（6.3.2），登录账号同步恢复。

::: warning 卸载程序不等于删除数据目录
“卸载程序”和“删除数据目录”是两件事。除非你已用 6.8 的方法完整备份，否则**不要**删除数据目录。干净重装指的是重装程序，文献应靠同步或保留数据目录自然恢复。若重装后文献没出现，先检查是否登录了同一账号、是否指向了原数据目录。
:::

## 6.3.17 安装阶段常见误解

| 误解 | 真相 |
| --- | --- |
| “有破解版更快/功能多” | Zotero 本就免费，不存在破解版；来源不明的安装包有安全风险 |
| “连接器能离线抓文献” | 连接器需联网识别网页、需主程序运行，且 PDF 下载依赖数据库权限 |
| “装插件要花钱” | 茉莉花、中文翻译器均免费、开源，由社区维护 |
| “Mac 装不了 / Linux 不支持” | 三系统都官方支持，Mac 用 .dmg，Linux 有 Flatpak / tarball |
| “装好就自动抓所有网站” | 仅对连接器支持的网站有效，冷门网站仍需手敲（6.1.9） |

## 6.3.18 确认数据目录位置（为备份做准备）

趁早确认“数据目录”在哪，这是 6.8 备份的基础：

1. 菜单「编辑 → 设置 → 高级 → 文件和文件夹」（Edit → Settings → Advanced → Files and Folders，位置因版本而异）。
2. 找到“数据目录位置 / Data Directory Location”一栏，记下显示的路径（如 `C:\Users\你的用户名\Zotero`）。
3. 点“显示数据目录 / Show Data Directory”可直达该文件夹，确认里面有 `zotero.sqlite` 和 `storage` 子文件夹。

::: tip 把数据目录路径记下来
把这个路径抄在笔记里，或截图保存。将来换电脑、重装系统前，只要复制整个数据目录，文献就完整保留。数据目录与“程序安装位置”（6.3.2 步骤 5）是两回事，别混淆。
:::

## 6.3.19 多设备登录同一账号的注意事项

Zotero 账号可在多台电脑同时登录，资料库通过同步保持一致。使用时注意两点：

1. **改完先同步再换设备**：在 A 电脑改了文献，先点工具栏同步箭头上传；再到 B 电脑打开时它会自动下载，看到的是最新状态。
2. **避免两端同时大改**：若 A、B 两台电脑都离线改了同一批文献再联网，可能产生冲突副本，需手动合并。正常“一台改完同步、再开另一台”的节奏不会冲突。

::: warning 没勾“同步附件”的后果
同步只同步“题录 + 你勾选的附件文件”。若「设置 → 同步」里没勾“同步附件中的文件”，PDF 不会上传云端，B 电脑上会有题录却没 PDF。免费额度 300 MB 附件，毕业论文阶段通常够；超了可在 6.8 用 WebDAV 或只同步题录、附件留本地。
:::

## 6.3.20 连接器与插件的版本匹配

连接器随浏览器更新，一般无需操心版本；但**茉莉花插件必须与你 Zotero 的大版本匹配**，这是安装失败的高发点。

| Zotero 版本 | 茉莉花适配 | 去哪确认 |
| --- | --- | --- |
| Zotero 7 | 需下载标注支持 7 的茉莉花版本 | 插件发布页 Release 说明、Zotero 中文社区 |
| Zotero 6 | 对应支持 6 的旧版茉莉花 | 同上，旧 Release |
| 不确定 | 先看「帮助 → 关于」的版本号，再下匹配版 | 发布页通常写“兼容 Zotero x” |

::: warning 下载插件前先读兼容性说明
下载插件时，务必读发布页的“兼容性 / 支持的 Zotero 版本”说明，不要只看文件名最新就下。装了不匹配的版本，会出现“不兼容”“启用后崩溃”或抓取无变化。Zotero 大版本升级后，第一时间到插件页看是否有适配新版，别急着强行启用旧插件。
:::

## 6.3.21 安装排障决策树

遇到安装问题，按下面的顺序走，多数能解决：

1. 连接器点击无反应 → 先确认 Zotero 主程序是否已打开；打开后仍无 → 重启浏览器；再无 → 重装连接器（6.3.5）。
2. 弹出保存窗口但题录字段错（作者是长串、类型是网页）→ 装 / 重装 / 启用茉莉花（6.3.8），并确认版本匹配（6.3.20）。
3. 题录正常但没 PDF → 确认知网已登录且有下载权限；用茉莉花下载（6.4）或手工下载后拖入（6.4 场景 C）。
4. 插件“不兼容” → 下匹配版本（6.3.20），不要强行启用。
5. 以上都无效且怀疑程序损坏 → 干净重装（6.3.16），注意保留数据目录。

::: details 展开：什么时候该求助
若按决策树走完仍失败，且你确认主程序能开、账号能登、连接器已固定、茉莉花匹配且已启用，可带着以下信息去 Zotero 中文社区提问：①Zotero 版本号（帮助→关于）；②浏览器与连接器版本；③具体报错文字截图；④一篇复现问题的知网链接。信息越具体，社区越容易帮你定位。
:::

### 6.3.23.2 常见答疑

1. **问：安装时杀毒软件报毒怎么办？** 答：先确认下载源是官网或中文社区；若确认无误，可将 Zotero 目录加入白名单。来源不明的安装包则直接删除，不要加白名单。
2. **问：茉莉花下载的 .xpi 双击打不开？** 答：.xpi 不是普通程序，要在 Zotero 的「工具 → 插件」里“从文件安装”，不是系统里双击运行。
3. **问：我有两个浏览器，都要装连接器吗？** 答：只在你实际用来检索知网的那个浏览器装即可；装多个也行，但没必要。
4. **问：装完能立刻写参考文献吗？** 答：还不能。装好是前提，真正生成参考文献表要等 6.7，中间还要走 6.4 抓取、6.5 整理、6.6 校对。

### 6.3.23.3 版本信息记录建议

为避免将来排障时反复查版本，建议在笔记里记一行：“Zotero x.x.x + 连接器 x.x.x + 茉莉花 x.x.x + 浏览器及版本 + 系统”。这行信息在 6.3.21 的求助场景、以及 Zotero 大版本升级后插件失效时，能让你快速判断是不是版本不匹配，也方便向中文社区提问时一次性说清环境。
