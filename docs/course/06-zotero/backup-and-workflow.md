# 6.8 同步、备份与附件管理

## 6.8.1 为什么需要同步与备份

把文献堆在单机 Zotero 里，有三重现实风险：硬盘损坏会丢失全部题录与 PDF；换一台电脑写作会中断；误删之后无处恢复。这两件事要分清楚。**同步解决“多设备可用”，备份解决“误删 / 损坏可恢复”**，两者作用不同，都要有。只同步不备份，一旦账号或云端出错仍可能丢；只备份不同步，换电脑时又得手动搬运。

毕业论文周期长（通常横跨一个学期），文献库是几个月积累的核心资产，必须在开始大量导入之前就把同步与备份搭好，而不是等到电脑坏了才后悔。一个稳妥的资料库，应当同时满足三句话：在实验室电脑能写、在宿舍笔记本能接着写、误删任何一条都能找回来。

## 6.8.2 同步的两部分：数据与文件

Zotero 同步分两类，理解它们的区别才能选对策略：

| 同步内容 | 包含什么 | 默认是否同步 | 体积特征 |
| --- | --- | --- | --- |
| 数据同步 | 题录、标签、笔记、分类结构 | 是，登录即同步 | 极小（文本为主） |
| 文件同步 | PDF 等附件 | 需开启，且受存储空间限制 | 较大（每篇数 MB 起） |

题录体积小、同步快；PDF 体积大，是同步空间的主要消耗者。因此很多同学会遇到“题录同步了、PDF 没上来”的情况，原因是文件同步受额度或设置影响。规划同步策略时，要先想清楚：是让官方帮你同步 PDF（占额度），还是自己用网盘管 PDF、只让官方同步轻量题录（见 6.8.6）。

**体积估算参考：** 一篇普通期刊 PDF 约 1–5 MB，100 篇约 0.1–0.5 GB；扫描版学位论文常达 20–50 MB，几十篇就可能上 GB。对照官方免费额度（有限，超出需付费），就能判断该不该用链接附件。

## 6.8.3 配置账号同步

1. 在 <https://www.zotero.org> 注册一个账号。
2. 打开 Zotero，菜单「编辑 → 设置 → 同步（Sync）」。
3. 输入账号密码，勾选“同步时自动下载文件”（如需同步 PDF）。
4. 点击“立即同步”，观察左下角同步状态图标从转圈变为完成。

**验证同步成功：** 同步完成后，到官网登录同一账号，进入“我的文库（Web 版）”，应能看到刚写入的题录；在另一台已登录的电脑上点同步，也应拉到相同内容。若两边不一致，先检查是否都登录了同一账号、网络是否通畅。

::: warning 版本差异与网络
同步设置入口文案在不同版本可能为“同步”或“Sync”；若找不到，请以当前 Zotero 版本实际界面为准。同步前确认网络可以正常访问官方服务；在学校网络环境下若访问不稳，可错峰同步。若两台设备同时编辑同一条目产生冲突，Zotero 通常会保留两个版本供你合并，遇到冲突提示时，按提示选择保留哪一侧。
:::

## 6.8.4 关于同步空间的说明

Zotero 官方为文件同步提供一定额度的免费空间，**免费额度有限，超出需要付费扩容**（具体额度与价格以官网当前公布为准，本讲义不罗列会变动的数字，以免过时）。对一篇毕业论文规模的文献（几十到上百篇 PDF），免费额度通常够用；若 PDF 极多、或包含大量扫描版大文件，建议改用“链接附件 + 自有网盘”的方式（见 6.8.6），把大文件交给自己的网盘，只让官方同步轻量的题录。

**额度管理建议：** 定期清理“待读文献”里最终不用的条目及其 PDF；学位论文全文往往体积大，可改用链接附件；不把与论文无关的私人 PDF 混入资料库，避免无谓占用。同步设置里可以单独关闭“同步文件”，只同步题录，需要时再手动处理 PDF。

## 6.8.5 附件的两种存储模式

两种模式的差别在文件放在哪：

| 模式 | 说明 | 优点 | 注意 |
| --- | --- | --- | --- |
| 存储副本（默认） | PDF 复制进 Zotero 数据目录，由 Zotero 托管 | 同步后不丢、路径稳定、最省心 | 占用官方同步空间 |
| 链接到文件 | Zotero 只记录指向原文件的链接，不复制 | 不占同步空间、可用自有网盘 | 原文件移动 / 删除则附件失效 |

初学者先用默认的“存储副本”即可，等文献量上来、或已经在用学校云盘管理 PDF 时，再考虑切换“链接到文件”。两种模式可以在同一个资料库里混用：核心小 PDF 用存储副本，超大扫描件用链接附件。判断标准很简单，文件大、且你已在网盘里管好它，就用链接；否则用存储副本。

## 6.8.6 链接附件的适用场景与设置

**适用场景：** 文件已按自己的习惯整理好、PDF 体积很大、或多台设备共用同一网络盘（如学校云盘、OneDrive）。

**设置存储基准位置（base directory）：**

1. 菜单「编辑 → 设置 → 高级（Advanced）→ 文件和文件夹（Files and Folders）」。
2. 找到“链接附件的根目录（Base directory for linked attachments）”，设为你的网盘 / 专用文件夹。
3. 之后“链接到文件”使用相对路径记录；换设备时只要网盘把原文件同步到位，Zotero 就能正常打开附件。

**完整工作流示例（链接附件 + 网盘）：**

1. 在学校云盘建文件夹 `ZoteroAttachments`，里面按“作者-年份”放 PDF。
2. 在 Zotero 设置 base directory 指向该云盘文件夹。
3. 添加附件时选“链接到文件”，指向云盘里的 PDF。
4. 宿舍笔记本也挂载同一云盘、设同一 base directory，打开 Zotero 即可读同一批 PDF。

::: warning 链接附件的风险
链接附件不随 Zotero 官方文件同步走，完全依赖你自己的文件管理。一旦原 PDF 被改名、移动或清理，Zotero 里点开就是“文件缺失”。因此采用链接模式必须配合 6.8.8 的本地备份，且不要在网盘之外再移动原文件。换电脑时务必先确认网盘已同步完成，再打开 Zotero。
:::

## 6.8.7 附件文件命名

- **存储副本模式**：文件名由 Zotero 管理，不要手动在资源管理器里改名，否则内部指向失效，附件可能“消失”。
- **链接附件模式**：文件名就是原文件名，存入网盘前自己用“作者-年份-关键词”规则命名（如“张伟-2020-加计扣除创新.pdf”），在网盘里就能直接定位。

| 推荐命名 | 不推荐命名 | 理由 |
| --- | --- | --- |
| 张伟-2020-加计扣除创新.pdf | 新建 PDF (1).pdf | 含作者年份主题，可检索 |
| 财税部-2015-119号.pdf | download.pdf | 政策文件标文号最实用 |
| 李芳-2021-文献综述.pdf | 文献2.pdf | 避免“文献1/2/3”混淆 |

真正检索靠题录字段，文件名只是辅助识别，不必为命名纠结。

## 6.8.8 数据目录位置与备份

Zotero 的全部本地数据（题录数据库 + 存储副本附件 + 笔记）都集中在一个“数据目录”里，备份它就能保全几乎所有本地成果。

::: warning 数据目录位置因系统与版本而异
典型位置如用户文档下的“Zotero”文件夹（Windows）或用户库中的“Zotero”目录（macOS）。具体路径可在「编辑 → 设置 → 高级 → 文件和文件夹」里的“数据目录位置（Data Directory）”查看，不同版本界面文案略有差异，以当前实际为准。不要凭记忆去系统盘里找，以设置里显示的路径为准。
:::

数据目录内部通常有两个关键部分：`zotero.sqlite`（题录与笔记的数据库）和 `storage` 文件夹（存储副本的 PDF，按随机名存放，不要手动翻动或改名）。备份整个数据目录即可，不必关心内部子结构，所以直接复制整个文件夹即可。

**推荐备份策略与频率：**

| 备份对象 | 方式 | 建议频率 |
| --- | --- | --- |
| 题录 + 笔记 | 导出 RDF（见 6.8.9） | 每周一次 |
| 整个数据目录 | 复制到移动硬盘 / 网盘 | 每月一次或换设备前 |
| 链接附件原文件 | 随网盘 / 单独拷贝 | 与数据目录同步 |
| 论文文档 | 另存多份 | 每次大改后 |

## 6.8.9 导出与导入

**导出题录（RDF）：**

1. 选中“我的文库”或某个分类。
2. 菜单「文件 → 导出资料库…」（不同版本文案可能为“导出”）。
3. 格式选“Zotero RDF”，按需勾选“导出笔记”“导出文件”（导出文件会把 PDF 一并打包，体积较大）。
4. 生成 .rdf 文件，作为备份留存或转移他用。

**导入恢复：**

1. 菜单「文件 → 导入…」，选择之前的 .rdf 文件。
2. 选择“合并到当前库”或“新建库”，恢复题录与笔记。合并时 Zotero 会尝试匹配已有条目，避免重复。

::: tip RDF 与存储副本的区别
RDF 是题录 + 笔记的“轻备份”，适合日常频繁备份；而整个数据目录的复制是“全备份”，包含 PDF 本体。两者配合：日常导 RDF，每周 / 每月复制一次数据目录，基本够用。RDF 具有跨版本、跨平台兼容性，即使将来升级 Zotero 或换电脑，导入都不会有障碍。若只导 RDF 未勾“导出文件”，恢复后 PDF 需重新关联或下载，属于“题录保底”方案。
:::

## 6.8.10 群组文库与协作（呼应 6.5.6）

若课程有大作业需要小组共享文献：

1. 在官网或 Zotero 内创建群组文库（Group Library）。
2. 邀请小组成员，共享题录与附件。
3. 个人“我的文库”与群组相互独立，避免把私人文献误传进群组。

群组权限设置很关键，建群时注意区分：

| 权限 | 含义 | 适用 |
| --- | --- | --- |
| 只读 | 成员只能看、不能改 | 给只需参考的同学 |
| 可编辑 | 成员可增删改条目 | 共同写作的小组 |
| 管理员 | 可管理成员与设置 | 组长 |

::: tip 个人作业不必建群组文库
本课程个人作业一般不需要群组，了解机制即可。真要协作时，先约定好分类与标签规则（参考 6.5），避免多人各建一套导致群组文库混乱。误删群组条目同样进回收站，可恢复。群组附件占用群组所属创建者的同步空间，建群前确认空间充足。
:::

## 6.8.11 多设备同步实战

1. **在台式机**：登录同步账号，正常导入、校对、写笔记；离开前点一次“立即同步”，确认状态图标完成。
2. **在笔记本（首次）**：安装同版本 Zotero，登录同一账号，点同步，题录与（若开启文件同步）PDF 自动下载到位。
3. **日常**：在哪台机器改了题录或笔记，离开前都同步一次；开始写作前也先同步一次，拉取对方的最新改动。
4. **冲突处理**：若两边都有改动，Zotero 提示冲突时，逐条比对，保留正确一侧或手动合并，不要盲目全选一侧。

::: warning 不要两台机器同时长时间离线编辑
同步依赖“改动后及时上传、使用前及时下载”。如果两台机器都离线改了同一篇文献很久，再联网时冲突会很多。养成“离开即同步、使用前先同步”的习惯，冲突几乎不会发生。
:::

## 6.8.12 恢复演练

备份好不好，不能等真丢了才验证。建议学期中做一次恢复演练：

1. 在临时位置新建一个空的 Zotero 测试库（或另一台备用机）。
2. 导入你此前导出的 RDF，确认题录、标签、笔记都回来了。
3. 若 RDF 含“导出文件”，确认 PDF 也能打开。
4. 演练通过后，把 RDF 和备份标注日期，安心继续写作。

这一步花十分钟，却能证明你的备份真的可用，远胜于“我以为备份了”。

## 6.8.13 从检索到写作的完整流程与时间线

一篇毕业论文的文献管理标准流程如下，建议贴在电脑旁：

1. 在知网等数据库检索，用连接器导出 / 抓取题录与 PDF。
2. 导入 Zotero，进入“我的文库”。
3. 按 6.6 校对元数据（条目类型、作者、期刊、页码、DOI）。
4. 下载或关联全文，作为条目附件。
5. 按 6.5 归入分类，并打上阅读状态 / 类型 / 用途三类标签。
6. 阅读、批注，按三层结构写笔记与阅读卡片。
7. 在 Word 中按 6.7 插入引用、选择样式、生成参考文献表。
8. 修改题录后回 Word 刷新，保持同步。
9. 按本节配置同步，并定期导出 RDF、备份数据目录。

对应的时间线建议：

- **每周**：导出一次 RDF 备份；把“待读文献”清空一部分。
- **每月 / 换设备前**：复制一次完整数据目录；检查同步状态。
- **每次大改论文后**：论文文档多存一份；确认参考文献表刷新无误。
- **答辩前**：做一次恢复演练（导入 RDF 到临时库，确认能还原）。

## 6.8.14 常见问题速查表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 换电脑后 PDF 打不开 | 用了链接附件且原文件未随迁 | 拷贝原文件夹，或改用存储副本 |
| 同步一直转圈不完 | 网络问题或免费空间不足 | 检查网络与剩余额度 |
| 误删了文献 | 移到回收站 | 在回收站恢复即可 |
| 找不到数据目录 | 版本路径不同 | 见 6.8.8 在设置里查看 |
| 备份 RDF 不含 PDF | 导出时未勾“导出文件” | 重新导出并勾选该选项 |
| 链接附件显示缺失 | 原文件被移动 / 改名 | 恢复原路径，或重设 base directory |
| 两台设备内容不一致 | 一边未同步或登错账号 | 确认同账号，手动触发同步 |
| 导入 RDF 出现重复 | 选了“新建库”而非合并 | 用“合并到当前库”重导 |
| 同步冲突提示 | 两设备都改了同一文献 | 逐条比对合并，见 6.8.11 |

## 6.8.15 数据目录迁移（换电脑全盘搬迁）

如果旧电脑要退役，最稳妥的搬迁不是靠同步，而是直接搬数据目录：

1. 在旧电脑 Zotero 设置里查看“数据目录位置”，关闭 Zotero。
2. 把整个数据目录文件夹复制到移动硬盘或网盘。
3. 新电脑安装同版本 Zotero，首次启动时在设置里把“数据目录位置”指向复制过来的文件夹（或先复制过去再启动）。
4. 启动后题录、PDF、笔记全部就位，无需重新导入。

::: warning 版本尽量一致
新旧电脑 Zotero 大版本尽量一致（如都是 Zotero 7），跨大版本迁移偶有兼容问题。若必须跨版本，先用 RDF 导出题录作为兜底，再搬数据目录。
:::

## 6.8.16 附件去重与文献库瘦身

文献库用久会臃肿，定期维护：

1. **去重条目**：运行重复项检查，合并字段最全者，转移附件与笔记后删空壳。
2. **清理无用 PDF**：“待读文献”里最终不引用的，连同附件删除，释放同步空间。
3. **链接附件优势**：大文件改用链接附件后，数据目录不再膨胀，瘦身效果明显。
4. **storage 文件夹**：存放存储副本 PDF，不要手动删里面的随机名文件，要用 Zotero 内删除条目来清理，否则数据库会指向失效文件。

## 6.8.17 隐私、账号与共享安全

1. **账号安全**：Zotero 账号关联你的全部题录，设置强密码，不在公用电脑勾选“记住我”。
2. **同步范围**：同步会把题录传到官方服务器，涉及未公开数据或涉密材料时注意脱敏，不要同步敏感内容。
3. **群组权限**：建群组时按需设只读 / 可编辑，避免成员误改或外泄（见 6.8.10）。
4. **备份脱敏**：提交或分享备份文件前，确认不含个人隐私或未授权材料。

## 6.8.18 备份介质对照

| 介质 | 优点 | 缺点 | 建议用途 |
| --- | --- | --- | --- |
| 移动硬盘 | 容量大、一次买断 | 易丢失损坏、需手动 | 全量数据目录月备份 |
| 学校 / 个人网盘 | 自动同步、异地 | 依赖网络、有容量上限 | RDF 周备份 + 链接附件 |
| 光盘 / 冷存储 | 长期稳定 | 读写不便 | 答辩后归档 |

## 6.8.19 文献库健康度自检与学期末归档

学期末或答辩前，对资料库做一次整体体检，确保它能长期可恢复、可复用：

| 自检项 | 合格标准 | 对应做法 |
| --- | --- | --- |
| 题录完整 | 每篇都有作者、年份、期刊 / 来源 | 跑一遍校对清单（见 6.6） |
| 无重复 | 无重复条目 | 重复项检查（见 6.6.14） |
| 附件可达 | 抽查 PDF 均能打开 | 随机点开 10 篇 |
| 标签整洁 | 总标签 ≤ 15、无变体 | 清理自动标签（见 6.5.7） |
| 已同步 | 官网与本地一致 | 手动同步一次核对 |
| 已备份 | 有近期 RDF + 数据目录备份 | 见 6.8.8、6.8.9 |

**学期末归档步骤：**

1. 完成上述自检，修掉发现的问题。
2. 导出一份最终 RDF，文件名标注日期（如 `thesis-zotero-20260601.rdf`）。
3. 复制整个数据目录到移动硬盘与网盘各一份。
4. 论文定稿与自动生成的参考文献表另存。
5. 若使用链接附件，把原 PDF 文件夹一并归档。

::: details 可复制的归档清单
逐项勾选，归档前确认全部完成：

- [ ] 题录校对完成（见 6.6），无字段缺失
- [ ] 重复项已合并（见 6.6.14）
- [ ] 抽查 10 篇 PDF 均能打开
- [ ] 标签总数 ≤ 15，无命名变体（见 6.5.7）
- [ ] 手动同步一次，官网与本地一致
- [ ] 导出最终 RDF 并标注日期
- [ ] 数据目录已复制到移动硬盘 + 网盘
- [ ] 论文定稿与参考文献表另存
- [ ] 链接附件的原 PDF 文件夹一并归档

:::

::: warning 归档后不要急着删源库
归档副本是“保险”，不是“清理理由”。毕业前务必保留本机资料库与网盘同步不中断，直到论文终稿被学校接收、查重存档完成。误删后再从备份恢复，既要时间也可能丢近期的笔记改动。
:::

## 6.8.20 提交成果

完成以下可检查产出：

1. 已登录同步账号的截图（隐去密码），并确认一次手动同步成功。
2. 一份导出的 RDF 备份文件（或导出对话框截图），证明已生成题录备份。
3. 书面说明：你的附件采用“存储副本”还是“链接附件”，以及本地备份（数据目录复制 / 网盘）存放在哪里。
4. 用 6.5 的四项自查加这一页的备份流程，确认资料库达到“可随时换设备继续写、误删可恢复”的状态。

::: tip 万一仍遇问题
若同步、备份或导入时遇到这里没讲到的情况，优先查阅 Zotero 官方文档 <https://www.zotero.org/support/> 与 Zotero 中文社区 <https://zotero-chinese.com>；涉及学校特定的存储或账号政策，以学校图书馆说明为准。把这条备份流程固定下来，文献就不容易丢。
:::
