# 6.6 题录校对、附件与阅读笔记

## 6.6.1 为什么必须手工校对题录

用连接器从知网、Web of Science 抓取文献，速度快但准确率不是 100%。错误常见来源包括：知网导出时作者名带方括号或分号、期刊名用了简称、页码写成“1-10+15”、英文文献大小写混乱、DOI 缺失等。这些错误单独看很小，但会在两个地方被放大：

1. **参考文献表。** 你最终交的论文文末，每一条都来自这些字段。一处错，整表都显得不专业，甚至被答辩老师指出格式硬伤。
2. **引用格式。** 引用样式（如 GB/T 7714）会从字段里拼出“（张三, 2020）”或“[1]”等，字段错则引用错，且往往成片出错。

下表对比“现在校对”与“定稿再改”的代价，说明为什么宁可提前花 2 分钟：

| 做法 | 单条耗时 | 100 条总耗时 | 风险 |
| --- | --- | --- | --- |
| 导入后逐条校对 | 约 2 分钟 | 约 3.3 小时，分散做 | 低，错误当场修 |
| 定稿前统一返工 | 约 5 分钟（要回查原文） | 约 8 小时，集中赶 | 高，易漏、易慌 |

## 6.6.2 右侧“信息”面板的字段详解

选中一条文献，右侧“信息”面板就是题录的编辑界面。先把每个字段认清楚，校对才有依据。

![Zotero 右侧信息栏](/images/zotero/z12-metadata-panel.svg)

*图 6-13 Zotero 右侧信息栏的题录字段。①条目类型 ②标题 ③作者 ④出版物 ⑤卷期页码 ⑥日期 ⑦DOI。*

| 字段（中文） | 字段（英文） | 作用与填写要点 |
| --- | --- | --- |
| 条目类型 | Item Type | 决定这条文献是期刊论文还是书，影响后续引用格式，见 6.6.4 |
| 标题 | Title | 论文 / 书名，注意保留副标题的冒号与破折号 |
| 作者 | Author | 支持“姓名”与“机构”两种作者类型；多人可上移下移排序 |
| 出版物 | Publication | 期刊名、出版社或学位授予单位 |
| 卷 | Volume | 期刊的卷号 |
| 期 | Issue | 期刊的期号 |
| 页码 | Pages | 起止页，格式见 6.6.5 |
| 日期 | Date | 出版年，必要时精确到月 |
| DOI | DOI | 数字对象标识符，能唯一定位文献，尽量补全 |
| URL | URL | 网页或开放获取链接 |
| 语言 | Language | 如 zh-CN、en，影响样式是否显示“等”“et al.” |
| 摘要 | Abstract | 便于检索和回忆，抓取通常自带 |
| 期刊缩写 | Journal Abbreviation | 部分样式需要，可留空 |
| ISSN | ISSN | 期刊编号，校验用 |
| 其它 | Extra | 自由字段，放基金号、引用备注等 |

::: tip 校对顺序建议
拿到一条抓取来的题录，按“条目类型 → 作者 → 出版物 → 卷期页 → 日期 → DOI → 语言”的顺序过一遍，比随机看更高效。先改会影响格式的（类型、作者），再看细节（页码、DOI）。
:::

## 6.6.3 作者字段的正确填法

作者栏是最容易出错、也最影响格式的地方：

1. 点击“作者”右侧的“添加”按钮，新增一行作者。
2. 在姓名框输入“姓, 名”形式，如“张, 伟”，Zotero 会按中文习惯显示“张伟”；英文输入“Smith, John”。
3. 若作者是机构（如“国家税务总局”），点击该行类型下拉，把“姓名”改为“机构（Organization）”，否则样式会把它当成人名处理，生成错误的“国, 家”之类。
4. 多篇作者时，用每行右侧的上移 / 下移箭头调整顺序，第一作者决定引用时的署名。

::: warning 作者顺序与“等”
中文论文引用常写“张三等（2020）”，英文写“Smith et al.”，这由作者数量和语言字段共同决定。如果作者顺序填反，或者把通讯作者放第一位，引用就会出错。校对时务必对照原文首页的作者次序。
:::

## 6.6.4 条目类型的正确选择

引用样式对“期刊论文”和“学位论文”的格式要求不同（例如文献类型标识 [J] 与 [D]）。Zotero 抓取时偶尔会判错，需要手动修正。

| 抓取常见错误类型 | 实际应为 | 判断依据 |
| --- | --- | --- |
| 知网学位论文被识别为“期刊论文” | 学位论文（Thesis） | 来源是“授予单位 + 年份”，有导师字段 |
| 会议论文被识别为“期刊论文” | 会议论文（Conference Paper） | 出版物含“会议”“论文集”字样 |
| 图书章节被识别为“图书” | 书的章节（Book Section） | 有“主编”“出自”字段，页码是其中一段 |
| 政府公告被识别为“网页” | 报告（Report）或政策文件 | 发布主体是机关单位，有文号 |
| 报纸文章被识别为“网页” | 报纸文章（Newspaper Article） | 来源是报纸名 + 版面 |
| 数据集页面被识别为“网页” | 数据集（Dataset） | 平台标注为 data / dataset |

常用条目类型清单：期刊论文（Journal Article）、学位论文（Thesis）、会议论文（Conference Paper）、图书（Book）、书的章节（Book Section）、报告（Report）、报纸文章（Newspaper Article）、网页（Web Page）、数据集（Dataset）。修改类型：在右侧“信息”面板顶部“条目类型”下拉中选择正确项，部分字段会随之增删。类型选错是参考文献表格式大面积出错的首要原因，务必先核对此处。

## 6.6.5 中文文献字段的四个高频错误

知网抓取的中文文献，以下四类错误出现频率极高，逐条给出处理办法。

**错误一：作者字段变成一长串。**
表现：作者栏只有一行，内容是“张三;李四;王五”或“张三,李四,王五”，样式无法识别多人。
处理：
1. 清空该长串。
2. 逐行点击“添加”，分别输入每位作者（见 6.6.3）。
3. 若安装了“茉莉花（Jasminum）”等中文增强插件，可在右栏作者区使用“按分号拆分”功能一次性拆分。

::: tip 关于拆分插件
部分中文社区维护的插件提供作者批量拆分、期刊名标准化等功能（参见 Zotero 中文社区 <https://zotero-chinese.com>）。它们不是 Zotero 官方组件，使用前确认来源可信、与当前 Zotero 版本兼容，避免引入不稳定因素。
:::

**错误二：期刊名用了简称。**
表现：出版物写成“财研”而非“财政研究”，或英文期刊写成缩写却没在“期刊缩写”字段区分。
处理：把出版物栏改为期刊的规范全称；若某引用样式要求缩写，应填在“期刊缩写”字段，而不是覆盖全称。这样既满足样式，也保留检索价值。

**错误三：页码写成“1-10+15”这类带加号形式。**
表现：知网把跨页文章导成“1-10+15”，意思是正文 1–10 页、续在 15 页。
处理：
1. 打开原文核对真实起止页。
2. 若确为不连续页码，按学校规范写成“1-10,15”或保留“1-10+15”（以本校学位论文模板要求为准）。
3. 不要直接照抄加号让样式当作普通连字符，部分样式会因无法解析而报错或显示异常。

**错误四：语言字段缺失或 DOI 缺失。**
表现：中文文献“语言”为空，导致样式误判为英文、出现“et al.”而非“等”；或明明有 DOI 却没填，丢失唯一定位符。
处理：中文文献把“语言”填为 `zh-CN`（或 `zh`），英文填 `en`；DOI 去期刊页复制，格式如 `10.1234/abc.2020.01.005`，不含前缀 `https://doi.org/`。

| 字段 | 可疑迹象 | 正确做法 |
| --- | --- | --- |
| 作者 | 含分号 / 逗号挤一行 | 逐行拆分 |
| 出版物 | 两三个字如“财研” | 改规范全称 |
| 页码 | 含“+”号 | 按学校模板改 |
| 语言 | 空着 | 填 zh-CN / en |
| DOI | 含 `https://` 前缀或空 | 只留 `10.xxxx` 部分 |

## 6.6.6 从 PDF 自动提取元数据

如果你只有一篇 PDF、没有现成题录，可以让 Zotero 尝试从 PDF 文字中提取信息：

1. 在左栏选中该 PDF 条目（或先建一个空条目再挂 PDF）。
2. 右键条目，选择「抓取 PDF 元数据」（Retrieve Metadata for PDF）。
3. Zotero 会联网匹配，匹配成功则自动补全标题、作者、期刊、年份等字段。
4. 匹配失败则保持空白，需回到 6.6.7 手工填写。

::: warning 自动提取的成功率
该功能依赖 PDF 内嵌的文字信息。对**中文文献**和**扫描版（图片型）PDF**成功率较低，因为前者识别困难、后者根本没有文字层。遇到失败不要反复重试，直接手工建条目更高效。
:::

## 6.6.7 手工新建条目

当抓取失败或来源不支持连接器时，手工新建最可靠：

1. 点击工具栏绿色加号（“新建条目”）。
2. 在弹出的类型列表里选择正确条目类型，如“期刊论文”。
3. 右侧“信息”面板出现空白字段，逐字段填写。
4. 填“出版物”时，输入期刊名开头，Zotero 会自动联想已存在的期刊，选中即可避免重复建刊。
5. 填完标题、作者、日期、卷期页、DOI 后，条目即在库中生成。

::: tip 先建刊再建文
如果同一期刊有多篇文章，第一次输入期刊名并让它联想保存后，后续文章选同一个期刊，能减少拼写不一致，也方便以后统一改刊名（例如期刊更名时一次改全）。
:::

## 6.6.8 附件管理

PDF 全文是写作时真正要读的材料，必须作为条目附件妥善管理。

**添加附件的两种方式：**

1. 右键条目，选择“添加附件”。
2. 选择“附加文件副本（Attach Stored Copy of File）”：把 PDF 复制进 Zotero 数据目录，由 Zotero 托管，换电脑同步后仍在。
3. 或选择“链接到文件（Attach Link to File）”：只记录一个指向你电脑原文件的链接，不复制，适合大文件或已有整理习惯的情况（详见 6.8）。

| 方式 | 存储位置 | 适用场景 |
| --- | --- | --- |
| 存储副本 | Zotero 数据目录内 | 大多数情况，保证同步后不丢 |
| 链接到文件 | 你指定的原路径 | 文件已归类、体积大、多设备用同一网络盘 |

**从公开来源反查 PDF：**

1. 选中只有题录、没有全文的条目。
2. 右键选择“查找可用的 PDF（Find Available PDF）”。
3. Zotero 会尝试从开放获取来源下载；**对中文文献（如知网）成功率有限**，多数需要你手动从学校图书馆下载后“附加文件副本”。

**查看附件的实际路径：**

1. 右键条目下的附件图标（PDF）。
2. 选择“显示文件（Show File）”，系统文件管理器会打开该 PDF 所在位置，便于核对。

**多附件的注意：** 一个条目可以有多个附件（如正文 PDF + 附录 Excel）。但**同一篇 PDF 不要重复挂在多条条目下**，否则更新一份、另一份还是旧的，容易引用到错误版本。

## 6.6.9 阅读与批注

校对完成后进入阅读。Zotero 内置 PDF 阅读器，不必另开 Adobe，批注也会随条目一起保存和同步。

![Zotero 内置 PDF 阅读器与批注](/images/zotero/z13-pdf-reader.svg)

*图 6-14 Zotero 内置 PDF 阅读器。①页面缩略图 ②批注工具（高亮/下划线/便签/区域截图）③批注颜色 ④侧栏批注列表 ⑤笔记区。*

**打开阅读器：**

1. 在中栏双击条目的 PDF 附件图标，或选中条目后点击右侧“附件”区的 PDF。
2. 阅读器在新标签页打开，左侧为页面缩略图，右侧为批注与笔记区。

**批注工具的分工：**

| 工具 | 用途 | 建议颜色 |
| --- | --- | --- |
| 高亮 | 标记关键句、结论 | 黄色 = 结论 |
| 下划线 | 标记定义、变量说明 | 蓝色 = 定义 |
| 便签（Sticky Note） | 写下你自己的判断、疑问 | —— |
| 区域截图 | 摘录图表、公式 | 绿色 = 方法相关 |

::: tip 用颜色固定含义
建议全库统一：黄色标“结论”、绿色标“方法”、红色标“与自己观点冲突”。写作时扫一眼颜色就能回想起这篇文献的可用之处，不必重读整篇。
:::

## 6.6.10 从批注到笔记

批注定位原文，笔记形成你自己的理解。两者要衔接起来，否则读完一批高亮，过两周还是不知道这篇文献“对我有什么用”。

**把批注转成笔记：**

1. 在阅读器里选中一条批注（高亮或便签）。
2. 右键选择“添加到笔记（Add to Note）”。
3. 选择“新建笔记”或某条已有笔记，批注内容即被摘录进去，并保留指向原文的链接。

**新建独立笔记：**

1. 选中条目，在右侧切换到“笔记”页。
2. 点击“添加笔记”，输入标题与正文，支持富文本与插入引文。

![Zotero 条目下的笔记](/images/zotero/z14-item-notes.svg)

*图 6-15 条目下的笔记与子条目结构。*

笔记是条目的子条目：在条目前面的三角箭头展开后，能看到它名下的所有笔记。写作时展开即可回顾，不必重新打开 PDF，也方便把多篇笔记对照着写综述。

## 6.6.11 笔记的三层结构（重点方法）

一篇合格的文献笔记应当分成三层，缺一不可：

1. **内容摘要**：作者研究了什么、用了什么材料、得到什么结论。用自己的话，不抄原文。
2. **证据摘录**：可核对的原文、页码、表格位置，**必须标明“原文”**，便于日后引用时回头核实。
3. **我的判断**：对我的选题有什么用、有什么局限、能否与其他研究比较。

下面是一篇填好的示例笔记（税收学场景，研发费用加计扣除主题）：

> **标题**：《研发费用加计扣除政策对企业创新的影响——基于制造业上市公司的实证》
> **内容摘要**：作者以 2015–2021 年 A 股制造业上市公司为样本，用加计扣除比例提高作为外生冲击，双重差分发现政策使研发投入强度提高约 0.8 个百分点，发明专利申请量显著上升，但效果在国有企业更弱。材料来自国泰安数据库与年报。
> **证据摘录**（原文，p.12）：“加计扣除比例每提高 1 个百分点，企业 R&D 强度平均提升 0.8 个百分点。”（原文，表 3）：处理组发明专利申请数平均多 7.3%。
> **我的判断**：这篇可直接支撑我论文“机制”章的“政策促进创新”论点；局限是样本只到 2021，我可补充 2022 年以后数据；与李×的相反结论（认为存在“为享优惠而注水”）形成对照，综述里要讨论。

非实证文献也能用三层结构。看一个“政策文件类”的简短示例：

> **标题**：《关于完善研究开发费用税前加计扣除政策的通知》（财税〔2015〕119 号）
> **内容摘要**：文件将加计扣除范围扩大到除负面清单外的行业，明确归集口径与追溯享受机制，是当前加计扣除的核心依据。
> **证据摘录**（原文）：“除规定不宜加计扣除的行业外，企业符合条件的研发费用均可加计扣除。”
> **我的判断**：这是我论文“政策背景”章的立论依据，需引用文号与发文机关；注意 2023 年又有新政，写作时要引用最新版本。

这三层对应着写作的三个动作：摘要帮你回忆“它讲了什么”，证据摘录保证“你引的每一句都有出处”，我的判断决定“它进你论文的哪一段、以什么姿态出现”。

## 6.6.12 阅读卡片模板

除三层笔记外，建议给每篇核心文献填一张“阅读卡片”，方便横向比较、也方便写文献综述时快速调用。可直接复制到笔记里使用：

| 字段 | 填写内容 |
| --- | --- |
| 研究问题 | 这篇文献想回答什么 |
| 数据与材料 | 用了什么数据、样本区间、来源 |
| 方法 | 实证策略（如 DID、IV）、识别假设 |
| 主要结论 | 最核心的 1–3 条发现 |
| 局限 | 样本、识别、外部有效性等方面不足 |
| 可用于本文的哪一部分 | 背景 / 机制 / 方法 / 对策 / 综述 |
| 我的疑问 | 读不懂或想追问的地方 |

::: tip 卡片与三层笔记的关系
三层笔记是“深读一篇”的产物，阅读卡片是“横向比较多篇”的工具。建议先写三层笔记，再从中提炼出一张卡片；写到综述时，把同一“可用于本文的哪一部分”的卡片排在一起，就是一段现成的综述骨架。
:::

## 6.6.13 批注与笔记的分工提醒

**批注定位原文，笔记形成你自己的理解。** 不要把大段原文摘录直接当成“我的判断”，否则写作时极易把别人的话误写成自己的，构成不当引用（与本书“学术道德”部分呼应）。三层笔记里，“证据摘录”必须标注“原文”，“我的判断”必须用自己的语言，两者在版式上也要分得开，例如用分隔线或不同标题区隔。

## 6.6.14 批量校对与插件辅助

当文献量达到几十篇时，逐条点开校对仍显低效，可以借助批量手段：

**合并重复项：**

1. 菜单「工具 → 查找重复项」（不同版本位置略有差异）。
2. Zotero 列出疑似重复，逐组对比，保留字段更完整的那一条。
3. 合并时选择把被合并条目的附件、笔记一并转移，再删除空壳。

**批量编辑字段：** 选中多条同类文献后，部分字段（如语言、期刊缩写）可在右侧批量统一；也可借助中文社区插件的“批量修改”功能。

**中文增强插件（茉莉花 Jasminum）常用功能：**

| 功能 | 解决什么 |
| --- | --- |
| 作者按分号拆分 | 错误一的一键处理 |
| 期刊名标准化 | 把简称批量改成全称 |
| 知网链接抓取 | 从题录反查并补全知网信息 |
| 标题繁简转换 | 繁体文献转简体便于统一 |

::: warning 插件不是万能
插件能显著提升中文文献整理效率，但它不是 Zotero 官方组件，安装前确认与当前 Zotero 版本兼容、来源可信。插件处理完之后，仍建议抽样复核几条，防止批量误改。
:::

## 6.6.15 校对后的反向检查

校完一遍之后，交稿前再做一次反向抽查：

1. 从资料库随机抽 5 条题录，回到知网 / 原文逐字段核对。
2. 从文末（若已生成参考文献表）随机抽 5 条，回 Zotero 核对题录。
3. 专门检查 DOI 是否可点击跳转、期刊名是否全称、页码连接符是否规范。
4. 把抽查发现的共性问题（如某批文献都缺语言字段）批量补上。

## 6.6.16 校对与阅读常见问题速查表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 引用里作者显示成一长串 | 作者字段未拆分 | 见 6.6.5 错误一，逐行重填或用插件拆分 |
| 参考文献里期刊名是简称 | 出版物字段填了缩写 | 改为规范全称，缩写放“期刊缩写”字段 |
| 页码出现“+15”导致格式报错 | 知网跨页导出 | 按学校模板改成“1-10,15”或保留原样 |
| 英文样式出现“等”而非“et al.” | 语言字段缺失 | 见 6.6.5 错误四，填 `zh-CN` / `en` |
| 右键没有“抓取 PDF 元数据” | 选中的是条目而非 PDF 子项 | 展开条目，选中其下 PDF 再右键 |
| PDF 双击打不开阅读器 | 系统默认关联了其他软件 | 在 Zotero 内双击，或右键“打开” |
| 笔记找不到了 | 笔记是子条目，被收起 | 点条目前的三角箭头展开查看 |
| 批注颜色想统一改 | 批注颜色逐条设置 | 建立习惯：黄 = 结论、绿 = 方法、红 = 冲突 |
| 条目类型选错导致 [J]/[D] 混乱 | 抓取误判 | 见 6.6.4 对照表修正 |
| 重复项合并后附件丢了 | 合并未勾选转移附件 | 合并时确认附件一并转移 |

## 6.6.17 课堂实操

完成以下可检查产出：

1. 从资料库挑出 5 条抓取来的题录，**逐字段校对**：修正作者拆分、期刊全称、页码格式、条目类型，补全 DOI 与语言字段（能找到的话）。
2. 选 2 篇已下载 PDF 的文献，用内置阅读器做完整批注：至少 3 处高亮（结论 / 方法 / 冲突用不同颜色）+ 1 条便签写自己的疑问。
3. 为这 2 篇各写一条三层结构笔记（内容摘要 / 证据摘录【标原文】 / 我的判断），并填好一张阅读卡片。
4. 把批注用“添加到笔记”汇总进对应笔记，确认条目前的三角箭头能展开看到笔记。
5. 运行一次重复项检查，对发现的重复做合并（保留字段完整者）。
