# 1.1 为什么要写毕业论文

## 1.1.1 先想清楚：毕业论文究竟是什么

很多同学第一次接触毕业论文时，会把它理解成“字数更多、格式更复杂的课程作业”。这种理解只看到了论文的外形，没有看到论文背后的训练目标。

毕业论文是一项限时完成的小型研究。它不要求本科生解决一个学科领域的全部问题，也不要求每个人都发表重大成果，但要求你能够：

- 从真实材料或已有研究中发现一个值得讨论的问题
- 把问题缩小到自己能够完成的范围
- 用文献、数据或案例支撑自己的判断
- 说明研究过程、方法和局限
- 按照学术规范向读者交代资料来源

因此，论文的价值不只在于“最后交上去”，更在于你是否经历了一次完整、真实、可检查的研究过程。

## 1.1.2 毕业论文不是“最后交的一篇长作业”

毕业论文要求你把四年学习转化为一个完整的研究过程：

1. 从现实或学术材料中发现问题
2. 把问题表达成可以研究的题目
3. 找到能够支持判断的文献和数据
4. 用清晰的方法组织证据
5. 对结果作出边界清楚的解释
6. 按规范向读者说明来源

这也是为什么一篇篇幅并不长的本科论文，仍然能够检验综合能力。教师和评审者关注的并不只是字数，而是你的问题、证据、方法和结论能否彼此对应。

## 1.1.3 论文训练了哪些能力

### 逻辑能力

论文不是观点堆积，而是有依据、有顺序的论证。研究背景要能推导出研究问题，文献综述要能说明已有研究走到了哪里，研究方法要能回应研究问题，结论要能回到证据本身。

可以把论文的基本逻辑概括为：

```text
为什么要研究 → 研究什么 → 别人研究了什么
        → 我怎样研究 → 得到什么结果 → 结果说明什么
```

如果其中一个环节缺失，论文就容易出现“背景很大、问题很小”“文献很多、方法不清”或“结论超过证据范围”等问题。

### 信息能力

你需要判断哪些资料值得使用，哪些只是网络上的二手转述；还要能够快速定位论文的研究问题、数据和结论。对于税收学专业的学生来说，政策文件、统计数据、学术论文、行业报告和新闻材料的权威程度和用途并不相同，不能简单地混在一起使用。

### 表达能力

论文训练的是可复核的表达：读者能够知道你的材料从哪里来、你做了什么处理，以及你的结论适用于什么范围。好的表达不是把句子写得复杂，而是让读者能够顺着你的文字重建研究过程。

### 反思能力

研究过程中一定会遇到数据不足、结论不一致或方法限制。承认边界、解释原因，是研究能力的一部分。论文不是“证明自己一开始完全正确”，而是让读者看到你如何面对不确定性。

### 时间管理能力

毕业论文通常从选题、检索、阅读到开题和初稿逐步推进。把任务拆成阶段目标，及时向指导教师汇报，比在最后几周集中赶工更重要。


## 1.1.4 学位论文与学术论文的区别

学位论文属于学术论文的一种，但两者的使用场景不同：

| 比较维度 | 学位论文 | 一般学术论文 |
| --- | --- | --- |
| 写作目的 | 完成培养和学位要求 | 交流和发表研究成果 |
| 读者 | 指导教师、评审专家、答辩委员会 | 学术共同体和期刊读者 |
| 选题范围 | 通常允许更完整地呈现研究过程 | 更强调问题集中和篇幅控制 |
| 评价重点 | 规范性、完整性、研究训练 | 问题价值、方法质量和学术贡献 |

本科阶段不必一开始就把自己当成成熟学者，但必须认真完成研究过程。

## 1.1.5 关于毕业论文的三个常见误解

### 误解一：论文必须提出特别惊人的创新

本科论文首先要做到问题清楚、材料真实、方法合适和表达规范。创新可以是研究对象、资料、指标、方法或分析角度的变化，不必把目标设定为建立一套全新的理论。

### 误解二：查重率低就说明论文合格

查重只能发现部分文字相似现象，不能证明数据真实、引用准确或论证成立。降低重复率不能替代阅读、思考和规范引用。

::: tip 两个率的要求
- 重复率 ≤ 28%
- AIGC率 ≤ 30%
:::

### 误解三：等题目完全确定后再读文献

选题和阅读是循环推进的。初步检索可以帮助你发现概念、研究争议和数据线索，从而反过来修正题目。

## 1.1.6 满足条件可以申请抵作毕业论文

我校根据学校培养方案和具体管理办法，允许同学以调研报告、商业策划、学科竞赛成果、论文或著作、专利发明以及其他符合要求的成果，申请替代传统毕业论文（设计）。但这类替代并不是“只要有一个作品就可以直接免写”，通常仍然需要经过成果认定、材料审核和学院审批。

[浙江越秀外国语学院关于印发《本科毕业论文（设计）多样化管理办法（试行）》的通知](</attachments/浙越外发〔2022〕273号 浙江越秀外国语学院关于印发《本科毕业论文（设计）多样化管理办法（试行）》的通知.pdf>)

因此，阅读相关文件时，建议重点关注以下内容：

- 哪些成果类型可以申请替代
- 成果需要达到什么质量或形式要求
- 是否需要同时提交说明、报告或支撑材料
- 申请时间、审核部门和审批流程是什么
- 替代成果是否仍然需要答辩、评审或抽检
