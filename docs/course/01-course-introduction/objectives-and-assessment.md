# 1.2 课程目标与考核办法

## 1.2.1 这门课要解决什么问题

很多同学不知道研究从哪里开始：

- 选题的灵感来自于哪里
- 题目太大，不知道如何缩小
- 不知道如何检索有用的文献
- 搜到很多文献，不知道哪些真正相关
- PDF 下载了很多，却找不到想用的内容
- 文献综述变成逐篇摘要
- 参考文献格式反复出错
- 开题报告的每一部分互相脱节

本课程的目标，就是把这些模糊困难拆成可以练习、可以检查的具体任务。

## 1.2.2 课程目标

1. **学术规范**：能够判断什么必须引用，避免抄袭、伪造、代写和不当使用 AI
2. **问题意识**：能够把宽泛兴趣转化为具体、可研究的问题
3. **检索能力**：能够设计关键词并找到与研究问题真正相关的文献
4. **管理能力**：能够整理题录、附件、标签、批注和引用信息
5. **综合能力**：能够归纳、比较和评价已有研究，而不是逐篇摘抄
6. **研究设计**：能够用开题报告说明研究内容、方法、技术路线和进度


## 1.2.3 六大模块的关系

```text
学术道德
    ↓
论文选题 → 知网检索 → Zotero管理 → 文献综述
    └──────────────→ 开题报告与课程报告
```

学术道德是底线，选题决定方向，检索和管理提供材料，文献综述形成判断，开题报告把判断转化为研究计划。

## 1.2.4 课程考核结构

本课程采用“过程性学习 + 期末课程报告”的方式。成绩构成为：

- 平时成绩：60%
  - 课堂表现：10%
  - 课堂作业约 2 次：30%
  - 综合作业：20%
  - 优秀表现可作为特别奖励
- 期末课程报告：40%
  - 重点考查选题、文献综述、研究设计和参考文献规范

::: warning 作业和课程报告提交要求
- 最迟提交时间：**第 10 周**
- 期末课程报告需要提交**电子版**和**纸质版**
- 电子版上传至云班课，纸质版打印后交给学委
- 作业只提交**电子版**，提交到`云班课`
- 具体文件命名、格式和截止时间以课堂通知及云班课公告为准
:::

## 1.2.5 评分时重点看什么

重点考查：

- 是否真正回应自己的研究问题
- 是否说明材料、数据和方法的来源
- 是否有清晰的结构和段落逻辑
- 是否区分自己的判断与他人的观点
- 是否做到引文与参考文献对应
- 是否根据反馈完成修改
