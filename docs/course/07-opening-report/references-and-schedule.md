# 7.7 参考文献与进度安排

第六、第七部分是开题报告的收尾。第六部分交代“什么时候做什么”，第七部分交代“依据了哪些材料”。两部分的写法都不复杂，但都是答辩时容易被挑格式问题的地方。

## 7.7.1 进度安排：写成可检查的任务

进度表常见的问题是只写大阶段，例如“查阅文献”“撰写论文”“修改论文”——这些无法检查，也无法判断是否延期。合格的进度表要把每个阶段的**产出**写清楚：

| 阶段 | 任务 | 产出 |
| --- | --- | --- |
| 1 | 确定选题方向，初步检索 | 选题说明、检索记录 |
| 2 | 扩展检索，精读核心文献 | Zotero 文献库、阅读卡片 |
| 3 | 撰写文献综述 | 文献综述初稿 |
| 4 | 完成研究设计，确认数据来源 | 变量定义表、框架图、技术路线图 |
| 5 | 数据收集与整理 | 清洗后的数据文件 |
| 6 | 实证或案例分析 | 结果表、图表 |
| 7 | 撰写论文初稿 | 论文初稿 |
| 8 | 修改、查重、定稿 | 定稿、查重报告 |

## 7.7.2 学院进度表的常见阶段

学院会统一发布一份毕业论文进度表，里面是一串**固定顺序**的节点。开题报告的这一栏，通常直接抄录学院进度表，而不是自己另写一份。学院进度表一般包含下列环节（具体日期以当年通知为准）：

1. 选题完成、任务书上传完成
2. 开题报告及答辩
3. 完成毕业论文初稿并上传、初期检查
4. 二、三稿上传，完成毕业论文中期检查
5. 定稿完成、上传查重稿系统完成
6. 完成论文查重、交叉评阅
7. 学校外审
8. 第一次毕业论文答辩
9. 第二次毕业论文答辩
10. 答辩后上传完善后的最终稿、成绩评定完成
11. 纸质稿材料上交、资料归档

::: warning 日期以学院当年通知为准
每年各环节的具体时间节点都会调整，往届模板上的日期不能照抄。正确做法是：先向指导教师确认当年进度表，把时间节点填进这一栏，再核对与自己其他安排（实习、考试、求职）是否冲突。如果某个节点确认来不及，要在开题答辩时就说明，而不是等中期检查时才提。
:::

## 7.7.3 参考文献的基本要求

必须遵守的要求：

| 要求 | 说明 |
| --- | --- |
| 有引必有录 | 正文引用了的，文末必须出现；文末列出的，正文必须引用过 |
| 格式统一 | 著录格式前后一致；DOI 号要么都写，要么都不写 |
| 排序方式 | 开题报告一般要求中文文献在前、英文文献在后；正文引用顺序需与文末编号对应 |
| 文献类型比例 | 以期刊论文为主，学位论文、报刊、书籍等作为补充 |
| 数量下限 | 一般要求 15 篇以上，其中外文文献不少于 2 篇，建议外文 3—5 篇 |
| 标注方式 | 正式论文中按顺序编号，并在正文中以方括号上标标注 |

数量的下限只是门槛。真正重要的是相关性、可核查性和格式一致性——评委翻到参考文献，先看的是格式是否整齐、有没有正文里根本没提过的材料。

## 7.7.4 著录格式：GB/T 7714

知网等数据库支持直接导出题录，导出时选择 **GB/T 7714** 格式即可，比自己手敲可靠得多。各种文献类型的著录格式如下（格式示例，非真实文献）：

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 期刊论文（中文） | 作者. 题名[J]. 刊名，年，卷(期)：起止页码. | 张三，李四. 某税收政策的经济后果研究[J]. 某某研究，2024，40(05)：96-108. |
| 期刊论文（外文） | Author A A, Author B B. Title[J]. Journal Name, Year, Vol(Issue): pages. | Bai F, Liu D, Dong K, et al. Research on how executive connections affect enterprise digital transformation[J]. Sustainability, 2023, 15(3): 2037. |
| 学位论文 | 作者. 题名[D]. 城市：学校，年. | 张三. 某某问题研究[D]. 绍兴：某某大学，2025. |
| 专著 | 作者. 书名[M]. 版本. 出版地：出版社，年：页码. | 李四. 税收经济学[M]. 北京：某某出版社，2023：56-60. |
| 报纸 | 作者. 题名[N]. 报纸名，出版日期(版次). | 张三. 某某政策解读[N]. 某某日报，2025-03-10(03). |
| 电子资源 | 作者. 题名[EB/OL]. (发布日期)[引用日期]. 网址. | 某某部. 某某统计公报[EB/OL]. (2025-01-20)[2025-09-10]. <https://www.example.gov.cn/report>. |

::: warning 中英文混排时的三个细节
一是英文条目的作者姓名写法要与中文条目统一（姓前名后、是否缩写要一致）；二是英文题名的首字母大写方式要统一；三是中文文献里的中文标点要用全角，英文文献里的标点用半角，不要把两者混在一起。
:::

## 7.7.5 用 Zotero 生成并逐条核对

参考文献不建议手写，用 Zotero 生成效率高得多，流程是：

1. 在 Zotero 中确认每条题录的作者、年份、刊名、卷期、页码完整（做法见 6.6）
2. 在正文中插入引用，并选定 GB/T 7714 样式（做法见 6.7）
3. 生成参考文献表后，**逐条核对**：
   - 正文引到的文献，文末是否都有
   - 文末列出的文献，正文是否都引到
   - 作者名、年份、刊名有没有错字或缺失
   - 卷期与页码是否完整
   - DOI 是否统一取舍
4. 把参考文献表复制到开题报告模板的第七栏，去掉域代码，保留纯文本

::: tip 导出后一定要人工过一遍
数据库导出的题录经常有错：作者姓与名颠倒、卷号与期号串位、页码缺失、期刊名简写不规范。Zotero 也是一样——它只是把数据库给的信息搬过来，不会替你把错误找出来。所以“生成”之后必须“核对”，这一步不能省。
:::

## 7.7.6 常见问题

| 问题 | 后果 | 处理 |
| --- | --- | --- |
| 引而不录 | 涉嫌学术不规范 | 用 Zotero 的“未引用条目”功能反查，逐条补齐 |
| 录而不引 | 文末出现无效文献 | 删除，或回到正文补上引用 |
| 来源单一 | 全是学位论文，或全是网络资料 | 补充期刊论文；以期刊为主，其余为辅 |
| 年份过旧 | 看不出研究前沿 | 补充近三年文献，制度沿革类文献除外 |
| 格式混乱 | 同一栏里有三种写法 | 统一导出格式，重新生成一遍 |
| 外文不足 | 不满足模板下限 | 通过第五部分的方法补充外文检索 |
