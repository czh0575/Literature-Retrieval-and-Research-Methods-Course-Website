# 7.6 研究方法与技术路线

第五部分要回答的是“你打算怎么把前面说的事情做完”。它由两块内容组成：一块是文字说明的研究方法，一块是图示的技术路线。

## 7.6.1 方法不是越多越好

研究方法部分最常见的问题是“堆方法”：一篇论文里同时写了文献研究法、实证研究法、案例研究法、比较研究法、问卷调查法、规范研究法、交叉研究法……看起来方法齐备，实际上有三四个根本用不上。

判断标准只有一条：**每一个方法都必须对应你要回答的某个问题。** 用不上的方法不要写。写四个方法、每个都说清用来做什么，比写八个方法、每个只给一句定义要好得多。

## 7.6.2 常用方法清单

课件列出的方法，可以按用途归成几类：

| 类别 | 方法 | 典型用途 |
| --- | --- | --- |
| 文献类 | 文献研究法 | 梳理概念、理论沿革与已有成果 |
| 规范类 | 规范研究法 | 分析制度逻辑、问题成因与政策方案 |
| 规范类 | 比较法 | 比较不同地区、制度或时期的做法 |
| 实证类 | 实证研究法、定量分析、因果分析法 | 用数据和计量方法检验变量之间的关系 |
| 实证类 | 问卷调查法、访谈法 | 获取态度、动机、行为等一手资料 |
| 案例类 | 案例研究法 | 深入分析某一政策、地区或企业 |
| 交叉类 | 交叉研究法 | 借用其他学科的理论或工具分析本学科问题 |
| 综合类 | 定性分析 | 对文本、案例、制度进行解释性分析 |

同属一类的多个方法不必都写。例如已经写了实证研究法，通常不必再单列定量分析与因果分析法——它们本来就是实证研究的一部分。

## 7.6.3 每个方法写三层

每个方法用两三句写清楚：

1. **是什么**：一句定义，不必展开成教科书
2. **用来做什么**：具体到本文的哪个问题、哪一章节
3. **怎么做**：数据、样本、模型或材料是什么

第二层最容易被忽略，也最能体现水平。“文献研究法：通过查阅国内外相关文献，为本研究提供理论基础”这样的写法，等于什么都没说。“文献研究法：系统梳理国内外关于 X 经济后果与 Y 影响因素的研究成果，归纳已有研究的主要发现与不足，明确本文的研究空白”——这一句就把方法、对象和目的都交代清楚了。

## 7.6.4 技术路线是什么

课件给出的定义：**技术路线是为达到研究目标而采取的技术手段、具体步骤及解决关键性问题的方法在内的研究途径。** 呈现方式是流程图或示意图，也就是**技术路线图**。

技术路线与研究内容、研究方法的关系是：研究内容说“做什么”，研究方法说“用什么做”，技术路线说“**按什么顺序、经过哪些环节把它们串起来**”。三者不能互相替代。

## 7.6.5 技术路线图怎么画

![技术路线示意图](/images/opening/o05-roadmap.svg)

*图 7-5　技术路线示意图（实证类选题）*

画技术路线图时，注意四点：

- **自上而下**，用箭头标出推进方向，不要左右乱指
- **分阶段**：通常包括“提出问题—理论分析—研究设计—实证检验—结论建议”几个阶段
- **方法入图**：每个阶段旁边注明用到的方法或数据来源，让评委一眼看出方法落在哪一步
- **可执行**：图上的每一步都应该是你真的会做的动作，不要为了好看加入“构建指标体系”“开展问卷调查”等实际并不进行的环节

::: warning 技术路线图不能只有框图，没有内容
一张只写着“提出问题 → 分析问题 → 解决问题”的三段式子图，等于没有画。技术路线图的价值在于把**你的**研究对象、变量、数据、方法嵌进流程里。例如“收集沪深 A 股上市公司 20XX—20XX 年数据”就比“收集数据”有信息量得多。
:::

## 7.6.6 范例

::: details 范例：《环保费改税对企业数字化转型的影响研究》

**五、研究方法与技术路线**

**（一）研究方法**

本研究综合运用规范分析与实证分析相结合的方法，具体包括以下四种。

**第一，文献研究法。** 系统梳理国内外关于环保费改税经济后果与企业数字化转型影响因素的研究成果，归纳已有研究的主要发现与不足，明确本文的研究空白与创新切入点。

**第二，理论演绎法。** 基于环境规制理论、波特假说、合法性理论等，构建环保费改税影响企业数字化转型的理论分析框架，并在逻辑推演的基础上提出研究假设。

**第三，实证研究法。** 收集沪深 A 股上市公司数据，将《环境保护税法》实施视为一项准自然实验，构建双重差分模型进行基准回归，检验环保费改税对企业数字化转型的净效应。在此基础上，采用中介效应或调节效应模型检验作用机制，按产权性质、企业规模、地区及行业特征进行分组回归考察异质性，并通过平行趋势检验、安慰剂检验、替换变量度量等方式进行稳健性检验。

**第四，归纳总结法。** 根据实证分析结果归纳研究结论，提出差异化的政策建议，并说明研究局限与未来展望。

四个方法各有分工：文献研究法解决“别人做了什么”，理论演绎法解决“为什么可能这样”，实证研究法解决“到底是不是这样”，归纳总结法解决“所以怎么办”。四种方法正好覆盖了论文的全部章节，没有一个多余。方法内部又写到了具体的数据、模型和检验方式，不是空转。
