# 7.5 拟解决的关键问题与难点

第四部分是开题报告里篇幅最短、但最容易被追问的一栏。评委通常会从这里挑问题：你说这是关键问题，为什么？你说这是难点，你打算怎么克服？这一部分如果写得含糊，答辩时很难圆回来。

## 7.5.1 先分清两个概念

- **拟解决的关键问题**：也就是**研究重点**。指研究要开展的重点工作，或者开展过程中必须注意的重点环节。它指向研究中的基本问题、关键问题或核心问题。
- **研究难点**：指影响研究顺利进行的**实际困难**，需要你花大力气想办法克服。

两者有一个重要区别：难点是“**可以被克服**”的困难。克服不了的，不叫难点，叫**研究不足**。

::: warning 不要把“做不到”写成“难点”
“样本数据不全”“本人尚未掌握某软件”这类表述要谨慎。“目前还不会”可以通过学习解决，属于难点；“数据根本不存在”则意味着选题本身需要调整。研究不足应该写在论文的结论和展望里（“本研究的局限在于……”），而不是塞进难点一栏。把做不到的事说成难点，评委的第一反应是建议你换题。
:::

## 7.5.2 重点写 2 条，每条三层

课件的写法要求很具体：**研究重点写 2 条**，每条的结构是：

> 总起（研究重点是什么）+ 为什么它是重点

展开一点，一个完整的关键问题条目通常包含三层：

1. **问题本身**：用疑问句或陈述句说清楚要解决什么。例如“X 对 Y 的净效应及其作用方向”。
2. **为什么它是重点**：它决定了论文的核心结论，或者它是后续分析的前提。
3. **打算怎么解决**：用什么识别策略、什么变量、什么数据来回答它。

第三层最容易漏。只写“这是重点”而不写“怎么解决”，评委会认为你没有想清楚。

## 7.5.3 难点写 2 条，每条三层

研究难点同样写 2 条，结构是：

> 总起（研究难点是什么）+ 为什么它是难点 + 如何克服

第三层“如何克服”是关键。难点的价值不在于承认困难，而在于证明你**已经想好了应对方案**。例如：

- 难点：如何把政策的净效应与其他同期趋势区分开
- 为什么难：企业行为同时受到多重因素影响，简单的政策前后比较无法识别因果
- 如何克服：采用双重差分法设置处理组与对照组，并辅以平行趋势检验、安慰剂检验

这三层写完，答辩时评委就很难再追问下去。

## 7.5.4 重点与难点怎么区分

课件提醒：研究重点和研究难点有时指向同一套东西，关键是从什么角度论述。但为了保证两者有所区分，建议**围绕研究中的不同信息去写**。可以从三个层面选切口：

| 层面 | 重点示例 | 难点示例 |
| --- | --- | --- |
| 理论层面 | 构建 X 影响 Y 的理论分析框架 | 缺少现成理论直接适用于你的特定情境 |
| 逻辑层面 | 打通 X 与 Y 之间的机制链条 | 机制之间存在相互抵消的效应，方向不易判断 |
| 方法层面 | 构建或改造 Y 的度量指标 | 政策识别中处理组与对照组的选择存在争议 |

一个稳妥的搭配是：**重点写“逻辑层面 + 方法层面”，难点写“方法层面 + 数据层面”**。这样两者既有关联又不会重复。

::: tip 一个简单的检验办法
把“重点”和“难点”两栏的文字互换位置。如果读起来毫无违和，说明你写的其实是同一件事，需要重写其中一栏。
:::

## 7.5.5 范例

::: details 范例：《环保费改税对企业数字化转型的影响研究》

**四、拟解决的关键问题及难点**

**（一）拟解决的关键问题**

**1. 环保费改税对企业数字化转型的净效应及其作用方向**

在控制其他因素之后，环保费改税整体上促进还是抑制企业数字化转型？针对这一问题，本研究拟将《环境保护税法》实施视为一项准自然实验，采用双重差分法构建计量模型。在变量测度上，采用上市公司年报文本分析等方法构建企业数字化转型指标，并控制企业规模、资产负债率、盈利能力、成长性、产权性质等企业层面特征以及企业与年份固定效应。

**2. 环保费改税影响企业数字化转型的具体机制与情境条件**

环保税政策通过成本约束、创新补偿、融资约束、信息披露等何种渠道作用于企业数字化转型？该影响在不同产权性质、企业规模、地区及行业之间是否存在显著异质性？对此，本研究选取环保投资、研发投入、融资约束、环境信息披露质量等中介变量或调节变量，采用中介效应模型或调节效应模型进行检验，识别政策影响数字化转型的具体路径。在情境条件方面，按产权性质、企业规模、所在地区及行业特征进行分组回归，比较不同子样本中政策效应的差异。

**（二）拟解决的难点**

如何有效剥离环保费改税政策对企业数字化转型的净影响，避免将其与同期其他宏观环境趋势所驱动的数字化转型增长相混淆。企业数字化转型受数字经济整体演进、产业政策调整、技术进步等多重因素共同影响，若仅进行简单的政策前后比较，难以准确识别环保费改税这一特定制度变革的因果效应。为克服上述难点，本研究拟采用双重差分法，通过设置处理组与对照组，计算二者在政策实施前后数字化转型变化的差值，从而在较大程度上剔除共同趋势与其他混杂因素的干扰，相对干净地识别环保费改税对企业数字化转型的净效应。在此基础上，结合平行趋势检验、安慰剂检验等稳健性检验，进一步验证因果识别的可靠性。

::: tip 这个范例好在哪
两条关键问题的标题本身就是完整的研究问题（“净效应及其作用方向”“具体机制与情境条件”），标题下面依次交代了问题、做法和变量。难点只有一条，但“为什么难”和“如何克服”都写足了——特别是“为克服上述难点，本研究拟采用……”这一句，把难点直接转化成了方法设计的说明，与第五部分自然衔接。
:::
