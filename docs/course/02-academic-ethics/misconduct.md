# 2.1 学术不端的类型与边界

## 2.1.1 学术诚信的基本含义

学术诚信要求研究者如实说明：

- 观点是谁提出的
- 材料从哪里来
- 数据如何获得和处理
- 哪些工作由谁完成
- 哪些结论仍然存在不确定性

学术规范的核心不是让所有文章写成同一种样子，而是让读者能够复核你的研究。

## 2.1.2 常见类型

### 抄袭与剽窃

直接复制他人的句子、结构、观点或数据，却不作明确引用。即使修改了几个词，只要核心表达和论证结构仍然来自他人，也不能当作自己的原创。

### 伪造与篡改

伪造是编造不存在的数据、访谈、文献或实验结果；篡改是对真实材料进行不当修改、删减或选择性报告，使结果看起来符合预期。

### 不当署名

- 没有参与研究却署名
- 参与研究却被故意漏署
- 未经同意使用他人姓名
- 没有说明各自贡献

### 买卖和代写

购买论文、委托他人代写，或者为他人代写，都会破坏评价的真实性。所谓“包通过”“包降重”并不能替代真实的研究过程。

## 2.1.3 三个容易混淆的边界

| 情形 | 是否需要说明来源 | 判断重点 |
| --- | --- | --- |
| 公共常识 | 通常不必 | 是否属于本学科普遍知道的事实 |
| 他人的具体观点 | 必须 | 读者能否看出观点来源 |
| 自己基于资料做出的分析 | 仍需引用资料 | 分析是自己的，证据来源不是 |

## 2.1.4 小练习

判断以下做法是否合适，并说明理由：

1. 把一篇论文的段落顺序保留，只替换同义词
2. 使用数据库中的统计表，但在图表下方标明来源
3. AI 生成了一条看似真实的参考文献，直接放入文末
4. 同学帮助清洗数据，但没有参与论文写作，是否需要说明
