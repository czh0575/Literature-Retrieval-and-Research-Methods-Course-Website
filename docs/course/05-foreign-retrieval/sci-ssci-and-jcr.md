# 5.5 SCI/SSCI 收录判定、JCR 分区与影响因子

## 5.5.1 先分清几组概念

在外文文献收集中，学生最常混淆的是“XX 是 SCI 吗”“这篇是几区”。回答这些问题，先要分清几组**收录体系（引文索引）**的概念。它们不是期刊等级，而是不同的数据库产品。

| 缩写 | 全称 | 中文名 | 覆盖学科 | 主要用途 |
| --- | --- | --- | --- | --- |
| SCI | Science Citation Index | 科学引文索引 | 自然科学（早期印刷版，已演进） | 历史概念，现多被 SCIE 取代 |
| SCIE | Science Citation Index Expanded | 科学引文索引扩展版 | 自然科学、工程技术 | 当前常说的“SCI”多指 SCIE |
| SSCI | Social Sciences Citation Index | 社会科学引文索引 | 社会科学（含经济、管理、法、教育等） | 经管法类外文期刊最常引用的收录体系 |
| A&HCI | Arts & Humanities Citation Index | 艺术与人文引文索引 | 艺术、人文 | 文史哲艺类文献 |
| ESCI | Emerging Sources Citation Index | 新兴来源引文索引 | 多学科新兴期刊 | 收录标准低于 SCIE/SSCI，影响力待观察 |
| CPCI | Conference Proceedings Citation Index | 会议录引文索引 | 会议论文 | 会议文献，不与 SCI 混同 |

对税收学、财政学、公共管理方向的本科生而言，**SSCI 是最相关的收录体系**。许多顶尖的税收经济学、公共财政期刊均被 SSCI 收录；部分方法偏计量或偏自然科学的跨学科研究可能落在 SCIE。

::: warning 现在说的 SCI 多指 SCIE
现在学术界日常说的“SCI 期刊”，绝大多数指的是 **SCIE（Science Citation Index Expanded）**，而非早期印刷版 SCI。二者在正式文献层级判定中通常不作区分，但你应知道这个历史演变，避免在查阅旧资料时困惑。
:::

## 5.5.2 常见误解澄清

| 误解 | 正确认知 |
| --- | --- |
| “SCI 是期刊分级” | 错。SCI/SSCI 是**收录数据库**，只说明期刊被某索引收录，不等于等级高下 |
| “影响因子高就一定是好文献” | 错。影响因子是**期刊层面**指标，且学科差异极大，不能用来评价单篇论文 |
| “ESCI 就是 SCI” | 错。ESCI 是另一索引，收录标准与影响力均不同于 SCIE/SSCI |
| “会议论文也算 SCI” | 错。会议论文通常归 **CPCI**，与 SCI/SSCI 是不同索引 |
| “被 WoS 收录就是 SSCI” | 错。WoS 核心合集包含 SSCI、SCIE、ESCI、A&HCI、CPCI 多种，须看具体 Index 标识 |
| “Q1 期刊的每篇文章都值得引” | 错。Q1 是期刊整体表现，单篇质量仍需你亲自判断 |

::: tip 收录看索引，水平看分区，质量看单篇
三条判断线索：**收录看“索引”（Web of Science Index），水平看“分区”（JCR Quartile），质量看“单篇”（你自己读）**。三者层层递进，不能互相替代。
:::

## 5.5.3 如何确认一篇文献发表在 SCI/SSCI 收录期刊上

确认收录层级有三条相互印证的路径，建议至少用两条交叉验证。

### 路径一：在 WoS 中检索该文献，看记录标识

1. 在核心合集的检索框输入该文献的题名片段或 DOI。
2. 进入该文献的详情页（Full Record）。
3. 在来源信息区域查看 **Web of Science Index** 标识，会明确列出如 `Social Sciences Citation Index (SSCI)`、`Science Citation Index Expanded (SCIE)` 等。
4. 同时可看到 **Source Title（来源出版物）** 名称，记录备用。

### 路径二：在 WoS 的“出版物”中查期刊名

1. 在核心合集顶部切换到 **Publications（出版物 / Source Publication）** 标签。
2. 输入期刊名（全称或缩写均可，WoS 会自动匹配）。
3. 打开该期刊的详情页，查看其被哪些索引收录、所属学科类目（Categories）。

![WoS 来源出版物详情](/images/foreign/f08-wos-journal.svg)

*图 5-9 在 WoS 中查看来源出版物的收录信息与学科类目。*

### 路径三：到 Journal Citation Reports（JCR）查分区与指标

1. 访问 <https://jcr.clarivate.com>（需机构权限）。
2. 在检索框输入期刊名或 ISSN。
3. 查看该期刊的收录索引、学科类别（Category）、分区（Quartile）与各项指标。

::: warning JCR 与 WoS 需要机构权限
JCR 与 WoS 都需要**机构订阅权限**。若你在校外访问显示“无权限”，请通过学校图书馆的授权入口（VPN / CARSI / WebVPN）登录，而非自行注册个人账号。个人免费账号通常看不到完整的分区与影响因子数据。
:::

## 5.5.4 JCR 是什么、在哪里查

**Journal Citation Reports（期刊引证报告，简称 JCR）** 是科睿唯安发布的期刊评价年度报告，数据来源于 Web of Science 核心合集的引文数据。它的作用是：对某一学科类别内的期刊，按引文指标进行排名与分区，帮助研究者快速判断一本期刊在其领域中的相对位置。

访问地址：<https://jcr.clarivate.com>

在 JCR 中你可以：

- 按 **期刊名（Journal name）** 检索某一本期刊。
- 按 **ISSN** 精确匹配。
- 按 **学科类别（Category）** 浏览某领域全部期刊及其排名。
- 查看期刊的 **Journal Impact Factor、Quartile、Rank、Percentile、JCI** 等指标。

::: tip 只为确认收录走 WoS，要截图再走 JCR
如果你只是想确认“某期刊是不是 SSCI、在哪个学科是几区”，优先用路径二（WoS 出版物页）更快；如果你需要正式的“分区截图”作为论文附录或申报材料，再到 JCR 取图，二者数据同源。
:::

## 5.5.5 JCR 的关键指标怎么读

JCR 页面上的指标较多，对本科论文最有用的几项如下。

![JCR 分区与影响因子示意](/images/foreign/f09-jcr-quartile.svg)

*图 5-10 JCR 分区与影响因子示意：同一学科类别内按指标高低分为 Q1-Q4。*

### Journal Impact Factor（JIF，期刊影响因子）

JIF 指某期刊在**前两年**发表的论文，在**统计年**被引用的平均次数。它的分母是前两年该刊的论文数，分子是这些论文在统计年被引次数。

- 它反映的是**整本期刊**近两年的平均被引水平。
- 它**不能**用来评价该期刊上的某一篇具体论文。
- 不同学科的平均被引量差异巨大，跨领域比较 JIF 没有意义。

### JIF Quartile（Q1—Q4，期刊分区）

分区是 JCR 的核心概念：在**同一个学科类别（Category）**内部，按 JIF 从高到低排序，等分为四段：

- **Q1**：前 25%
- **Q2**：25%—50%
- **Q3**：50%—75%
- **Q4**：后 25%

::: warning 分区必须点明学科类别
分区的第一前提是“**在哪个学科类别里**”。JCR 中同一本期刊可能同时归属多个 Category，而它在不同类别里的分区可能完全不同。例如某本横跨“经济学”与“公共管理”的期刊，可能在经济学类是 Q2，在公共管理中是 Q1。因此报告分区时必须写清“XX 类的 Q1”，不能只说“Q1”。
:::

### JIF Rank 与 JIF Percentile

- **JIF Rank**：该期刊在其学科类别中的名次，如 `12 / 380` 表示该类共 380 本期刊，它排第 12。
- **JIF Percentile**：按百分比表示的相对位置，数值越高越靠前，便于快速判断。

### JCI（Journal Citation Indicator，期刊引文指标）

JCI 是按学科**归一化**后的指标，剔除了学科间被引习惯的差异，便于跨学科横向比较。它的解读逻辑类似 JIF，但更强调“同口径比较”。

### Category（学科类别）

一份期刊可同时属于多个 Category。理解与图 5-10 一致的抽象示例：假设期刊 J 同时被归入“经济学”与“环境研究”两个类别，在经济学中它排在中间靠后（如 Q3），在环境研究中因竞争者较少而排在前列（如 Q1）。这说明**分区高度依赖所参照的学科类别**，离开类别谈分区没有意义。

### 辅助指标：自引率与发文量

- **自引率（Self-citation rate）**：期刊引用自身文章的比例，过高可能提示影响因子被人为抬高，需谨慎看待。
- **发文量（Total Articles）**：年发文量过大有时伴随质量参差，可作为参考而非定论。

::: details 展开：为什么“影响因子高”不等于“这篇文献好”
影响因子是期刊层面、两年窗口、平均化的统计值。它既不能说明某篇具体论文被引多少，也不能说明其方法是否严谨、结论是否适用于你的研究。一个常见误区是：看到某 Q1 期刊就直接引用其中的文章。正确做法是：先确认该文主题与你的论文相关，再读摘要与方法判断其结论可否支撑你的观点，最后才引用。分区只是“初筛可信来源”的辅助，不是引用的充分条件。
:::

## 5.5.6 JCR 分区与中科院分区的区别

国内高校在评价期刊时，常出现两套分区口径，务必分清：

| 维度 | JCR 分区（科睿唯安） | 中科院分区（中国科学院） |
| --- | --- | --- |
| 发布方 | 科睿唯安（Clarivate） | 中国科学院文献情报中心 |
| 划分方法 | 按学科类别内 JIF 四等分 | 按 3 年平均 JIF，且前 5% 为 1 区（金字塔式） |
| 学科分类体系 | JCR Category | 中科院大类/小类 |
| 国内使用习惯 | 国际通用、外文学术界常用 | 国内高校、职称与学位评审常用 |
| 同一期刊的结果 | 可能在多个类别有不同 Q | 有固定的大类/小类分区 |

::: warning 先问清用 JCR 分区还是中科院分区
写论文或申报材料时，**务必先问清本单位要求的是“JCR 分区”还是“中科院分区”**。两套口径对同一期刊可能给出不同结果（例如某刊在 JCR 是 Q1，在中科院可能是 2 区）。以你所在学校或学院发布的认定办法为准，不要自行混用。
:::

## 5.5.7 Q1 不等于适合自己

即便确认了某期刊是 SSCI 且为 Q1，也不代表它一定适合你的本科论文引用。判断时应综合以下因素：

1. **主题相关度**：该文研究的问题是否与你的一致？跨太大领域的 Q1 文章可能只是“看起来高级”。
2. **方法可复用性**：其计量方法、数据来源你能否理解并在文中转述？本科论文更适合引用方法清晰、结论稳健的文献。
3. **数据可得性**：该文使用的微观数据（如某国税收调查）你是否拿得到？若拿不到，引用时需说明无法复现。
4. **文献类型**：对本科生而言，引用 Q1 期刊的**综述类（Review）文章**往往比引用其原创实证文章更有效率，综述帮你快速搭建理论框架，实证文章可作为方法参考。

::: tip 先求相关，再求层级
本科论文引用外文文献，贵在“用得上”而非“堆层级”。一篇 SSCI Q2 的综述，若与你的研究问题高度契合，价值可能高于一篇沾边但难消化的 Q1 实证。先求相关，再求层级。
:::

还需提醒一点：税收学许多重要文献发表于**财政、经济类综合期刊**与**国际组织工作论文**（如 IMF、OECD、世界银行），后者常不被 SSCI 收录，但政策参考价值很高。判定层级时应如实区分“期刊论文（SSCI/SCIE）”与“工作论文（未收录）”，二者都可在论文中引用，只是标注方式不同，不可为追求“全 SSCI”而漏掉关键的政策文献。

## 5.5.8 用“索引类型”筛文献的正确姿势

很多同学一上来就在检索式里写成 `SSCI AND Q1`，结果把大量关键文献筛掉了。推荐的顺序是：

1. **先保证主题相关**：用 TS= 等主题字段把相关文献找全。
2. **再看收录层级**：在 Refine results 中用 Web of Science Index 筛选 SSCI/SCIE，确认来源可靠性。
3. **最后看年份与方法**：按 Date 或 Citations 排序，挑出最新或最经典的若干篇。
4. **需要分区时再查 JCR**：对最终要引用的几篇，到 JCR 确认其学科类别与分区，作为论文“文献层级说明”的依据。

::: warning 不要把 SSCI 筛选放在第一步
不要把“筛选 SSCI”作为检索的第一步。过早限定会让你错过 ESCI 中新兴但高度相关的文献，以及虽未被 SSCI 收录但在本国税收实务中很有参考价值的区域性期刊文章。先广后精，才是稳妥策略。
:::

## 5.5.9 常见问题与自查清单

| 问题 | 自查方向 |
| --- | --- |
| 这篇到底是不是 SSCI？ | 看 WoS 记录的 Web of Science Index 是否明确列出 SSCI |
| 为什么 JCR 查不到这本刊？ | 可能未被 SCIE/SSCI 收录，或属 ESCI/CPCI，JCR 不覆盖 |
| 同一刊在不同地方分区不同？ | 检查是否参照了不同 Category，或 JCR 与中科院口径不同 |
| 影响因子是多少？ | 不记具体数字，到 JCR 按当年版本查询；数值逐年变化 |
| ESCI 能当 SSCI 用吗？ | 不能，二者索引不同，须分别标注 |
| 会议论文算不算？ | 会议属 CPCI，与 SCI/SSCI 分开标注 |

**自查清单（确认一篇文献的收录层级时逐条勾选）：**

- [ ] 在 WoS 核心合集中检索到该文献，并记录 Source Title。
- [ ] 详情页 Web of Science Index 列出了具体索引（SSCI/SCIE/ESCI/A&HCI/CPCI）。
- [ ] 如需要分区，已在 JCR 按“正确学科类别”查到 Quartile。
- [ ] 已区分是 JCR 分区还是中科院分区，并以本单位口径为准。
- [ ] 未将期刊影响因子直接当作该篇文献质量的证明。
- [ ] 若引用 Q1 文章，已确认其主题与方法确实支撑你的论点。

::: details 展开：一个完整的判定流程示例（抽象）
假设你在写一篇关于“碳税与企业绿色创新”的论文，读到一篇发表在某环境经济类期刊上的文章。判定步骤：

1. 在 WoS 用 DOI 检索该文 → 详情页显示 Web of Science Index 含 SSCI。
2. 切到 Publications 查该刊 → 确认其同时归属“环境研究”与“经济学”两个 Category。
3. 到 JCR 查该刊 → 在“环境研究”类中为 Q1，在“经济学”类中为 Q2。
4. 你的论文归属公共管理/财政方向，学校认定以 JCR 为准 → 你在文中注明“该刊为 SSCI 收录，在环境研究类为 Q1”。

注意：你始终依据“类别 + 分区”双信息，而非孤立地说“Q1”。
:::

## 5.5.10 论文中如何规范标注收录层级

在你的本科毕业论文里，通常需要有一处说明“所引外文文献的层级”（常见于文献综述开头或研究方法章）。规范标注应注意以下几点：

1. **如实标注索引，不夸大**：若某刊为 ESCI 而非 SSCI，应写“ESCI 收录”，不可写“SSCI”。导师与评审最忌讳层级标注失实。
2. **分区必须带口径与类别**：写“SSCI 经济学类 Q1（JCR）”，而不要只写“Q1”。若学校采用中科院分区，则改为“中科院 2 区”并注明大类/小类。
3. **影响因子不写具体数字，或注明年份与来源**：如确需引用，可写“据 JCR（20XX 年卷）该刊 Journal Impact Factor 位于其学科前列”，并保留查询截图作为附件；不凭记忆写数字。
4. **区分“期刊层级”与“论文质量”**：标注时可使用“所引文献主要发表于 SSCI/SCIE 收录期刊”这类总体性表述，而非逐篇声称“高质量”。
5. **区域表述规范**：涉及中国香港、中国台湾、中国澳门的高校或研究机构时，务必写作“中国香港”“中国台湾”“中国澳门”。

::: tip 论文里怎么写外文文献的层级
一个稳妥的论文表述模板：“本文参考的外文文献以 SSCI、SCIE 收录期刊为主，其中部分期刊在其 JCR 学科类别中位居 Q1/Q2；少数区域性研究引用了 ESCI 及机构工作论文，均已在参考文献中标注来源。”这样既展示了文献层级意识，又避免了逐篇堆砌分区数字的风险。
:::

::: warning ESCI 不要写成 SSCI
被评审退回的常见问题之一是“把 ESCI 写成 SSCI”或“只写 Q1 不写学科类别”。提交前请逐篇核对 Web of Science Index 与 JCR 的真实标识，宁可标注保守（如写“SSCI 收录”而不写未核实的分区），也不要冒层级失实的风险。
:::

## 课堂实操

请任选你专业方向（税收学/财政学/公共管理）的 **3 篇** 外文文献，逐篇完成收录层级判定，并提交一份简短的“判定报告”。报告每篇包含以下字段：

1. **文献题名与来源期刊（Source Title）**。
2. **收录索引**：在 WoS 核心合集中查到的 Web of Science Index 具体标识（如 SSCI、SCIE、ESCI）。
3. **学科类别（Category）**：该期刊在 JCR 中所归的学科类别（至少写出你参照的那一个）。
4. **分区（Quartile）**：在上述类别中的 Q1—Q4，并注明是 JCR 还是中科院口径。
5. **判断依据**：你是如何查到的（路径一/二/三），截图或记录关键页面信息。

提交示例（请用真实文献填写，不要留空）：

| 序号 | 来源期刊 | 收录索引 | 学科类别 | 分区 | 依据 |
| --- | --- | --- | --- | --- | --- |
