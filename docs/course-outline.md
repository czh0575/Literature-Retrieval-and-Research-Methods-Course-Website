# 《文献检索与研究方法》课程大纲

本课程面向大四学生，围绕“从提出问题到形成规范研究成果”的完整过程展开。课程不把论文写作理解为最后阶段的格式加工，而是将学术道德、选题、文献检索、文献管理、文献综述和开题报告视为相互衔接的研究训练。

## 一、课程简介

### 1. 课程定位

- 认识学位论文与一般学术论文、课程报告之间的联系与区别
- 训练提出问题、分析问题、组织证据和规范表达的能力
- 为毕业论文选题、开题答辩和论文初稿准备可复用的工作流程

### 2. 学习目标

学完本课程后，学生应能够：

1. 说明学术道德、学术规范与论文质量之间的关系
2. 将宽泛兴趣转化为可研究、可度量、可完成的研究问题
3. 使用知网、ScienceDirect、Web of Science 等数据库建立关键词体系并完成检索、筛选和导出
4. 使用 Zotero 管理题录、附件、标签、批注和引用
5. 按专题归纳文献，完成“有综有述”的文献综述
6. 独立完成一份结构完整、格式规范的课程报告或开题报告

### 3. 课程任务与考核

- 平时成绩：50%
  - 课堂表现（考勤、讨论、提问与回答）：20%
  - 课堂作业约 3 次：30%
  - 优秀表现可作为特别奖励
- 期末课程报告：50%
  - 以开题报告或课程报告为基础
  - 文献综述是重点部分
  - 必须有规范的引文和参考文献
  - 课程报告评分与开题答辩成绩相互独立

### 4. 课程产出

- 一份可行的论文选题说明
- 一份检索记录和文献管理库
- 一份文献综述初稿
- 一份课程报告或开题报告

## 二、学术道德

### 1. 为什么要学习学术道德

- 学位论文不仅考查结果，也考查研究过程
- 规范写作是未来写报告、做研究和进入职场的基础能力
- 诚信比“降低重复率”更重要，不能把查重当成学术规范的全部

### 2. 学术不端的基本类型

- 剽窃、抄袭和侵占他人学术成果
- 伪造、篡改或选择性报告数据
- 不当署名、虚构合作者或隐瞒他人贡献
- 提供虚假学术信息
- 买卖论文、代写论文
- 违规使用人工智能工具或把未经核验的生成内容当作事实

### 3. 论文写作中的具体规范

- 何时必须引用
- 直接引用、转述和总结的区别
- 引文与参考文献的一致性
- 数据、图表、图片和网络资料的来源标注
- 合作写作中的贡献确认
- 使用 AI 时的核验、披露与责任边界

### 4. 案例与课堂活动

- 代写和买卖论文案例
- “只改写句子就不算抄袭”的误区
- “AI 生成内容能否直接放入论文”的判断练习
- 给一段材料，要求学生完成转述、引用和参考文献标注

## 三、关于论文选题

### 1. 从兴趣到研究问题

- 区分研究对象、研究问题、研究变量和研究结论
- 用“是什么、为什么、怎么办”拆解问题
- 避免把“研究某行业/某群体”直接当成研究问题

### 2. 选题的四项原则

- 研究性：能够提出需要分析和论证的问题
- 创新性：在已有研究基础上形成新的角度、材料、机制或结论
- 时效性：与现实政策、行业变化或社会问题保持联系
- 可行性：在时间、数据、方法和能力范围内完成

### 3. 税收学专业的选题方向

- 税收理论与税收史
- 税收政策与制度
- 税收管理与征收
- 税收与经济发展
- 专项税种与企业、个人
- 税收法治与税收遵从
- 地方税收
- 特殊行业与税收

### 4. 实证选题的基本结构

- 用 X 表示核心解释变量，用 Y 表示被解释变量
- X、Y 必须能够找到文献支撑并且可以度量
- 避免 X 对 Y 的关系过于直接、无需研究
- 尽量优先考虑可获得的企业层面数据

### 5. 选题流程与产出

1. 确定大致方向
2. 搜集并阅读相关文献
3. 初步确定研究内容
4. 明确背景、视角、方法和意义
5. 拟定研究思路与框架
6. 撰写选题说明和开题报告

### 6. 常见问题

- 核心变量含义不清
- 研究对象过大
- 概念无法度量
- 数据获取难度过高
- 研究意义只是宏大口号
- 选题与已有论文高度重复

## 四、中文文献的搜集

### 1. 检索前的准备

- 把研究题目拆成核心概念
- 建立“核心关键词—上位概念—同义词—相关概念”的关键词金字塔
- 先求全，再逐步限定学科、年份、来源和文献类型

### 2. 基础检索与高级筛选

- 主题、篇名、关键词、摘要和全文字段的区别
- 关键词组合与检索式设计
- 按学科、年份、来源、核心期刊和文献类型筛选
- 用标题和摘要判断相关性

### 3. 从检索结果发现研究脉络

- 识别高频关键词和代表性研究
- 追踪综述、学位论文和高被引论文
- 通过参考文献和被引文献扩展检索
- 使用知网的可视化分析辅助了解研究领域

### 4. 文献筛选与记录

- 建立纳入与排除标准
- 保存题录、摘要、关键词、来源和下载位置
- 记录每篇文献的研究问题、数据、方法和结论
- 形成可追溯的检索日志

### 5. 导出与引用

- 批量导出题录
- 检查作者、年份、刊名、卷期、页码和 DOI
- 认识数据库导出格式可能存在的错误
- 为后续 Zotero 管理和文献综述写作准备数据

## 五、外文文献的搜集

### 1. 外文检索的准备

- 从中文论文的英文摘要与关键词栏收集英文表达，而不是直接翻译题目
- 制作中英文关键词对照表，掌握税收学高频术语的中英对应
- 缩写与全称（R&D / research and development、VAT / value-added tax）都要检索
- 注意英式与美式拼写差异
- 用"回验法"验证译法是否地道：把英文词放回外文库检索一遍

### 2. ScienceDirect 检索

- 快速检索与 Advanced search 的分工
- 字段选项：Title, abstract or author-specified keywords（≈ 知网的"主题"）、Title only、Author、Author affiliation、Journal and book title
- 检索语法：双引号精确短语、AND / OR / NOT 大写、* 通配、括号控制优先级
- 文献类型识别：Research article、Review article、Book chapter 的区别与阅读顺序

### 3. 结果精炼与全文获取

- Refine by：Year、Article type、Publication title、Subject areas、Access type
- 90 秒判读一篇外文文献：Highlights → Abstract 结论句 → Keywords → Conclusion
- 全文获取途径：机构订阅、Open access、机构知识库与预印本、文献传递与馆际互借、向通讯作者索取
- 导出 RIS / BibTeX 题录，交由 Zotero 统一管理

### 4. 定位 SCI / SSCI 文献

- 分清 SCI、SCIE、SSCI、ESCI、A&HCI、CPCI，理解各自覆盖的学科范围
- 用 Web of Science 的 Web of Science Index 精炼项直接筛出 SSCI、SCI-EXPANDED 收录文献
- 检索字段与语法：TS=、TI=、AU=、SO=、PY=、NEAR/n、SAME
- 在来源出版物详情页确认期刊的收录索引与学科类目

### 5. JCR 分区与影响因子

- JIF、JIF Quartile（Q1—Q4）、JIF Rank、JCI、Category 的含义与边界
- 分区是"同一学科类别内部"的相对位置，必须说明是哪个类别里的 Q1
- JCR 分区与中科院分区的区别，写作与申报前先确认本单位采用哪一种口径

### 6. 引用追踪与检索语法速查

- Google Scholar 的被引用次数、相关文章、所有版本与快讯功能
- 引用追踪三条路径：参考文献往回追、引证文献往后追、同被引文献横向追
- 中外文数据库（知网 / Web of Science / ScienceDirect）检索字段与语法对照速查表
- 英文引文条目的 GB/T 7714 与 APA 格式写法

## 六、文献管理工具：Zotero

### 1. 为什么需要文献管理工具

- 解决文件散落和重复下载问题
- 解决题录字段不完整和格式不统一问题
- 让“阅读—批注—引用—生成参考文献”形成连续流程

### 2. 认识界面与完成安装

- Zotero 由主程序、浏览器连接器、文字处理器插件、账号与云同步四部分组成
- 主界面三栏结构与六个区域：菜单栏、工具栏、左栏资料库与分类、中栏条目列表、右栏信息面板、标签过滤器
- 安装 Zotero 主程序与浏览器连接器（Zotero Connector）
- 安装知网中文插件（茉莉花 Jasminum）并更新翻译器，改善中文文献抓取效果

### 3. 把文献抓进 Zotero

- 三种入库方式的比较：拖动识别、连接器一键抓取、导出题录再导入
- 拖动的四种落点（中间栏空白处 / 已有条目上 / 分类上 / 本地 PDF）与结果差异
- 利用知网插件下载知网全文（PDF / CAJ）
- 抓取失败的常见原因与排查

### 4. 题录与附件管理

- 从知网等数据库导入题录
- 导入 PDF 并核对元数据
- 合并重复条目
- 统一文件命名和附件位置
- 使用标签和笔记记录阅读状态

### 5. 阅读与知识整理

- 给文献添加摘要、批注和阅读笔记
- 区分“原文观点”和“自己的判断”
- 为文献建立专题、观点和方法标签
- 记录可直接用于综述的证据句和页码

### 6. Word 引用与参考文献

- 插入文内引用
- 选择 GB/T 7714 等引用样式
- 自动生成和更新参考文献表
- 修改题录后刷新文档
- 论文定稿前逐条检查引用与参考文献

### 7. 工作流与备份

同步与备份的区别 → 下载题录 → 核对元数据 → 归档 PDF → 阅读批注 → 写作引用 → 生成参考文献 → 备份与恢复演练。

## 七、开题报告撰写

开题报告是毕业论文的第一份正式文书，也是把前面各模块的成果组装成完整研究设计的环节。本部分按开题报告的七个栏目逐项展开，并给出可对照的范例与自查清单。

### 1. 开题报告的结构与写作流程

- 开题报告要回答的六个问题
- 七个基本部分：背景与意义、国内外研究现状、研究内容与可行性、关键问题与难点、研究方法与技术路线、总体安排与进度、主要参考文献
- 各部分之间的逻辑关系：上半段解决“为什么研究”，下半段解决“怎么研究”
- 建议的写作顺序：先定研究内容，再写方法与综述，最后写背景与参考文献

### 2. 选题背景与研究意义

- 研究背景的三个维度：国家有政策、社会有需要、学界有需求
- 三个维度最终都要落到自己的研究内容上
- 理论意义与现实意义的分工与常用落点
- 分点论述与总分结构这两个写作加分项

### 3. 文献综述

本节分三页讲授：7.3.1 任务、范围与专题划分 → 7.3.2 归纳、比较与评述 → 7.3.3 从阅读卡片到综述初稿。

- **7.3.1 任务、范围与专题划分**
  - 文献综述回答的四个问题
  - 字数与查重、格式不规范、只有综没有述这三类常见问题
  - 三种组织方式：按专题、按国内外、综合组织
  - “X 对 Y 型”的三种拆法与“问题/对策型”的由大到小拆法
  - 著者—出版年制的引注规范
- **7.3.2 归纳、比较与评述**
  - “综、述、评”三种动作的分工
  - 罗列式写法与合并同类写法的对比
  - 合并同类观点的三个技巧：相同结论合一句、承接词串脉络、上位概念统摄
  - 分歧的来源与写法
  - 文献评述的五个维度与收尾方式
- **7.3.3 从阅读卡片到综述初稿**
  - 阅读卡片要记录的六个字段
  - 从卡片到段落的三步法
  - 三种可复用的段落模板：共识型、分歧型、分层型
  - 组装初稿的顺序与四个常见返工点

### 4. 研究内容与可行性分析

- 研究内容的总分结构
- 逐章介绍要交代的四件事
- 实证类与规范类的章节框架，正文以 5—6 章为宜
- 框架图的画法与常见问题
- 可行性分析：思路可行、数据可行、方法可行

### 5. 拟解决的关键问题与难点

- 关键问题即研究重点；难点是可以克服的困难，克服不了的是研究不足
- 关键问题写 2 条，每条“总起 + 为什么是重点 + 打算怎么解决”
- 研究难点写 2 条，每条“总起 + 为什么是难点 + 如何克服”
- 重点与难点的区分办法

### 6. 研究方法与技术路线

- 按研究问题选择方法，不做方法堆砌
- 每个方法写清“是什么、用来做什么、怎么做”
- 技术路线的定义、技术路线图的画法要点与常见问题

### 7. 参考文献与进度安排

- 进度表要写成可检查的任务
- 学院进度表的常见阶段，具体日期以当年通知为准
- 参考文献的基本要求与 GB/T 7714 著录格式
- 用 Zotero 生成并逐条核对

### 8. 提交前检查与答辩准备

- 内容、格式、语言三轮检查
- 逐栏检查清单
- 开题答辩的评审关注点与九类常见问题
- 答辩不通过的常见原因

## 八、贯穿全课程的学习路径

选题方向 → 关键词体系 → 数据库检索 → Zotero 建库 → 阅读和批注 → 文献综述 → 开题报告 → 课程报告或论文初稿。

每个模块都应留下可提交的过程性成果，最终形成一套能够继续用于毕业论文的研究档案。
