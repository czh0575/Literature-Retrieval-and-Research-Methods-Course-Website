## 欢迎来到《文献检索与研究方法》课程网站

本课程面向准备撰写毕业论文的本科同学，围绕“从提出问题到形成规范研究成果”的完整过程展开。学完本课程，你应当能够：

- 说明学术道德、学术规范与论文质量之间的关系
- 把宽泛的兴趣转化成可研究、可度量、可完成的研究问题
- 使用知网、ScienceDirect、Web of Science 建立关键词体系，完成检索、筛选与题录导出
- 使用 Zotero 管理题录、附件、标签、批注与引用
- 按专题归纳文献，写出一份“有综有述有评”的文献综述
- 独立完成一份结构完整、格式规范的开题报告，并完成开题答辩准备

点击上方「开始学习」进入课程第一章。进入课程页后，可在左侧导航栏按顺序浏览各章；页面顶部可以搜索全站内容。
